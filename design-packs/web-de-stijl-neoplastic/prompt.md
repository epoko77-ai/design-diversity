# 데 스틸 네오플라스틱 — web 디자인 팩

spec_version: v3.1-2026-08-16 · reference_mode: historical_canon

## 이 스타일의 정체성
굵은 순흑 수직·수평 선이 페이지를 직사각형 면으로 비대칭 분할하고, 일부 면만 순수 빨강·노랑·파랑으로 채우며 나머지는 흰색으로 두는 1917년 신조형주의(몬드리안·리트벨트) 사이트다. 무엇을 보면 이 스타일임을 아는가 — 사선과 곡선이 단 하나도 없고 모든 분할이 수직·수평 직선이다, 검정 선이 6–12px로 굵게 면을 가른다, 색이 삼원색(빨강·노랑·파랑)뿐이고 그것도 면 전체에서 소수의 면만 채운다, 모션이 전혀 없는 정적 구성이다.

근거는 신조형주의 정전의 원리 인벤토리 — 직교(수직·수평) 구성만 허용, 삼원색 + 무채색(흰·검)으로 색 제한, 비대칭 균형, 검정 룰로 경계 지어진 면(plane), 평면성(깊이 표현 없음). 정전은 특정 hex·px·면적 비율을 규정하지 않으므로 아래 수치는 본 팩 지정 운영값이다.

## 색 — 역할·면적 비율·대비 실측
- 화이트 필드 `#FFFFFF`: 화면 면적의 55–70% — 지배 면.
- 프라이머리 레드 `#E30613`: 면적 8–15%.
- 프라이머리 블루 `#0050A0`: 면적 8–15%.
- 프라이머리 옐로 `#FFD500`: 면적 4–10% — 셋 중 가장 작게(포인트).
- 블랙 라인 `#1A1A1A`: 분할선·텍스트 — 룰 면적 합계 5–10%.
- 위 5색 외 hex 0개 — 회색·파스텔·보라·초록·주황 전부 금지. 그라디언트 0개.
- 대비 실측: `#1A1A1A` on `#FFFFFF` = 17.4:1 (AAA) / `#1A1A1A` on `#FFD500` = 12.2:1 / `#FFFFFF` on `#0050A0` = 7.9:1 / `#FFFFFF` on `#E30613` = 4.9:1 (AA).
- 레드 면 위 검정 텍스트 금지 — 3.6:1로 미달. 레드·블루 면 텍스트는 흰색, 옐로·흰 면 텍스트는 검정.

## 타이포그래피 — 크기 집합 고정
- 디스플레이: `Archivo Black`(Google Fonts) weight 400, 대체 `'Arial Black', Helvetica, sans-serif`.
- 본문·라벨: `Archivo`(Google Fonts) weight 500·700, 대체 `sans-serif`. 이 2 family 외 폰트 금지 — 세리프 0.
- H1: `clamp(2.4rem, 5vw, 4.6rem)`, 대문자, line-height 1.0, letter-spacing `-0.01em`.
- H2/면 제목: `clamp(1.5rem, 2.6vw, 2.2rem)`, Archivo Black 대문자, line-height 1.05.
- 카드 제목: `1.25rem`, Archivo Black 대문자.
- 본문: `1rem`, Archivo 500, line-height 1.5, 측정 56–66자.
- 라벨/캡션: `0.75rem`, Archivo 700, 대문자, letter-spacing `0.12em`.
- 크기 집합은 위 5단만 — 집합 밖 임의 크기 금지. 텍스트 회전·사선 배치 0건.

## 반응형 — 브레이크포인트별 값
- CSS 브레이크포인트 2개: `768px`, `1120px`.
- 375px 뷰포트: 면 분할이 세로 스택으로 단순화(1열) — 각 면이 풀폭 가로 밴드, 검정 룰 6px, 면 내부 패딩 24px, 히어로 min-height 100svh.
- 768px 뷰포트: 2열 면 분할 시작, 주 분할선 8px, 면 내부 패딩 32px.
- 1280px 뷰포트: 전체 비대칭 컴포지션 — 주 분할선 8–12px·보조 6px, 면 내부 패딩 48px, content_max 없음(풀폭 면 구성).
- 브레이크포인트 전환 시에도 모든 면은 검정 룰로 사방이 닫힌 상태 유지 — 스택에서도 면 사이 룰 6px.

## 레이아웃 / 그리드 — 해소된 면 구성
- 화면 전체가 직사각형 plane으로 빈틈없이 덮인다 — CSS Grid `grid-template`, 불균등 `fr` 트랙(예: `2fr 5fr 1.5fr`), 균등 분할 금지.
- 면 사이 경계 = 검정 룰: 주 분할선 8–12px, 보조 분할선 6px, `gap` + 배경 `#1A1A1A` 또는 보더로 구현.
- **모든 면은 사방(화면 외곽 제외)이 검정 룰로 닫힌다** — 경계 없는 빈 흰 영역 0개, 홀로 떠 있는 색 사각형 0개.
- 색 면은 항상 검정 룰을 공유하며 인접 면과 맞물린다 — 큰 흰 공간 중앙 부유 배치 금지.
- 면 내부 패딩 `clamp(24px, 3vw, 48px)` 일관. 텍스트는 면 좌상 또는 좌하 정렬(중앙 정렬 금지 — 비대칭).
- 면 크기는 의도적 불균등 — 최대 면과 최소 면의 면적비 6:1 이상.
- 섹션 수직 리듬 없음(0px) — 섹션 사이도 검정 룰이 경계.

## 형태 / 질감
- 모서리 radius 0px — 직각만. 곡선·사선·둥근 모서리 0건.
- 그림자 0, 그라디언트 0, 깊이 표현 0 — 완전 평면.
- 이미지: 직사각형 면에 꽉 차게(object-fit: cover), radius 0px, 둘레 검정 룰 6px.
- 아이콘: 직사각형·직선만으로 구성한 기하 도형, 검정 또는 삼원색, 24px 그리드. 제너릭 아이콘·이모지 0건.

## 모션 — 없음
- `transition: none` — duration 0ms. 스크롤 진입 애니메이션·패럴랙스·페이드 0건.
- 허용되는 유일한 상태 변화: hover/active 시 면 색이 0ms로 즉시 교체(트랜지션 없이).
- `prefers-reduced-motion`: 이미 모션 0이므로 추가 대응 불요 — 단 hover 색 교체는 유지(모션 아님).

## 인터랙션 상태
- 버튼 default: 레드 `#E30613` 또는 블루 `#0050A0` 직사각형 면 + 검정 보더 4–6px + 흰 Archivo Black 대문자 라벨, 패딩 `14px 32px`, radius 0px.
- 버튼 hover: 배경이 0ms로 다른 삼원색 또는 `#1A1A1A`로 즉시 교체(라벨 대비 4.5:1 이상 유지 — 옐로로 바뀌면 라벨 검정).
- 버튼 focus-visible: `outline: 4px solid #1A1A1A; outline-offset: 2px` — 모든 인터랙티브 요소 공통, outline 제거 금지.
- 버튼 active: 배경 `#1A1A1A` + 흰 라벨(반전), 0ms.
- 링크 default: 검정 텍스트 + 하단 3px 검정 룰. hover: 룰이 6px로 즉시 굵어짐(0ms). active: 텍스트 `#E30613`.
- 메뉴 현재 항목: 노랑 `#FFD500` 면 배경 + 검정 텍스트.

## 컴포넌트

## 상세 페이지 (5종) — 전역 규칙 상속, 아래는 페이지 고유 값

### 1. 히어로 (면 분할 구성)
- min-height 88vh를 검정 룰 8–12px로 면 분할 — 그리드 `grid-template-columns: 7fr 3fr` / `grid-template-rows: 5fr 2fr` 기준 비대칭.

- 우측 세로 블루 면: 화면 높이의 70%, 텍스트 없는 순수 색 면.
- 우하 노랑 면: 블루 면 아래, 높이 30%, 검정 룰 8px로 블루와 분리.
- 좌하 가로 밴드: 흰 면 + `0.75rem` 라벨 1줄(스크롤 힌트, 검정).
- 색 면적 검산: 블루 ≈12% + 노랑 ≈6% + 레드(버튼) ≈2% — 합계 20% 내외, 흰 면 지배.
- 면 4개+버튼이 화면 100%를 덮음 — 검정 룰 미공유 경계 0개.
- 375px: 세로 스택 순서 H1 흰 면 → 블루 밴드(높이 120px) → 노랑 밴드(높이 64px), 룰 6px.
