# 아르누보 플로리도 — web 디자인 팩

spec_version: v3.1-2026-08-16 · reference_mode: historical_canon

## 이 스타일의 정체성
휘감기는 식물 채찍 곡선(whiplash curve) 장식이 섹션 경계·프레임·구분선을 휘감고, 흐르는 디스플레이 세리프가 위계를 만들며, 차분한 머스터드·세이지·플럼의 벨 에포크 팔레트가 크림 배경을 채우는 1890년대 아르누보 사이트다. 무엇을 보면 이 스타일임을 아는가 — 직선 보더 대신 SVG 채찍 곡선이 콘텐츠를 감싸고 흐른다, 헤드라인이 우아하게 흐르는 세리프이고 본문도 가라몬드 세리프다, 색이 채도 높은 원색이 아니라 19세기풍 머스터드/세이지/플럼이다, 곡선 장식이 부드럽게 드로우·페이드하며 등장한다.

근거는 아르누보 정전(오르타·기마르·무하 계열)의 원리 인벤토리 — 비대칭 채찍 곡선, 식물 모티프의 구조 통합, 직각 지배 회피, 기계적 반복 회피. 색 hex·px 값은 정전이 규정하지 않으므로 본 팩 지정값이다.

## 색 — 역할·면적·대비 실측
- 배경 크림 `#F2EBD9`: 기본 캔버스 — 전체 화면 면적의 60% 이상.
- 표면 변주 `#EAE1CB`: 교대 섹션·후기 배경 — 면적 상한 25%.
- 잉크 `#2E2A22`: 본문·헤드라인 전용 텍스트 색.
- 머스터드 골드 `#C9A227`: 곡선 stroke·프레임·드롭캡 전용. 크림 위 대비 2.03:1 — **장식·3줄 높이 드롭캡 한정, 본문·라벨 텍스트 사용 금지**.
- 세이지 `#6E7E5B`: 보조 곡선·구분선. 크림 위 3.68:1 — 텍스트로는 1.5rem 이상 large text만.
- 플럼 `#6B4869`: 키커·라벨·딥 강조. 크림 위 6.41:1 (AA 통과).
- 대비 실측: `#2E2A22` on `#F2EBD9` = 12.0:1 (AAA) / `#2E2A22` on `#EAE1CB` = 11.0:1 / `#F2EBD9` on `#6B4869` = 6.4:1.
- 팔레트는 위 6색 고정 — 추가 hex 0개, 그라디언트 0개.

## 타이포그래피 — 크기 집합 고정
- 디스플레이: `Cormorant Garamond`(Google Fonts) weight 600, 대체 `Georgia, 'Times New Roman', serif`. 헤드라인 small-caps 변주는 `Cormorant SC`.
- 본문: `EB Garamond`(Google Fonts) weight 400·500, 대체 `Georgia, serif`. 이 2 family 외 폰트 금지 — 산세리프 0.
- H1: `clamp(2.6rem, 5vw, 4.8rem)`, line-height 1.1, letter-spacing 0.
- H2: `clamp(1.9rem, 3.2vw, 2.9rem)`, Cormorant 600, line-height 1.15.
- H3/카드 제목: `1.35rem`, Cormorant 600, line-height 1.25.
- 본문: `1.1rem`, line-height 1.7, 측정 60–70자.
- 키커/라벨: `0.82rem`, EB Garamond 500, small-caps, letter-spacing `0.16em`, 색 `#6B4869`.
- 인용문: `clamp(1.5rem, 2.6vw, 2.1rem)`, Cormorant italic, line-height 1.35.
- 드롭캡: Cormorant 600, 본문 3줄 높이(≈`5.4rem`), 색 `#C9A227`, 우측 마진 12px.
- 크기 집합은 위 7단만 사용 — 집합 밖 임의 크기 금지.

## 반응형 — 브레이크포인트별 값
- CSS 브레이크포인트 2개: `720px`, `1080px`.
- 375px 뷰포트: 1열 스택, 좌우 패딩 24px, 섹션 수직 80px, 히어로는 텍스트→이미지 순 스택, 갤러리 1열, 곡선 밴드 높이 40px.
- 768px 뷰포트: 히어로 2열(7:5) 시작, 좌우 패딩 40px, 섹션 수직 ≈104px, 갤러리 2열, 본문 2단 시작.
- 1280px 뷰포트: content_max 1080px(좌우 여백 자동), 좌우 패딩 56px, 섹션 수직 128px 상한, 갤러리 3열.
- 타이포는 위 clamp가 뷰포트를 따라 연속 스케일 — 브레이크포인트에서 점프 없음.

## 레이아웃 / 그리드
- 콘텐츠 최대 폭 `1080px`. 섹션 수직 리듬 `clamp(80px, 9vw, 128px)`.
- 비대칭 배치 — 텍스트·이미지 블록이 곡선 흐름을 따라 좌우로 4–8% 어긋남. 좌우 대칭 컴포지션 금지.
- 간격 스케일: 8px 베이스. 키커↔헤드라인 20px, 헤드라인↔리드문 24px, 리드문↔CTA 32px.
- 곡선 밴드와 콘텐츠 사이 여백 `clamp(32px, 4vw, 56px)` — 곡선이 텍스트를 침범하지 않게.
- 각 섹션은 텍스트 + 이미지/일러스트 + 곡선 장식 3요소 완결 — 장식 없는 섹션 0개.

## 장식 문법 — 채찍 곡선 수치 (정전 핵심)
- whiplash 곡선: 비대칭 S-곡선 SVG path. stroke는 시작 2.5px → 끝 0.5px로 가늘어짐(taper). 색 `#C9A227` 또는 `#6E7E5B`.
- 곡률: 컨트롤 포인트 반경 40–160px 범위의 유연한 호 — 반경 20px 미만 급커브·직선 세그먼트 금지.
- 섹션 경계 밴드: 높이 48–72px, 섹션 상·하단 1쌍. 곡선 끝은 지름 10–18px 잎·꽃봉오리 모티프로 마감.
- 코너 필리그리: 96–160px 크기 덩굴 곡선, 대각 2코너(좌상+우하 또는 우상+좌하)에만 — 4코너 대칭 배치 금지(정전은 비대칭).
- 워터마크: 빈 면에 opacity 0.12–0.2, 크기 `min(40vw, 480px)`의 큰 곡선/꽃 모티프 1점.
- 기계적 반복 금지 — 같은 곡선 path의 복붙 타일링 0회, 각 곡선은 미러/스케일 변형이라도 다르게.
- 장식 밀도 하한: 섹션당 경계 밴드 1쌍 + 코너 필리그리 2점 + 워터마크 1점.

## 형태 / 질감
- 모서리: 카드·이미지는 비대칭 유기 곡선 — `border-radius: 60px 8px 60px 8px` 식의 비대칭. 4모서리 균일 radius 금지.
- 그림자 0 — 깊이는 곡선 프레임과 면 색 차이로만.
- 이미지: 상단 아치(`border-radius: 50% 50% 8px 8px` 또는 clip-path 곡선), 위에 머스터드 1.5px 곡선 프레임.
- 아이콘: 아르누보 식물 모티프(잎·꽃봉오리·덩굴 컬)를 1.5px stroke로 크래프트, 24px 그리드. 제너릭 라인 아이콘·이모지 금지.

## 모션
- 기본 전환: `420ms cubic-bezier(0.34, 1.2, 0.64, 1)` — 부드러운 오버슈트.
- 곡선 드로우: 뷰포트 진입(threshold 0.3) 트리거, `stroke-dashoffset` 800ms ease-in-out. 끝 모티프는 드로우 완료 후 200ms 페이드+scale(0.6→1) 인.
- 스크롤 진입: 콘텐츠 `opacity 0→1` + `translateY(20px→0)`, 420ms, 형제 요소 stagger 90ms.
- 호버 모티프: scale 1.0→1.08, 360ms. 링크 곡선 밑줄은 좌→우 드로우 300ms.
- `prefers-reduced-motion: reduce`: 드로우·translate·scale 전부 제거, opacity 200ms만 유지.
- 200ms 미만 기계적 스냅 금지 — 흐르고 피어나는 유기 모션만.

## 인터랙션 상태
- 버튼 default: 머스터드 1.5px 곡선 보더 알약(또는 플럼 `#6B4869` 솔리드+크림 텍스트), 패딩 `12px 30px`, EB Garamond small-caps.
- 버튼 hover: 좌우 식물 디테일 scale 1.08 + 보더 stroke 1.5→2px, 360ms. 솔리드형은 배경 `#5A3C58`로 8% 어둡게.
- 버튼 focus-visible: `outline: 2px solid #6B4869; outline-offset: 3px` — 모든 인터랙티브 요소 공통, outline 제거 금지.
- 버튼 active: scale 0.97, 120ms.
- 링크 default: 잉크 텍스트 + 세이지 1px 곡선 밑줄(옅음). hover: 밑줄이 머스터드 2px로 좌→우 재드로우 300ms. active: 텍스트 `#6B4869`.
- 카드 hover: 프레임 모티프 bloom(scale 1.08) — 카드 자체 translate·그림자 없음.

## 컴포넌트
- **헤더/내비:** 높이 76px, 크림 배경. 좌 워드마크(Cormorant SC `1.3rem`), 우 메뉴 5개(EB Garamond small-caps `0.82rem`, 간격 28px). 하단 경계는 직선 룰 대신 옅은(opacity 0.5) 채찍 곡선 밴드, 양 끝 잎 모티프.
- **곡선 프레임 카드:** `border-radius: 60px 8px 60px 8px`, 머스터드 1.5px 프레임, 크림 표면, 내부 패딩 32px. 드롭캡+제목↔본문 16px, 본문↔하단 모티프 20px. 빈 코너 1곳에 덩굴 필리그리.
- **장식 디바이더:** 좌우로 흐르는 비대칭 곡선(폭 60–80%, 높이 32px) + 중앙 꽃 모티프 1점. 직선 `<hr>` 금지.
- **드롭캡:** 본문 첫 글자 3줄 높이, `#C9A227`, 잎 필리그리 프레임.
- **인용 블록:** Cormorant italic `clamp(1.5rem,2.6vw,2.1rem)` + 좌우 곡선 따옴표 장식 + 세이지 large-text 출처 라벨(`1.5rem` 미만이면 플럼으로).
- **갤러리 타일:** 아치 마스크 이미지 + 머스터드 1.5px 프레임 + 하단 small-caps 캡션 `0.82rem`.

## 하지 말 것 (정전 위반 + 회귀 금지)
- 직각 지배 금지 — 하드 1px 직선 보더·직각 그리드 프레임 0개 (정전: 곡선이 구조).
- 대칭·기계 반복 금지 — 4코너 동일 장식, 같은 path 타일링 (정전: 비대칭·비반복).
- 산세리프 0 — 헤드라인·본문·라벨 모두 세리프.
- 채도 높은 원색·그라디언트·이모지·글래스 패널·그림자 금지. 팔레트 6색 밖 hex 0개.
- 균일 radius(4모서리 같은 값) 금지 — 비대칭 유기 곡선만.
- 곡선 장식 생략·축소 금지 — 섹션당 밴드 1쌍+필리그리 2점+워터마크 1점 하한 미달이면 정체성 상실.
- 빈 크림 데드 보이드·플레이스홀더 회색 박스·길 잃은 부유 요소 금지 — 모든 장식은 곡선 흐름선에 묶인다.
- 정전이 규정하지 않은 것을 정전으로 주장 금지 — hex·px는 본 팩 지정값으로만 서술.

## 상세 페이지 (6종) — 전역 규칙 상속, 아래는 페이지 고유 값

### 1. 히어로 (곡선 장식 프레임)
- min-height 88vh, 크림 `#F2EBD9`. 좌 6열 텍스트 / 우 6열 아치 이미지 — 이미지 상단이 텍스트보다 48px 위로 어긋남.
- 텍스트: 플럼 키커 → H1(`clamp(2.6rem,5vw,4.8rem)`) → 리드문 `1.25rem`/line-height 1.6 → CTA 페어(간격 16px).
- 상·하단 경계 곡선 밴드 각 1쌍(높이 64px), 드로우 시작 딜레이 상단 0ms/하단 200ms.
- 우측 아치 이미지: 머스터드 1.5px 프레임 + 좌상 코너 필리그리 140px.
- 좌측 텍스트 블록 좌상 코너 덩굴 필리그리 120px.
- 텍스트·이미지 사이 빈 면에 워터마크 곡선 1점(opacity 0.15, 크기 44vw).
- 히어로 내 곡선 요소 총 5점 이상 — 가는 선 1–2개로 끝내기 금지.
- 375px: 이미지가 텍스트 아래, min-height 해제, 워터마크 크기 70vw로 확대해 배경 유지.

### 2. 헤더·내비게이션
- 높이 76px 고정, 스크롤 시에도 배경 크림 불투명 유지(블러 0).
- 좌 워드마크 Cormorant SC `1.3rem`, 중앙 메뉴 5개 간격 28px, 우측 곡선 프레임 CTA(패딩 `10px 24px`).
- 하단 곡선 밴드 opacity 0.5, 높이 20px, 양 끝 잎 모티프 지름 12px.
- 메뉴 hover: 곡선 밑줄 드로우 300ms. focus-visible: 전역 outline 규칙.
- 현재 페이지 메뉴: 플럼 `#6B4869` + 상시 곡선 밑줄 1.5px.
- 375px: 메뉴 → 우측 곡선 햄버거(24px 아이콘, 잎 모티프 3획), 열면 크림 풀스크린 오버레이 + 메뉴 `1.6rem` 세로 스택 간격 28px.
- 오버레이 진입: opacity 0→1 320ms + 항목 stagger 60ms.
- 헤더 CTA는 히어로 CTA보다 한 단계 작게 — `0.82rem` 라벨.

### 3. 콘텐츠 상세
- 좌 5열 곡선 마스크 이미지 / 우 7열 텍스트 — 이미지 상단을 텍스트 첫 줄보다 32px 아래로 어긋나게.
- 본문 2단(1080px에서), 단 간격 48px, 단 사이 옅은(opacity 0.3) 세로 채찍 곡선 1개.
- 첫 문단 드롭캡 3줄 높이 `#C9A227` + 필리그리 프레임 96px.
- 섹션 사이 세이지 곡선 디바이더(폭 70%, 중앙 꽃 모티프 14px).
- 이미지 프레임: 머스터드 1.5px + 우하 코너 덩굴 필리그리 110px.
- 소제목 H2 위 여백 48px / 아래 20px.
- 인용 블록 1개 삽입 — 본문 폭의 110%로 좌측 돌출(비대칭).

### 4. 갤러리
- 아치 타일 6개, 비대칭 2–3열 — 열별 상단 오프셋 0 / 40px / 80px로 높이 위계.
