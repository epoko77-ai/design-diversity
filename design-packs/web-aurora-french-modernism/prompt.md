# 오로라 프렌치 모더니즘 — web 디자인 팩

spec_version: v3.1-2026-08-16 · reference_mode: style_synthesis

## 이 스타일의 정체성
밝은 캔버스 위에 노랑→시안→핑크가 오로라처럼 흐르는 다색 메시 그라디언트 면이 섹션 배경을 채우고, 버튼·카드는 모서리 반경 0의 날카로운 직사각형이며, 큰 지오메트릭 산세리프가 활기차게 자리잡는 프랑스 모더니즘 사이트다. 무엇을 보면 이 스타일임을 아는가 — 그라디언트가 작은 점이 아니라 섹션 배경 면 전체를 채운다, 오로라처럼 노랑·시안·핑크 세 색이 부드럽게 섞여 흐른다, 둥근 모서리가 단 하나도 없고 버튼·카드가 전부 zero-radius 직각이다, 모션이 150–200ms로 빠르고 단호하다.

## 색 — 역할·면적·대비 실측
- 배경 `#FFFFFF`: 기본 캔버스. 잉크 `#0E0E12`: 유일한 텍스트 색(흰 면 위) + 보더 + 솔리드 버튼.
- 오로라 3색: 옐로 `#FFE14D` · 시안 `#2BC4FF` · 핑크 `#FF5BA8` — 그라디언트 면 전용, 단색 면·텍스트 색으로 단독 사용 금지.
- 오로라 섹션은 전체 페이지 섹션의 40–60% — 흰 섹션과 교대, 연속 2개 초과 금지.
- 대비 실측: `#0E0E12` on `#FFFFFF` = 19.3:1 / on `#FFE14D` = 14.8:1 / on `#2BC4FF` = 9.6:1 / on `#FF5BA8` = 6.7:1 — 그라디언트 면 어느 지점에서도 잉크 본문 AA 이상.
- 흰 텍스트는 잉크 `#0E0E12` 면 위에서만(19.3:1). 그라디언트 위 흰 텍스트 금지.
- 위 5색 외 hex 0개 — 특히 보라 계열 금지.

## 오로라 메시 레시피 (섹션 배경 공통)
- 베이스 `#FFFFFF` 위에 radial-gradient 3–4 레이어 중첩:
- layer 1: `radial-gradient(60% 80% at 15% 20%, #FFE14D 0%, transparent 60%)`
- layer 2: `radial-gradient(70% 90% at 85% 30%, #2BC4FF 0%, transparent 65%)`
- layer 3: `radial-gradient(80% 70% at 60% 85%, #FF5BA8 0%, transparent 60%)`
- 선택 layer 4: `radial-gradient(50% 60% at 40% 50%, #FFE14D 0%, transparent 55%)` — 깊이 보강.
- 각 레이어 중심 좌표는 섹션마다 10–20% 범위로 변주 — 동일 레시피 복붙 금지.
- 흐름: `background-position` 20s linear infinite — 이 배경 유동만 장시간 모션 허용.

## 타이포그래피 — 크기 집합 고정
- 디스플레이: `Clash Display`(Fontshare) weight 600, 대체 `'Arial Black', Helvetica, sans-serif`.
- 본문·UI: `Inter`(Google Fonts) weight 400·600, 대체 `sans-serif`. 이 2 family 외 금지.
- H1: `clamp(2.6rem, 5.5vw, 5rem)`, line-height 1.04, letter-spacing `-0.02em`.
- H2: `clamp(1.8rem, 3.4vw, 3rem)`, Clash 600, line-height 1.08.
- 카드 제목: `1.3rem`, Clash 600, line-height 1.2.
- 본문: `1.05rem`, Inter 400, line-height 1.6, 측정 58–68자.
- 키커/라벨: `0.78rem`, Inter 600, 대문자, letter-spacing `0.1em`.
- 버튼 라벨: `0.92rem`, Inter 600.
- 크기 집합은 위 6단만 — 그라디언트 텍스트 0건(텍스트는 항상 단색 잉크).

## 반응형 — 브레이크포인트별 값
- CSS 브레이크포인트 2개: `768px`, `1120px`.
- 375px 뷰포트: 1열 스택, 좌우 패딩 24px, 섹션 수직 80px, 카드 그리드 1열, 히어로 이미지가 텍스트 아래.
- 768px 뷰포트: 2열 시작, 좌우 패딩 40px, 섹션 수직 ≈96px, 기능 카드 2열.
- 1280px 뷰포트: content_max 1240px, 좌우 패딩 56px, 섹션 수직 120px, 기능 카드 3열.
- 오로라 레이어 수는 375px에서 3개로 축소(성능) — 색·좌표 구성은 유지.

## 레이아웃 / 그리드
- 콘텐츠 최대 폭 `1240px`, 12열 그리드, 거터 24px. 섹션 수직 리듬 `clamp(80px, 9vw, 120px)`.
- 풀블리드 — 오로라 면은 화면 끝까지, 콘텐츠는 content_max 내 정렬. 모든 요소가 컬럼 경계에 스냅.
- 간격 스케일: 8px 베이스. 키커↔H1 16px, H1↔리드문 24px, 리드문↔버튼 페어 32px, 버튼 페어 간격 16px.
- 카드 그리드 갭: 0(보더 맞붙음, `margin-left: -1px` 중복 제거) 또는 24px — 한 섹션 안에서 혼용 금지.
- 빈 영역 처리: 오로라 면이면 그라디언트가 풍부하게 흐르게, 흰 면이면 직각 카드·이미지로 채움 — 평평한 단색 보이드 0.

## 형태 / 질감
- radius 0px — 버튼·카드·이미지·입력 필드 전부. 1px라도 둥근 모서리 금지.
- 보더: `1px solid #0E0E12` — 카드·외곽선 버튼·입력 필드 공통. 그림자 0.
- 아이콘: 1.75px 스트로크 지오메트릭 라인, 직각 모서리, 24px 그리드. 둥근 캡·이모지 금지.
- 이미지: radius 0px, 자연 채도. 잉크 1px 보더 선택.

## 모션
- 기본 전환: `170ms cubic-bezier(0.3, 0, 0.2, 1)` — snappy.
- 스크롤 진입: 뷰포트 threshold 0.25 트리거, `opacity 0→1` + `translateY(12px→0)` 180ms, stagger 60ms.
- 오로라 유동: background-position 20s linear infinite — 유일한 장시간 모션.
- `prefers-reduced-motion: reduce`: 오로라 유동 정지 + 진입 translate 제거, opacity 120ms만.
- 250ms 초과 인터랙션 모션·바운스·패럴랙스 금지.

## 인터랙션 상태
- 버튼(프라이머리) default: 잉크 `#0E0E12` 솔리드 + 흰 라벨, radius 0px, 패딩 `13px 30px`.
- 버튼 hover: 솔리드↔외곽선 반전(배경 투명 + 1px 잉크 보더 + 잉크 라벨) 170ms.
- 버튼 focus-visible: `outline: 2px solid #0E0E12; outline-offset: 2px` — 그라디언트 면 위에서는 3px. outline 제거 금지.
- 버튼 active: `translateY(1px)`, 100ms.
- 세컨더리 버튼: 외곽선(1px 잉크)이 default, hover 시 솔리드로 반전.
- 링크: default 잉크 + 1px 밑줄. hover: 밑줄 2px 즉시(0ms 등장). active: 밑줄 3px.
- 카드 hover: `translate(-3px, -3px)` + 원위치에 `1px solid #0E0E12` 직각 잔상(box-shadow `3px 3px 0 #0E0E12` 아님 — 보더 잔상), 170ms.
- 입력 필드 focus: 보더 1px→2px 잉크, 170ms.

## 컴포넌트
- **헤더/내비:** 높이 64px, 흰 배경 또는 오로라 위 투명. 좌 워드마크(Clash 600 `1.2rem`), 우 메뉴(라벨 스타일, 간격 28px) + 잉크 솔리드 CTA. 메뉴 hover: 잉크 1px 언더라인 즉시.
- **기능 카드:** 흰 면 + `1px solid #0E0E12`, 내부 패딩 32px. 아이콘↔키커 16px, 키커↔제목 8px, 제목↔본문 12px.
- **가격 카드:** 직각, 내부 패딩 32px, 플랜명↔가격 12px, 가격↔사양 20px. 추천 플랜만 오로라 면 배경 + 잉크 텍스트 + 잉크 2px 외곽선.
- **입력 필드:** radius 0px, `1px solid #0E0E12`, 패딩 `13px 16px`, 플레이스홀더 `#0E0E12` opacity 0.45.
- **아이콘:** 직각·기하 모티프 크래프트만 — 제너릭 세트 금지.

## 하지 말 것
- radius 1px 이상·그림자·글래스 패널·이모지 0건 — zero-radius 직각이 정체성.
- 보라 단색·2색 그라디언트 금지 — 옐로+시안+핑크 3색 오로라만.
- 그라디언트를 점·텍스트·버튼에만 쓰기 금지 — 섹션 배경 면 전체(섹션의 40–60%가 오로라).
- 그라디언트 텍스트·그라디언트 위 흰 텍스트 금지 — 텍스트는 단색 잉크 `#0E0E12`.
- 250ms 초과 인터랙션·바운스 금지 — snappy 170ms.
- 흰 카드만으로 채우기·평면 단색 보이드·플레이스홀더 회색 박스·컬럼 미정렬 부유 요소 0건.
- 팔레트 5색 외 hex 0개.

## 상세 페이지 (6종) — 전역 규칙 상속, 아래는 페이지 고유 값

### 1. 히어로 (오로라 그라디언트)
- 풀블리드, min-height 88vh, 오로라 4레이어(전역 레시피 + layer 4 포함) — 화면 전체에 깊이 있는 필드.
- 좌 7열: 키커 → H1(`clamp(2.6rem,5.5vw,5rem)`, 최대 3줄) → 리드문 `1.15rem`/1.6 → 버튼 페어(솔리드+외곽선, 간격 16px).
- 우 5열: 직각 제품 이미지 또는 흰 면 카드(패딩 32px) — 실제 비주얼 필수, 빈 프레임 금지.
- 이미지/카드에 잉크 1px 보더 + 배경과 대비되게 흰 면 90% 불투명.
- H1은 뷰포트 폭의 55% 이상을 차지하는 크기 — 헤드라인이 화면을 지배.
- 스크롤 힌트: 하단 중앙 잉크 1.75px 직각 화살표 아이콘 24px.
- 375px: 이미지가 텍스트 아래, min-height 100svh 해제, 버튼 페어 세로 스택 간격 12px.
- 오로라 유동 20s — hero에서만 layer 2 좌표를 `85% 30%→70% 40%`로 왕복.

### 2. 헤더·내비게이션
- 높이 64px, 히어로 위 투명 시작 → 스크롤 80px 이후 흰 배경 + 하단 `1px solid #0E0E12` 등장(170ms).
- 좌 워드마크 Clash 600 `1.2rem`, 중앙 메뉴 5개(라벨 `0.78rem` 대문자, 간격 28px), 우 잉크 솔리드 CTA(패딩 `10px 22px`).
- 메뉴 hover: 잉크 1px 언더라인 0ms 등장, 현재 페이지: 언더라인 2px 상시.
- 375px: 중앙 메뉴 숨김, 우측 직각 햄버거 24px — 열면 오로라 3레이어 풀스크린 오버레이.
- 오버레이 메뉴: Clash 600 `2rem` 세로 스택, 행 간 24px, 잉크 텍스트.
- 오버레이 진입 170ms, 항목 stagger 50ms.
- 헤더 내 모든 인터랙티브 요소 focus-visible 전역 규칙(투명 상태에서는 3px).

### 3. 기능 그리드
- 흰 배경 섹션. 3열 직각 카드(1120px 이상), 갭 0 — 보더 맞붙음(`margin-left: -1px`).
- 카드 구성: 1.75px 아이콘 32px → 키커 → 제목 `1.3rem` → 본문(최대 4줄).
- 카드 내부 패딩 32px, 카드 min-height 280px — 높이 통일.
- 섹션 헤더: 키커 + H2 중앙 정렬, 헤더↔그리드 48px.
- 카드 hover: translate(-3px,-3px) + 잔상 보더, 170ms.
- 6개 카드(3×2) — 2행 사이에도 보더 맞붙음.
- 768px: 2열(마지막 행 2개), 375px: 1열 갭 0 세로 보더 맞붙음.
- 카드 아이콘 색은 잉크 단색 — 오로라 색 아이콘 금지.

### 4. 가격표
- 오로라 3레이어 섹션 배경(중심 좌표 히어로 대비 +15% 이동).
- 흰 직각 가격 카드 3개, 폭 각 4열, 갭 24px, 내부 패딩 32px.
- 카드: 플랜명 키커 → 가격 Clash 600 `clamp(2.2rem,3.5vw,3rem)` → 사양 리스트(행 간 12px, 각 행 앞 잉크 사각 불릿 6px) → CTA.
- 추천 플랜(중앙): 오로라 면 배경 + 잉크 텍스트 + `2px solid #0E0E12` 외곽선 + 상단 잉크 면 라벨 밴드(흰 텍스트 `0.78rem`, 높이 32px).
- 비추천 플랜 CTA는 외곽선 버튼, 추천 플랜 CTA는 솔리드.
- 가격 숫자 아래 기간 라벨 `0.78rem` 잉크 opacity 0.6.
- 375px: 카드 세로 스택 간격 24px, 추천 플랜이 첫 번째로 이동.
- 카드 그리드 상단 섹션 헤더(키커+H2, 잉크) — 오로라 위에서도 잉크 유지.

### 5. 갤러리
- 흰 배경 풀폭. 직각 이미지 타일 6개, 3열 그리드, 갭 12px, 비율 4:3 고정.
- 타일 hover: 오로라 면(3레이어)이 이미지 위로 좌→우 슬라이드 인 170ms + 잉크 캡션 등장.
- 캡션: Clash 600 `1.1rem` + 키커 `0.78rem`, 타일 좌하단 패딩 20px.
- 타일에 잉크 1px 보더 — 갭 12px과 함께 격자 명료.
- 6개 중 2개는 2열 span(가로 와이드) — 직각 유지, 비율 8:3.
- hover 슬라이드는 `transform: translateX(-100%→0)` — opacity 페이드 금지(단호한 슬라이드).
- 768px: 2열 갭 12px, 375px: 1열, 와이드 타일도 1열 폭.
- 키보드 포커스 시 hover와 동일한 오로라 슬라이드 + focus-visible 아웃라인.

### 6. CTA·푸터
- CTA: 풀블리드 오로라 4레이어, 수직 패딩 `clamp(96px,12vw,160px)`, 중앙 정렬.
- CTA 구성: H2(`clamp(1.8rem,3.4vw,3rem)` 잉크) → 리드 1줄 → 버튼 페어(간격 16px), H2↔리드 16px, 리드↔버튼 32px.
- 푸터: 잉크 `#0E0E12` 솔리드 + 흰 텍스트(19.3:1), 수직 패딩 64px.
- 4컬럼(워드마크+소개 / 제품 / 회사 / 법적고지), 컬럼 갭 24px, 헤더 `0.78rem` 대문자 흰색, 헤더↔링크 20px, 링크 행 간 12px.
- 푸터 링크: 흰 `0.95rem` opacity 0.75, hover 시 opacity 1 + 흰 1px 밑줄 0ms.
- 최하단: `1px solid #FFFFFF` opacity 0.2 라인 위 카피라이트 `0.78rem`.
- 푸터 내 focus-visible: `outline: 2px solid #FFFFFF; offset 2px`.
- 375px: 푸터 2열(워드마크 풀폭 + 3컬럼이 2열 랩), CTA 수직 패딩 96px.
