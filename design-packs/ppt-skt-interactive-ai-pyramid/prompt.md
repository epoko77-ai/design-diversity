## 이 스타일의 정체성

한눈에 알아보는 단서: (1) **순백 단일 배경 + SKT Electric Indigo `#0023C3` 1색** — 표지 거대 `DOTHEGOODAI` 글자, 모든 챕터 슬레이트 lettering, 모든 H1, 모든 ▶︎ chip, 모든 차트 강조 막대, 활성 탭이 전부 정확히 이 한 색. SKT Red `#EA002C`는 **표지 SK telecom 로고 워드마크 0.16% 면적에만** 등장하고 본문 절대 금지. (2) **챕터 색 변주 없음** — DO AI · THE AI · GOOD AI · APPENDIX 네 챕터가 모두 동일 블루를 공유, 챕터 식별은 오직 상단 4-탭 네비의 「어느 탭이 활성인지」로만. (3) **AI 피라미드 2.0 3D isometric 3단** — Agentic AI(꼭대기, 흰 면+`#DBE8FA` 좌면) / AIX(중간, `#4B8CE6` 좌면+`#2B65D8` 우면) / AI Infra Super Highway(바닥, `#0023C3` 좌면+`#0010A7` 우면) — 좌·우 두 면이 각각 다른 색으로 isometric 입체감을 만들고, 우측에 `AI B2C·B2B·DC` 흰 정원 배지 3개가 각 단을 가리키며, 바닥 아래 「자강과 협력」 흰 캡슐이 모든 단을 떠받친다. (4) **거대 lettering + ✦ sparkle** — 표지·챕터 슬레이트는 흰 배경에 좌측 정렬된 thin/medium 디스플레이 거대 글자(96~150pt, weight 400~500의 얇은 톤 — Bold/Black 절대 아님)와 그 옆 중간 지점의 ✦ + 가는 가로 헤어라인이 전부. (5) **상단 풀폭 4-탭 PDF 네비게이션** — 모든 본문 페이지 y=0~3.6% 영역에 🏠+☰ 아이콘 + `DO AI · THE AI · GOOD AI · APPENDIX` 4탭 + 우측 `SK Telecom Annual Report 2024 [p.NN]` 메타. (6) **본문 ▶︎ 캡슐 chip** — H1 바로 아래에 진 블루 솔리드 둥근 캡슐 + 흰 한글 라벨 + 우측 끝 ▶︎ 화살표(`거버넌스 ▶︎` `예방 ▶︎` `식별 ▶︎` 등)가 모든 본문 페이지 하위 섹션 시작마다 반복. (7) **차트 3톤 사다리** — 회색 `#595757` + 미디엄 블루 `#4B8CE6` + 진 블루 `#0023C3` 단 세 톤. 무지개·따뜻한 색·녹색·빨강 절대 등장 없음. (8) **하단 풋라인 없음** — 페이지 번호·아카이브 메타는 전부 상단 네비 우측 끝. 본문 페이지 하단 5~8%는 의도적 빈 화이트스페이스.

## 타이포그래피

SK Sans 계열 커스텀 코퍼레이트 sans(라이선스상 사용 불가) → 오픈 대체 **Pretendard**(한글) + **Inter**(영문 보조). mono 폰트 **0건**(deck 전체 mono 미사용).

- **폰트 패밀리:** 본문/디스플레이 전부 `Pretendard`(대체 `Noto Sans KR, Inter, Arial, sans-serif`). 영문 디스플레이도 Pretendard 단일 — Inter 등 별도 영문 폰트 분리 안 함. **mono 폰트 0건** — JetBrains Mono · IBM Plex Mono 류 사용 금지. 모든 작은 텍스트·페이지 번호·각주도 비례 sans.
- **표지 거대 lettering `DO THE GOOD AI`** — Pretendard 500 medium / **96~130pt**(1920×1080 기준 130pt) / 색 `#0023C3` / UPPERCASE / **near-zero kerning**(글자가 거의 붙어 `DOTHEGOODAI` 한 흐름으로 — 단어 사이 띄어쓰기 거의 없음, 자간 -0.04em) / 좌측 정렬 x≈5-7% / 세로 중앙 y≈45-58% / **절대 Bold/Black 아님**.
- **챕터 슬레이트 거대 lettering `DO AI` / `THE AI` / `GOOD AI` / `APPENDIX`** — Pretendard 400~500 thin~medium / **110~150pt**(1920×1080 기준 150pt) / 색 `#0023C3` / UPPERCASE / 자간 normal(표지처럼 붙이지 않음) / 좌측 정렬 x≈4-7% / y≈40-58% / **얇은/미디엄 톤 의무 — Bold/Black 금지**.
- **섹션 H1**(예: `회사 소개` `비즈니스 모델` `경제가치 창출` `사업 소개` `이사회 구성` `ESG Overview` `Business Overview`) — Pretendard 700 Bold / **28~36pt** / 색 `#0023C3` / 좌측 정렬 x≈4-5% / 상단 네비 바 아래 y≈9-12%.
- **서브섹션 H2**(예: `CEO 메시지` `Financial Highlights & Outlook` `ESG 비전(DO THE GOOD AI)` `이사회 중심의 선진 지배구조 구축`) — Pretendard 700 Bold / **16~18pt** / 색 `#000000`(또는 미니 섹션 승격 시 `#0023C3`).
- **▶︎ 캡슐 chip 라벨** — Pretendard 500 Medium / **11~12pt** / 흰 텍스트 on `#0023C3` 둥근 캡슐 채움 + 우측 끝 흰 `▶︎` 글리프 / 캡슐 height 26~30px / border-radius 14~16px / 폭 텍스트 hug(80~180px). 본문 거의 모든 서브섹션 시작 마커.
- **상단 네비 탭 라벨** — Pretendard 500 Medium / **9~10pt** / UPPERCASE / 자간 +0.05em / 활성 `#0023C3` + 1.5pt 같은 색 하단 underline / 비활성 `#595757` + 1px `#EAEAEA` 하단 underline.
- **목차 트랙 헤더**(`DO AI` `THE AI` `GOOD AI` `APPENDIX`) — Pretendard 500 Medium / **28~32pt** / 색 `#0023C3` / UPPERCASE / 위에 ✦ sparkle + 가로 헤어라인.
- **목차 섹션 엔트리** — 좌측 30px 페이지 번호(Pretendard 400 / 10pt / `#000000` 또는 그룹 헤더는 `#0023C3`) + 우측 한글/영문 섹션명(Pretendard 400 / 10pt / `#000000`). 2-column 정렬 (예: `04   Business Overview`).
- **본문 paragraph** — Pretendard 400 Regular / **9~10pt**(작은 편 — 좁은 컬럼에 빽빽) / `#000000` / 행간 1.55 / **신문풍 3~5 narrow 컬럼**(한 컬럼 폭 220~330px on 1920px 캔버스, 16~18% 캔버스 폭).

## 형태 / 질감

모든 다이어그램·박스·캡슐·배지 = 둥근 모서리 또는 정원. 90° 날카로운 사각형은 표 셀 외 전무.

- **모서리 반경:** 작은 chip 4~6px / 캡슐 14~16px / 큰 컨테이너 20~24px / 정원 배지·KPI 카드 50%(원). 단 표 셀과 표 헤더 행만 0px(직각).
- **보더:** 1px 헤어라인 `#D7D7D7`(다이어그램 outline·표 행) 또는 1.5px `#4B8CE6` outline(정원 배지·일부 강조 박스). 보더 굵기 절대 2px 초과 금지.
- **그림자·그라디언트·글로우·블러:** **전면 금지**. AI 피라미드 isometric 입체감도 그림자가 아니라 「좌·우 두 면을 다른 단색으로 칠해서」 만든다. CSS box-shadow / filter blur / radial gradient / linear gradient 일체 금지.
- **AI 피라미드 isometric 입체:** 6개 flat color face — 꼭대기 단(흰 우면+`#DBE8FA` 좌면) / 중간 단(`#4B8CE6` 좌면+`#2B65D8` 우면) / 바닥 단(`#0023C3` 좌면+`#0010A7` 우면). 각 면은 평면 단색, 그라디언트 아님. 단 사이 0.5pt 헤어라인 분리.
- **아이콘:** 1.5pt 가는 라인 단색(`#595757` 슬레이트 또는 `#4B8CE6`). 그림 채움·여러 색·이모지 금지. 정원 배지 안의 아이콘도 모두 thin-line.
- **이미지·사진:** 본문 50p 중 5~7회 등장. 모두 푸른 톤 보정(글로벌 네트워크 지도·데이터센터 글래스 인테리어·제품 사진·AI brain holographic). 일러스트·클립아트·플랫 일러스트 금지.
