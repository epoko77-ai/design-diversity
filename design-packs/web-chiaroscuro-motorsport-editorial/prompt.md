# 키아로스쿠로 모터스포츠 에디토리얼 — web 디자인 팩

spec_version: v3.1-2026-08-16

## 이 스타일의 정체성
순흑 면과 순백 면이 페이지를 엣지투엣지로 극적 분할(키아로스쿠로 명암 대비)하고, 그 위에 큰 에디토리얼 세리프 헤드라인과 좁은 본문 칼럼이 모터스포츠 매거진처럼 밀도 있게 앉으며, 레이싱 레드는 페이지 전체에 단 한 번만 찍히는 사이트다. 무엇을 보면 이 스타일임을 아는가 — 흑/백 영역이 흐릿한 그레이 없이 순흑·순백 고대비로 화면 끝까지 맞물린다, 헤드라인은 디스플레이 세리프인데 본문은 좁고 빽빽한 그로테스크 칼럼이다, 레드 한 점이 페이지에 딱 한 번 등장해 시선을 못박는다, 트랜지션은 100–150ms로 짧고 단호하다.

## 색
- 블랙 필드: `#0A0A0A`. 화이트 필드: `#FFFFFF`. 중간 그레이 배경 절대 금지.
- 본문 잉크(화이트 필드 위): `#1A1A1A`. 블랙 필드 위 텍스트: `#FFFFFF`.
- 메타·캡션: 블랙 필드 위 `#C4C4C4` / 화이트 필드 위 `#6A6A6A`.
- 강조: 레이싱 레드 `#D40000` — 페이지 전체에 **단 한 번만**. 키워드 하이라이트 1개 또는 1px 표시선 하나. 적용 면적 0.5% 이하. 두 번 이상 절대 금지.
- 색 역할 면적 배분: 흑 필드 40–65%, 백 필드 35–60%(섹션마다 비율 상이), 레드 0.5% 이하.
- 대비 실측: `#FFFFFF` on `#0A0A0A` ≈ 19.4:1 (AAA). `#1A1A1A` on `#FFFFFF` ≈ 17.4:1 (AAA). `#C4C4C4` on `#0A0A0A` ≈ 11.1:1. `#6A6A6A` on `#FFFFFF` ≈ 5.4:1 (AA).
- 레드 `#D40000` on `#FFFFFF` ≈ 5.5:1 (AA) — 화이트 필드 위에서만 텍스트 허용. 블랙 필드 위 레드는 ≈ 3.5:1 — 1px 표시선·장식만, 텍스트 금지.

## 타이포그래피
- 디스플레이: `Newsreader`(Google Fonts) weight 600, 대체 `Georgia, 'Times New Roman', serif`. H1 `clamp(2.6rem, 5vw, 4.6rem)`, line-height 1.05, `letter-spacing: -0.015em`.
- 거대 인덱스/이슈 번호: `Newsreader` 600, `clamp(3rem, 8vw, 7rem)`, line-height 1.
- 본문: `Inter`(Google Fonts) weight 400, `0.95rem`, line-height 1.55, 측정 48–58자 — 좁고 빽빽한 매거진 칼럼. 칼럼 폭 `300–360px`.
- 키커/섹션 라벨: `Inter` weight 700, `0.7rem`, 대문자, `letter-spacing: 0.18em`.
- 캡션/크레딧: `Inter` `0.72rem`, weight 400, italic 허용.
- 사용 가능한 텍스트 크기 집합(이외 금지): `0.7rem / 0.72rem / 0.95rem / 1.2rem / clamp(2.6rem,5vw,4.6rem) / clamp(3rem,8vw,7rem)`.
- 웨이트 집합: Newsreader 600 / Inter 400·700만. 중간 웨이트(500·600 Inter) 금지 — 위계는 크기·대비로.

## 레이아웃 / 그리드
- 풀블리드 — content_max 없음(데스크탑 1280px 뷰포트 기준). 흑/백 면이 화면 끝까지 맞물림. 텍스트는 면 내부 패딩 `clamp(24px, 5vw, 80px)`.
- 브레이크포인트: `768px`, `1120px`.
- 섹션마다 흑/백 비대칭 분할 — 비율은 섹션마다 다르게(예: 58/42, 50/50, 40/60). 같은 비율 연속 2회 금지.
- 밀도 높은 위계 — dense. 본문 칼럼은 한 면 안에 1–2칼럼, 칼럼 간 거터 32px.
- **명암 면 완결 — 평면 보이드 금지.** 흑 면이 비면 거대 인덱스 번호(`clamp(3rem,8vw,7rem)`)·dense 텍스트 칼럼·1px 라인 디테일로, 백 면이 비면 풀블리드 그레이스케일 이미지 또는 dense 텍스트 칼럼으로 채운다.
- **간격 리듬:** 8px 베이스 스케일. 키커↔헤드라인 12px, 헤드라인↔본문 20px, 본문 칼럼 거터 32px, 캡션 위 8px. dense하되 간격은 일관.

## 반응형 (뷰포트별 값)
- 375px: 흑/백 분할은 좌우 → 상하 스택으로 전환(흑 상단·백 하단), 면 내부 패딩 `24px`, 본문 1칼럼, 인덱스 번호 실효 ≈ 3rem.
- 768px: 좌우 분할 복귀, 내부 패딩 ≈ `38px`(5vw), 본문 1–2칼럼, 갤러리 2열.
- 1280px: 내부 패딩 `64–80px`, 본문 2칼럼, 갤러리 3열, 인덱스 번호 실효 ≈ 7rem.
- 히어로 min-height: 375px `100vh`, 1280px `90vh`.
- 기록 테이블은 768px 미만에서 가로 스크롤(`overflow-x: auto`).

## 형태 / 질감
- 보더 거의 없음 — 흑/백 면 경계 자체가 구획 장치. 필요 시 1px 라인 하나(흑 위 `#C4C4C4` / 백 위 `#1A1A1A`).
- 모서리 radius `0px` 전역. `box-shadow: none` 전역.
- 이미지: 그레이스케일(`filter: grayscale(1) contrast(1.1)`) 고정, radius 0px, `object-fit: cover`, 면에 꽉 차게. 비율은 면 분할을 따름(자유).
- 아이콘: 1px 스트로크 라인 20px 박스, 모터스포츠 모티프(체커기·랩타임·계기)만, 최소한으로. 면 아이콘·이모지 금지.
- 버튼: 흑 위 → 흰 솔리드 + 흑 텍스트 / 백 위 → 흑 솔리드 + 흰 텍스트. 모서리 0px, 패딩 `12px 28px`, Inter 대문자 `0.8rem` letter-spacing 0.1em.

## 상태
- default: 버튼 명도 반전쌍(흑↔백), 보더 없음.
- hover: 버튼 흑↔백 즉시 반전 110ms. 갤러리 이미지 `grayscale(1)→grayscale(0)` 130ms. 링크 밑줄 opacity 0→1 즉시(드로우 금지).
- focus-visible: 흑 필드 위 `outline: 2px solid #FFFFFF`, 백 필드 위 `outline: 2px solid #1A1A1A`, offset 2px.
- active: 버튼 opacity 0.85, 80ms.
- 내비 현재 항목: 하단 1px 흰 인디케이터 상시.

## 모션
- 전환: `snappy` — `120ms cubic-bezier(0.3, 0, 0.2, 1)`. 대상: color·background·opacity·filter·clip-path.
- 스크롤 진입: 흑/백 면이 `clip-path: inset()` 와이프 140ms — 명암 면이 단호하게 자리잡음. 텍스트는 `opacity 0→1` 120ms, stagger 40ms.
- 진입 트리거: 요소 상단이 뷰포트 20% 지점(`IntersectionObserver threshold 0.2`).
- 스크롤 거동: 헤더 `position: sticky; top: 0`. 패럴랙스 금지.
- `prefers-reduced-motion: reduce`: 면 와이프·필터 전환 제거, opacity 120ms만.
- 느린 페이드(200ms 초과)·바운스·1초 이상 모션 금지 — 모터스포츠다운 단호함.

## 컴포넌트
- **헤더/내비:** 높이 60px, 블랙 필드 `#0A0A0A`, 하단 `1px solid #C4C4C4`. 좌측 워드마크(Newsreader 600 `1.2rem`), 우측 메뉴(Inter 700 대문자 `0.7rem`, 항목 간격 24px).
- **스토리 블록:** 면 분할 안에 거대 인덱스 번호 + Newsreader 헤드라인 + 키커 + 좁은 Inter 본문 칼럼. 키커↔헤드라인 12px, 헤드라인↔본문 20px.
- **거대 인덱스 번호:** Newsreader 600 `clamp(3rem,8vw,7rem)` — 흑 면 위 `#C4C4C4` opacity 0.85, 헤드라인과 겹치거나 면 한 구석에.
- **갤러리 카드:** 그레이스케일 이미지 + 하단 캡션 바(반대 명도 면, 높이 48px). hover 시 grayscale 해제 130ms.
- **기록 테이블:** 행 구분 1px 라인, 행 높이 44px, Inter tabular-nums, 헤더행 반전 명도. 우승 행 1개만 좌측 2px 레드 표시선(레드 단 한 번 사용처일 때).
- **버튼:** 형태 절의 반전쌍 규칙. 패딩 `12px 28px`, 모서리 0px.

## 하지 말 것
- 레이싱 레드를 두 번 이상 쓰기 금지 — 페이지 전체 단 한 점.
- 흑/백 분할을 그레이로 약화 금지 — 순흑 `#0A0A0A` / 순백 `#FFFFFF` 고대비.
- 둥근 카드·그라디언트·이모지·box-shadow 금지.
- content_max 박스로 콘텐츠 가두기 금지 — 흑/백 면은 엣지투엣지.
- 본문 칼럼 60자 초과 금지 — 좁고 빽빽한 매거진 칼럼.
- 컬러 사진 금지 — 그레이스케일/하이콘트라스트만(호버 해제 순간만 예외).
- 느린 페이드(>200ms)·패럴랙스 금지 — 모션은 snappy.
- 헤드라인에 산세리프 금지 — Newsreader 세리프.
- 평면 단색 데드 보이드 금지 — 빈 흑 면은 거대 인덱스·dense 텍스트로, 빈 백 면은 그레이스케일 이미지로.
- 빈 플레이스홀더 채움 블록 금지 — 이미지 면에는 실제 그레이스케일 이미지를 담는다.
- 길 잃은 떠다니는 요소 금지 — 모든 요소는 면 내부 패딩 정렬축에 묶인다.
- 정체성 약화 금지 — 순흑·순백 면 분할과 에디토리얼 세리프 위계가 모든 페이지에서 또렷해야 한다.
- 중앙정렬 균일 카드 그리드·보라 그라디언트 등 기본 AI 미감 금지.

## 상세 페이지 (6종)
전역 규칙(색·타이포·상태·모션)은 위를 상속한다. 아래는 각 페이지 고유 값만 적는다.

### 1. 히어로 (흑백 분할)
- min-height 90vh를 좌 58% 블랙 / 우 42% 화이트로 비대칭 분할, 경계는 수직선(사선 금지).
- 블랙 필드 내부 패딩 `clamp(24px,5vw,80px)`, 콘텐츠 좌측 정렬.
- 콘텐츠 스택: 키커(Inter 700 `0.7rem` `#C4C4C4`) → H1(Newsreader `clamp(2.6rem,5vw,4.6rem)` `#FFFFFF`) → 본문(48–58자, `#C4C4C4`) → 흰 솔리드 CTA(패딩 `12px 28px`).
- 키커↔H1 12px, H1↔본문 20px, 본문↔CTA 32px.
- H1 키워드 1개에만 레이싱 레드 `#D40000` — 페이지 유일 레드.
- 블랙 필드 우상단 구석에 거대 이슈 번호(`clamp(3rem,8vw,7rem)`, `#C4C4C4` opacity 0.5).
- 화이트 필드: 풀블리드 그레이스케일 이미지(`grayscale(1) contrast(1.1)`, `object-fit: cover`)가 면 100% 채움.
- 이미지 부재 시: 화이트 필드에 dense 2단 텍스트 칼럼(각 48자) 또는 거대 인덱스로 채움 — 빈 백 면 금지.
- 진입: 흑/백 면 clip-path 와이프 140ms → 텍스트 opacity 120ms, 40ms stagger.

### 2. 헤더·내비게이션
- 높이 60px 블랙 필드, 하단 `1px solid #C4C4C4`, `position: sticky; top: 0`.
- 좌측 워드마크: Newsreader 600 `1.2rem` `#FFFFFF`.
- 우측 메뉴 5개: Inter 700 대문자 `0.7rem` letter-spacing 0.18em `#FFFFFF`, 항목 간격 24px.
- 메뉴 hover: 텍스트 아래 4px 지점에 1px 흰 인디케이터 즉시 등장(110ms 이내).
- 현재 페이지: 인디케이터 상시 + 텍스트 유지.
- 모바일(<768px): 메뉴 숨김, 우측 20px 햄버거(1px 스트로크 라인 2개, 간격 7px).
- 모바일 드로어: 풀스크린 `#0A0A0A`, 메뉴 행 높이 64px, 행 구분 1px `#C4C4C4` opacity 0.3, Newsreader `1.6rem`.
- 좌우 패딩 `clamp(24px,5vw,80px)` — 본문 면 패딩과 정렬.

### 3. 헤리티지 스토리 콘텐츠
- 화이트 필드 풀폭, 상하 패딩 `clamp(64px,8vw,112px)`.
- 상단 풀폭 그레이스케일 이미지 밴드: 높이 `clamp(240px,38vh,420px)`, `object-fit: cover`.
- 밴드 아래 32px부터 본문 구역: 좌측 폭 30%에 거대 이슈 번호(`clamp(3rem,8vw,7rem)` `#1A1A1A`) + 키커(12px 아래).
- 우측 폭 70%: Newsreader 헤드라인(`clamp(2.6rem,5vw,4.6rem)`) + 2칼럼 Inter 본문(각 48자, 거터 32px).
- 본문 칼럼 사이 1px `#1A1A1A` 세로 구분 룰.
- 헤드라인↔본문 20px, 단락 간 16px — dense.
- 캡션: 이미지 밴드 아래 8px, Inter `0.72rem` italic `#6A6A6A`.
- 이 페이지에서 레드 사용 금지(히어로에서 소진) — 재사용 시 히어로 레드 제거.

### 4. 모델 갤러리
- 블랙 필드 풀폭, 상하 패딩 `clamp(64px,8vw,112px)`.
- 3열 그리드(768px 미만 1열, 768–1120px 2열), 갭 `2px` — 면이 거의 맞붙는 매거진 조판.
- 각 카드: 그레이스케일 이미지 비율 4:3, radius 0px.
- 카드 하단 캡션 바: 화이트 필드 `#FFFFFF`, 높이 48px, 좌측 모델명(Newsreader 600 `1.2rem` `#1A1A1A`) + 우측 연식(Inter tabular `0.95rem` `#6A6A6A`), 좌우 패딩 16px.
- hover: 이미지 `grayscale(1)→grayscale(0)` 130ms — 컬러가 순간 드러나는 유일한 장치.
- 섹션 헤더: 키커 + Newsreader H2, 그리드와 40px 간격, `#FFFFFF`.
- 카드 진입: opacity 0→1 120ms, 카드 간 40ms stagger.
- 이미지 부재 카드: 흑백 대비 타이포 카드(거대 인덱스 번호 + 모델명)로 대체 — 빈 회색 타일 금지.

### 5. 레이스 기록·인용
- 상 50% 블랙 / 하 50% 화이트 수평 분할.
- 블랙 영역: Newsreader 인용문 2–3줄(`clamp(1.8rem,3vw,2.6rem)` `#FFFFFF`, 폭 상한 720px) + 출처 라벨(Inter 대문자 `0.7rem` `#C4C4C4`, 인용문 아래 16px).
- 인용부호는 Newsreader 거대 글리프(`clamp(3rem,8vw,7rem)`, `#C4C4C4` opacity 0.4)로 인용문 좌상단에.
- 화이트 영역: 기록 테이블 8행 내외, 행 높이 44px, 행 구분 `1px solid #1A1A1A`.
- 테이블 열: 연도(Inter tabular) / 대회(Newsreader) / 기록(Inter tabular 우측 정렬) / 순위.
- 헤더행: `#0A0A0A` 배경 + `#FFFFFF` 텍스트, Inter 700 대문자 `0.7rem`, 높이 40px.
- 우승 행 1개: 좌측 2px `#D40000` 표시선 — 히어로에서 레드 미사용 시에만.
- 양 영역 내부 패딩 `clamp(24px,5vw,80px)`, 테이블 폭 상한 880px.

### 6. CTA·푸터
- CTA: 블랙 필드 풀폭, 상하 패딩 `clamp(80px,10vw,128px)`, 중앙 정렬(이 팩에서 유일한 중앙축).

- 푸터: 화이트 필드, 상단 `1px solid #1A1A1A`, 상하 패딩 64px/32px.
- 4컬럼(워드마크 / 라인업 / 헤리티지 / 법적고지), 컬럼 간 거터 32px, 768px 미만 2열 스택.
- 컬럼 헤더: Inter 700 대문자 `0.7rem` `#1A1A1A`, 헤더↔첫 링크 12px.
