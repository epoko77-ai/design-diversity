# Kula 미니멀리스트 키노트 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 본 문서의 px 좌표는 1280×720 캔버스 기준이며 렌더 해상도에 비례 확대한다. Kula 미니멀리스트 키노트 — 따뜻한 샌드 배경에 둥근 모서리(16~24px) 이미지 프레임이 모듈러 블록 그리드로 정렬되고, 작은 산세리프 캡션이 도록처럼 단정한 차분한 룩북/포트폴리오 키노트. 더스티 뉴트럴 톤, dusty clay 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 따뜻한 샌드 `#EDE8E0` 배경에 둥근 모서리(16~24px) 이미지 프레임 — 이미지가 모듈러 블록 그리드로 갤러리처럼 정렬, (2) 채도 낮은 더스티 뉴트럴 색만 — 채도 높은 색 일절 없음, (3) 작은 산세리프 캡션이 미술 도록처럼 단정하고 여백이 넓다. 부드럽고 차분한 룩북. 여백이 정체성이므로 여백의 크기·리듬은 아래 수치로 고정한다.

## 색 (역할·면적 상한 포함)
- 배경 샌드 `#EDE8E0` — 캔버스 기본 채움
- 표면(이미지 프레임·카드) `#FFFFFF`
- 따뜻한 잉크 `#4A4540`
- 강조 dusty clay `#B79B86` — 캡션 강조·작은 라벨·룰·차트 강조 1계열에만. 노출 면적 합계 슬라이드의 5% 이하
- 캡션 `#8C857C`
- 차트 더스티 데이터 계열: 연 `#D3CABF` / 진 `#8C857C`
- 듀오톤 톤 필드: 샌드 `#EDE8E0` ↔ dusty clay `#B79B86` 사이 미세 톤차(채도 그대로, 명도 차 ≤12%)
- 델타 표기: 상승 clay `#B79B86`·하락 잉크 `#4A4540`, 부호 +/− 명기
- 사진은 더스티 톤 정합: 채도 -10~-20% 낮춰 배경과 어울리게
- 강조색은 dusty clay 1개뿐. 채도 높은 색·화려한 그라디언트 금지(듀오톤 톤 필드만 예외)
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 전부 `Plus Jakarta Sans`(대체 `Hanken Grotesk, Helvetica Neue, sans-serif`). 한글은 `Pretendard`.
- 허용 크기 집합: {11, 12, 14, 16, 18, 20, 24, 28, 34, 44}pt — 이 집합 밖의 임의 크기 사용 금지
- 슬라이드 헤딩: 34pt / 600 / 자간 -1% / 행간 1.2 / 최대 2줄 (표지 타이틀만 44pt)
- 부제: 20pt / 400 / 색 따뜻한 잉크
- 본문: 18pt / 400 / 행간 1.5 / 슬라이드당 6줄 이하
- 미니헤더·근거·델타: 14pt / 400~600
- 콜아웃 인사이트: 16pt / 500
- 도록 캡션: 12pt / 500 / 자간 +4% / 색 캡션 `#8C857C`
- 작은 라벨: 11pt / 600 / 자간 +8% / 대문자 / 색 dusty clay
- 블록 메트릭: 28pt / 600 / tabular, 풀쿼트: 24pt / 600
- KPI 대형 수치: 44pt / 600 / tabular numerals
- 행간 집합: 헤딩 1.2 / 본문 1.5 / 캡션 1.4 / 수치·KPI 1.0 — 그 외 행간 금지
- 페이지 번호 형식: `03 / 12` — 12pt tabular

## 레이아웃 / 그리드 (여백을 수치로 고정)
- **모듈러 블록 그리드(airy) + 고정 안전 여백.** 콘텐츠 안전 여백 좌·우·상 각 72px(콘텐츠 폭 1136px, x=72~1208), 하단 풋라인 baseline y=664(하단에서 56px) 고정 — 모든 슬라이드 동일.
- 12열 그리드를 큰 블록 모듈로 묶어 배치: 6:6 분할(경계 x=640) 또는 4:4:4. 모듈 사이 거터 0.3in — 이 거터가 이 팩의 여백 리듬이며 임의 확대·축소 금지.
- 둥근 모서리 이미지 프레임을 2~6개 블록 그리드로 정렬(갤러리/룩북 페이지). 캡션은 프레임 하단 +20px에 12pt로 도록처럼 단정하게.
- **타이틀 baseline·풋라인 고정:** 헤딩 baseline은 덱 전체 y=140 통일(표지·클로징 예외), 풋라인(도록 캡션 + 페이지 번호)은 baseline y=664. 텍스트 좌측 엣지 덱 전체 동일 x=72, 수직 리듬 24/32/48px 스텝.
- **밀도 원칙(절제 ≠ 빈약):** 차분한 톤을 유지하되 둥근 흰 카드 모듈 **3개 이상**을 모듈러 그리드에 정렬해 본문 슬라이드는 캔버스 82% 이상, 표지·간지·갤러리는 70% 이상을 채운다. "거대한 샌드 여백에 카드 하나"는 금지(표지·간지 예외).
- **구성 균형 — 죽은 공백 금지:** 캔버스의 어느 한 영역도 ~20%를 넘게 비우지 않는다. 여백은 모듈 사이 0.3in 거터로 의도적으로 분산하고 한 구석(특히 우측)에 거대한 빈 샌드 면이 고이지 않게 한다. 떠다니는(off-grid) 요소 금지 — 모든 모듈이 12열 그리드에 스냅.
- **이미지/비주얼 프레임은 실제 비주얼을 담는다:** 실제 사진, 듀오톤 톤 필드 + 12pt 도록 캡션 라벨, Kula풍 차트(더스티 막대·도넛), 또는 다이어그램. **평면 단색 빈 베이지/샌드 블록 절대 금지** — 누락 에셋·미완성처럼 보인다.
- **도록 콜아웃 카드:** 둥근 흰 카드(반경 16px) + 11pt 대문자 clay 라벨 + 16pt 인사이트 1~2줄. 카드 높이는 내용 높이 + 패딩 0.22in — 하단 절반이 비지 않는다. 차트·본문 옆에 1개.
- 대문자 clay 라벨: 자간 +0.08~0.12em / 11pt 일관
- 모든 본문성 슬라이드: 좌하단 도록 출처 캡션 12pt + 우하단 페이지 번호 12pt를 풋라인 baseline y=664에 정렬
- 수치는 tabular figures 우정렬, 소수 자릿수·단위 일관, 강조 셀/행은 슬라이드당 1개만

## 형태 / 질감
- 이미지 프레임만 둥근 모서리: 큰 프레임 20~24px·작은 프레임 16px radius. 텍스트 박스는 보더 없음·모서리 0px.
- 카드·다이어그램 노드 radius 집합: {12px(노드·적층), 16px(카드), 20~24px(이미지 프레임)} — 그 외 radius 금지.
- 그림자: 없거나 아주 옅게 — offset 0 / blur 0~4px / alpha 4% 이하.
- dusty clay 룰 굵기: 카드 상단·좌측 0.08in 고정.
- 아이콘은 1.5pt 가는 라인 단색 더스티, 24×24px. 풀블리드 사진 금지(이미지는 둥근 프레임 안에).

## 차트·데이터 시각화 (룩북 차트 — 더스티 뉴트럴 + clay 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 차분한 룩북 미감.
- **데이터 색:** 막대·선 기본 `#D3CABF`(연) / `#8C857C`(진). 강조 1개만 dusty clay `#B79B86` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 4px(차트 막대만 살짝 둥글게). 베이스라인 0(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 2~3개 0.5pt `#D3CABF`). 차트 테두리 박스 제거. x축선 0.75pt `#8C857C`.
- **값 레이블:** 막대 상단·꼭짓점 위 8px 직접 표기, 14pt Plus Jakarta Sans 600 tabular. 범례 박스 금지 — 직접 라벨링.
- **라인 차트:** 1.5pt clay 폴리라인, 면적 채움 없음, 강조 시점만 지름 8px clay 원 마커.
- **도넛:** 1개만, 외경 240px·링 두께 40px·조각 3개 이하. 파이 다중·3D 금지.
- **미니 스파크라인:** 폭 120px·높이 24px·1.5pt 더스티 라인(KPI 카드 안).
- **가로 막대(순위):** 막대 높이 32px·간격 20px·모서리 4px, 라벨 좌측 14pt·값 우측 14pt tabular.
- **축 카테고리 라벨:** x축 아래 +16px, 12pt `#8C857C` — 회전 금지(길면 축약).
- **출처:** 차트 하단 좌측 12pt Plus Jakarta Sans `#8C857C` 출처·단위 각주.

## 다이어그램·컴포넌트 (룩북 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 둥근 모서리(12~16px) 흰 카드, 보더 없음 또는 아주 옅은 그림자, 커넥터는 1.5pt 부드러운 직선(화살촉 8×8px), 단계 번호는 0.3in clay 원, 강조는 clay 텍스트·0.08in 룰.
- **프로세스 플로우:** 좌→우 둥근 카드 노드 4~5단계(반경 12~16px·각 폭 190~220px·높이 100px, 흰 채움) — 1.5pt 커넥터. 각 노드 좌상단 0.3in clay 원 단계 번호(번호 12pt 흰색). 핵심 단계만 좌측 0.08in clay 룰.
- **타임라인:** 수평 축 0.75pt `#8C857C`. 마일스톤 0.12in 더스티 원(현재 시점만 clay 솔리드). 날짜 라벨 12pt 도록 캡션체.
- **비교(2~3열):** 둥근 카드 칼럼(반경 16px, 흰 채움) — 칼럼 사이 0.5in 간격, 보더 없음. 헤더 11pt 대문자 clay. 우세 칼럼만 상단 0.08in clay 룰.
- **매트릭스 2×2:** 0.75pt 더스티 십자축. 사분면 라벨 12pt 도록 캡션체. 데이터 포인트 0.14in 더스티 원(핵심만 clay 솔리드).
- **계층/퍼널:** 둥근 사각 적층(반경 12px·각 단 높이 64px), 폭 비례 — 더스티 명도 단계, 핵심 단만 clay. 레벨 라벨 우측 18pt.
- **KPI·스탯 카드:** 둥근 흰 카드(반경 16px), 11pt 대문자 clay 라벨 + 44pt 600 따뜻한 잉크 수치 + 14pt 델타. 카드 3~4개 가로 균등, 거터 0.3in.
- **목차 컴포넌트:** 0.3in clay 원 번호 + 18pt 항목명, 항목 사이 넓은 간격(0.4in).
- **섹션 디바이더:** 샌드 배경 + 둥근 이미지 프레임 1점 + 34pt 섹션명 + 11pt clay 섹션 번호.
- **인용:** 둥근 흰 카드(반경 16px) + 24pt 600 풀쿼트(최대 3줄) + 12pt 도록 출처 캡션.

## 전환 (PPT)
subtle — 둥근 이미지 프레임·카드가 200ms ease-out으로 부드럽게 페이드 인하는 정도만. 슬라이드·바운스 모션 금지.

## 하지 말 것
- 채도 높은 색 금지 — 더스티 뉴트럴만(채도 높은 색은 다른 팩의 자리).
- 풀블리드 사진 금지 — 이미지는 둥근 모서리 프레임 안에(풀블리드는 warm-hospitality의 자리).
- 짙은 그림자·글로우·화려한 그라디언트 금지(그림자는 blur ≤4px·alpha ≤4%만).
- 강조색 2개 이상 금지 — dusty clay 한 톤, 노출 면적 5% 이하.
- 허용 크기 집합 {11~44}pt·radius 집합 {12/16/20~24px} 밖의 임의 값 금지.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.
- **거대한 샌드 여백에 카드/차트 하나만 두고 비우기 금지(표지·간지·갤러리 예외).** 절제 ≠ 빈약 — 본문/비교/차트 슬라이드는 둥근 카드 모듈 3개 이상.
- **빈 플레이스홀더 블록 절대 금지** — 프레임은 반드시 실제 사진·듀오톤 톤 필드·차트·다이어그램을 담는다.
- **캔버스 한 구석에 죽은 샌드 공백 금지** — 여백은 모듈 사이 0.3in 거터로 분산.
- **헤드라인 문장 중간 단어 비대 금지** — 헤딩은 일관 크기, 강조는 clay 색·굵기로.
- **안전 여백 72px·풋라인 baseline y=664·타이틀 baseline y=140 드리프트 금지.**

## 상세 페이지 (7종)
전역 규칙(색·타이포·그리드·풋라인)은 상속한다. 아래는 각 페이지 고유의 좌표·구성만 기술한다(1280×720 기준).

### 01 · 표지 (cover)
- 6:6 분할 — 좌 콘텐츠 x=72~616 / 우 이미지 프레임 x=664~1208
- clay 대문자 라벨 11pt(자간 +0.1em): baseline y=170
- 타이틀 44pt 600: 첫 줄 baseline y=280, 최대 3줄(줄 간격 60px)
- 부제 20pt: 타이틀 마지막 baseline +48px
- 도록 메타 스트립(`STUDIO`·`DATE`·`EDITION`): 12pt 캡션체 3셀, 셀 간격 32px, baseline y=560
- 우측 이미지/비주얼 프레임 1점: 544×576px(y=72~648), radius 20px — 실제 사진 또는 듀오톤 톤 필드 + 12pt 캡션 라벨, 빈 단색 블록 금지
- 하단 도록 메타 캡션 12pt + 페이지 번호 12pt: baseline y=664
- 표지는 절제 허용 — 캔버스 채움률 ≥70%, 여백은 좌 콘텐츠와 프레임 사이 48px 거터로 분산

### 02 · 목차 (agenda)
- clay 라벨 11pt baseline y=104 → 헤딩 `Contents` 34pt 600 baseline y=140
- 좌측 7열 x=72~734: 목차 5항목, 행 높이 64px + 행 간격 0.4in, y=200부터 적층
- 항목 구성: 0.3in clay 원 번호(번호 12pt 흰색) → 18pt 항목명 → 12pt 캡션 설명 1줄 → 우측 끝 페이지 번호 12pt tabular 우정렬
- 현재 섹션: 좌측 0.08in clay 룰(진행 인디케이터), 강조 1항목만
- 우측 5열 x=760~1208: 둥근 흰 카드(반경 16px·패딩 0.22in), y=200~620
- 카드 내부: 덱 한 줄 요지 18pt 2줄 + 둥근 이미지/비주얼 프레임 1점(폭 384px·높이 240px·radius 16px, 사진 또는 듀오톤 필드 + 라벨)
