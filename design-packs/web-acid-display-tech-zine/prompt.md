# 애시드 디스플레이 테크 진 — web 디자인 팩

spec_version: v3.1-2026-08-16 · reference_mode: style_synthesis

## 이 스타일의 정체성
거의 검정인 짙은 캔버스 위에서 애시드 민트와 울트라바이올렛이 듀오로 충돌하고, 굵은 디스플레이 활자가 헤드라인을 포스터처럼 짜며, 요소가 의도적으로 어긋난 비대칭 진(zine) 레이아웃의 테크 매거진 사이트다. 무엇을 보면 이 스타일임을 아는가 — 강조색이 하나가 아니라 애시드 민트 + 울트라바이올렛 두 색이 충돌하며 활기를 낸다, 헤드라인이 굵은 디스플레이로 포스터처럼 크다, 요소가 그리드에 정렬되지 않고 의도적으로 어긋나 진(zine)처럼 거칠다, 트랜지션이 120–180ms로 빠르고 단호하다.

## 색 — 역할·대비 실측
- 배경 `#101014` (near-black). 패널 `#1B1B22`.
- 텍스트 `#ECECEC`: on `#101014` = 16.1:1 / on `#1B1B22` = 14.5:1 (AAA). 보조 `#8A8A95`: 5.6:1 (AA) — 메타·캡션용.
- 애시드 민트 `#4FFFB0`: on `#101014` = 14.7:1 — 텍스트·보더·면 모두 허용. 민트 면 위 텍스트는 `#101014`(14.7:1).
- 울트라바이올렛 `#7C4DFF`: on `#101014` = 3.9:1, on 패널 = 3.6:1 — **large text 전용**(`1.5rem` 이상, 3:1 통과). `1.5rem` 미만 바이올렛 텍스트 금지. 보더·하드 오프셋·면으로는 자유.
- 바이올렛 면 위 텍스트는 `#FFFFFF`(4.8:1, AA).
- **듀오 강제:** 민트와 바이올렛은 모든 페이지에 함께 등장 — 사용 비율 민트:바이올렛 = 40:60 ~ 60:40 범위. 한 색 독주 금지.
- 위 6색 외 hex 0개. 그라디언트·라디얼 글로우 0건.
- 듀오톤 이미지: 섀도→ `#7C4DFF`, 하이라이트→ `#4FFFB0`, 채도 +10%.

## 타이포그래피 — 크기 집합 고정
- 디스플레이: `Clash Display`(Fontshare) weight 700, 대체 `'Arial Black', Helvetica, sans-serif`.
- 본문·UI: `Inter`(Google Fonts) weight 400·700, 대체 `sans-serif`. 이 2 family 외 금지.
- H1: `clamp(2.8rem, 6vw, 5.5rem)`, line-height 0.98, letter-spacing `-0.02em`.
- 거대 인덱스/이슈 번호: `clamp(3rem, 8vw, 7rem)`, Clash 700, 민트/바이올렛 듀오 배색(둘 다 large — 대비 통과).
- H2/기사 제목: `clamp(1.8rem, 3.6vw, 3rem)`, Clash 700, line-height 1.02.
- 카드 제목: `1.35rem`, Clash 700, line-height 1.1.
- 본문: `1rem`, Inter 400, line-height 1.6, 측정 56–66자.
- 키커/라벨: `0.74rem`, Inter 700, 대문자, letter-spacing `0.14em` — 색은 민트 또는 `#ECECEC`(바이올렛 금지 — 소형 대비 미달).
- 크기 집합은 위 6단만. 그라디언트 텍스트 0건.

## 반응형 — 브레이크포인트별 값
- CSS 브레이크포인트 2개: `768px`, `1120px`.
- 375px 뷰포트: 1열 스택, 좌우 패딩 20px, 섹션 수직 72px, 회전 어긋남 -1.5~1.5°로 완화, 거대 인덱스 `clamp(2.4rem,14vw,4rem)`.
- 768px 뷰포트: 2열 시작, 좌우 패딩 40px, 섹션 수직 ≈88px, 카드 그리드 2열.
- 1280px 뷰포트: content_max 1280px, 좌우 패딩 56px, 섹션 수직 104px, 카드 그리드 3열 + 풀 어긋남(-3~3°).
- 어긋남 오프셋: 데스크탑 최대 48px, 모바일 최대 16px — 뷰포트 밖 가로 스크롤 0.

## 레이아웃 / 그리드 — zine 문법
- 콘텐츠 최대 폭 `1280px`, 12열 베이스, 거터 24px. 섹션 수직 리듬 `clamp(72px, 8vw, 104px)`.
- 의도적 어긋남 3종: ① 컬럼 경계 이탈 최대 48px ② 요소 겹침 16–40px ③ 회전 -3~3°(0.5° 단위) — 섹션당 어긋난 요소 2–4개, 전부 어긋나면 소음.
- 간격 스케일: 8px 베이스. 키커↔헤드라인 12px, 헤드라인↔리드문 20px, 리드문↔버튼 24px.
- 빈 near-black 면 처리: 거대 인덱스 번호 / 듀오톤 이미지 패널 / 태그 칩 그룹(2–3개) / 옅은 zine 도트 패턴(2px 도트, 간격 24px, opacity 0.06) 중 1개 이상 — 평면 보이드 0.
- 겹침 레이어 z-순서: 이미지(0) < 인덱스 번호(1) < 헤드라인(2) < 칩(3).

## 형태 / 질감
- 보더: 1–2px, `#4FFFB0` 또는 `#7C4DFF` — 한 화면 안에서 듀오 교차.
- 모서리 radius 0–4px — 4px 초과 금지.
- 그림자는 하드 오프셋만: `4px 4px 0 #7C4DFF`(또는 민트) — blur 0. 소프트 섀도 0건.
- 아이콘: 2px 스트로크, 민트/바이올렛, 24px 그리드 — zine 모티프(글리치·화살표·별표) 크래프트. 이모지 금지.
- 이미지: radius 0–4px, 듀오톤 처리, 위에 민트/바이올렛 1–2px 보더.

## 모션
- 기본 전환: `150ms cubic-bezier(0.3, 0, 0.2, 1)` — snappy.
- 스크롤 진입: threshold 0.2 트리거, `opacity 0→1` + `translateY(14px→0)` + `rotate(-2deg→0)` 150ms, stagger 50ms.
- 보더 색 스위치(민트↔바이올렛): 120ms.
- `prefers-reduced-motion: reduce`: translate·rotate 제거, opacity 100ms만. 하드 오프셋 등장은 유지(위치 고정 상태 변화).
- 250ms 초과 페이드·바운스·패럴랙스 0건.

## 인터랙션 상태
- 버튼(프라이머리) default: 민트 `#4FFFB0` 솔리드 + `#101014` 라벨(Inter 700 대문자), radius 4px, 패딩 `12px 28px`.
- 버튼 hover: `translate(-2px,-2px)` + 하드 오프셋 `4px 4px 0 #7C4DFF` 즉시 등장, 150ms.
- 버튼 focus-visible: `outline: 2px solid #4FFFB0; outline-offset: 3px` — 전 요소 공통, outline 제거 금지. 민트 면 위에서는 `#7C4DFF` 아웃라인.
- 버튼 active: translate(0,0) + 오프셋 `2px 2px 0`, 80ms.
- 세컨더리 버튼: 바이올렛 솔리드 + `#FFFFFF` 라벨(4.8:1) — hover 오프셋은 민트 `4px 4px 0 #4FFFB0`.
- 링크: default `#ECECEC` + 민트 1px 밑줄. hover: 배경이 바이올렛 면으로 즉시 채워짐(0ms) + 텍스트 `#FFFFFF`. active: 민트 면 + `#101014` 텍스트.
- 카드 hover: 하드 오프셋 `4px 4px 0`(보더 반대색) + translate(-2px,-2px) + 보더 민트↔바이올렛 스위치 120ms.
- 입력 필드 focus: 보더 2px 바이올렛 → 민트 스위치 + 전역 아웃라인.

## 컴포넌트
- **헤더/내비:** 높이 64px, `#101014`, 하단 2px 민트 라인. 좌 워드마크(Clash 700 `1.2rem`), 우 메뉴(라벨 스타일 `#8A8A95`, 간격 24px) + 민트 솔리드 CTA.
- **기사 카드:** 패널 `#1B1B22`, 2px 듀오 보더(카드마다 민트/바이올렛 번갈아), radius 4px, 패딩 24–28px. 인덱스↔키커 12px, 키커↔제목 8px, 제목↔본문 12px.
- **거대 인덱스 번호:** 전역 크기 집합 참조 — 헤드라인 뒤 z-1 레이어 또는 카드 구석, opacity 1(옅게 깔기 금지 — zine은 대담하게).
- **태그 칩:** 민트 또는 바이올렛 1px 외곽선 + 텍스트는 민트 또는 `#ECECEC`(바이올렛 텍스트 금지), 패딩 `4px 12px`, radius 2px.
- **풀쿼트:** 민트 2px 외곽선 박스, Clash 700 `1.5rem`(바이올렛 배색 허용 크기), 패딩 24px, 회전 -1°.

## 하지 말 것
- 강조색 1개로 줄이기 금지 — 민트:바이올렛 40:60~60:40 듀오가 정체성.
- `1.5rem` 미만 바이올렛 텍스트 금지(3.9:1) — 소형 강조 텍스트는 민트.
- radius 4px 초과·소프트 섀도(blur 1px 이상)·글래스 패널·이모지 0건.
- 그라디언트 텍스트·라디얼 글로우·보라 그라디언트 0건.
- 완벽 정렬 금지 — 섹션당 어긋난 요소 2–4개(0개도 5개 이상도 아님).
- 250ms 초과 페이드·바운스 금지 — 150ms snappy.
- 평면 단색 보이드·빈 플레이스홀더 패널·구성에서 분리된 무작위 부유 요소 0건 — 어긋남은 항상 다른 레이어와 16px 이상 겹쳐 묶인다.
- 팔레트 6색 외 hex 0개.

## 상세 페이지 (5종) — 전역 규칙 상속, 아래는 페이지 고유 값

### 1. 히어로 (듀오 강조)
- min-height 88vh, `#101014`. 좌 7열 텍스트 / 우 5열 이미지 패널.
- 텍스트: 민트 키커 → H1(`clamp(2.8rem,6vw,5.5rem)`, 2–3줄) — 단어 단위 듀오 배색(민트 1–2단어 + 바이올렛 1–2단어 + 나머지 `#ECECEC`) → 리드문 `1.1rem` → 민트 솔리드 CTA + 바이올렛 2px 외곽선 세컨더리(라벨 `#ECECEC`), 버튼 간격 16px.
- 배경 거대 이슈 번호: `clamp(3rem,8vw,7rem)`, 우상단, 헤드라인과 24px 겹침, z-1.
- 우측 이미지 패널: 듀오톤 실사, rotate -3°, 2px 민트 보더 + `6px 6px 0 #7C4DFF` 하드 오프셋.
- 헤드라인 주변 태그 칩 3개 — 각각 rotate -2°/0°/1.5°, 칩 간격 8px, 1개는 헤드라인에 16px 겹침.
- 배경 zine 도트 패턴(2px, 간격 24px, opacity 0.06) 좌하단 40% 영역.
- 어긋난 요소 검산: 이미지 패널·칩 2개·인덱스 번호 = 4개(상한).
- 375px: 이미지 패널이 텍스트 아래(rotate -1.5°), 이슈 번호 `clamp(2.4rem,14vw,4rem)` 우상단 유지.

### 2. 헤더·내비게이션
- 높이 64px 고정, `#101014`, 하단 `2px solid #4FFFB0`.
- 좌 워드마크 Clash 700 `1.2rem` `#ECECEC`, 중앙 메뉴 5개(라벨 `0.74rem` `#8A8A95`, 간격 24px), 우 민트 CTA(패딩 `9px 20px`).
- 메뉴 hover: 바이올렛 면 하이라이트 0ms + `#FFFFFF` 텍스트. 현재 페이지: 민트 텍스트 + 하단 2px 민트 룰.
- 스크롤 후에도 높이·보더 불변(축소 없음).
- 375px: 메뉴 숨김, 우측 2px 민트 보더 햄버거 40×40px.
- 모바일 오버레이: `#101014` 풀스크린, 메뉴 Clash 700 `2.2rem` 듀오 번갈아 배색(항목별 민트/바이올렛 — 이 크기는 둘 다 대비 통과), 행 간 20px, 항목 rotate -1~1° 랜덤.
- 오버레이 진입 150ms + stagger 40ms.
- 헤더 CTA hover는 전역 버튼 규칙(오프셋 `4px 4px 0 #7C4DFF`).

### 3. 기사 콘텐츠
- 좌 8열: H2 헤드라인이 패널(`#1B1B22`, rotate -2°, 패딩 32px) 위에 얹히고 텍스트 일부가 패널 우측 경계를 24px 넘침.
- 헤드라인 위 민트 키커 + 날짜 `0.74rem` `#8A8A95`.
- 우 4열 본문 칼럼 — 컬럼 시작을 그리드 경계에서 우로 24px 이탈(zine 어긋남).
- 본문 중간 풀쿼트 1개: 민트 2px 박스, rotate -1°, 본문 폭 110% 좌 돌출.
- 듀오톤 이미지 1점: 본문 칼럼 좌상단에 32px 겹침, 2px 바이올렛 보더 + `4px 4px 0 #4FFFB0`.
- 문단 간격 20px, 소제목(카드 제목 스타일) 위 40px/아래 12px.
- 본문 옆 마진에 세로 쓰기 라벨(`writing-mode: vertical-rl`, `0.74rem` 민트) 1개.
- 768px 미만: 본문 1단 풀폭, 돌출·이탈 해제, 겹침 16px로 축소.

### 4. 기사 그리드 갤러리
- 카드 6개, 3열 그리드(1120px 이상), 갭 24px — 카드별 rotate 순서 [-3°, 1°, -1.5°, 2°, -0.5°, 3°].
- 카드 2개는 grid-row span 2(세로 롱), 나머지 4개 기본 — 높이 위계.
- 각 카드: 거대 인덱스 2자리 → 민트 키커 → Clash 제목 `1.35rem` → 듀오톤 썸네일(비율 16:10).
- 보더 교차: 홀수 카드 민트 2px, 짝수 카드 바이올렛 2px — 오프셋은 반대색.
- 인덱스 번호는 카드 우상단에서 12px 돌출(카드 경계 밖).
- hover: 전역 카드 규칙 + 썸네일 듀오톤 반전(민트↔바이올렛 매핑 스위치) 120ms.
- 섹션 헤더: H2 + 우측 "ALL ISSUES →" 민트 링크, 헤더↔그리드 40px.
- 768px: 2열(span 해제), 375px: 1열, rotate ±1.5° 완화.

### 5. 구독 CTA·푸터
- CTA 패널: `#1B1B22`, rotate -1.5°, 최대 폭 880px 중앙, 패딩 `clamp(40px,6vw,64px)`, 2px 바이올렛 보더 + `8px 8px 0 #4FFFB0`.

- 이메일 입력: radius 2px, 2px 바이올렛 보더, `#101014` 배경, `#ECECEC` 텍스트, 패딩 `12px 16px`, 폭 최대 380px.
- 구독 버튼: 민트 솔리드, 입력과 간격 12px — 375px에서 세로 스택.
- 입력 placeholder `#8A8A95`(5.6:1), focus 시 보더 민트 스위치.
