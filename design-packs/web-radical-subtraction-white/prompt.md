# 래디컬 섭트랙션 화이트 — web 디자인 팩

spec_version: v3.1-2026-08-16

## 이 스타일의 정체성
풀뷰포트 시네마틱 사진 한 장 + 짧은 헤드라인 한 줄 + 외곽선/솔리드 버튼 한 쌍만 남기고 장식 UI를 전부 제거한, 극단적 환원의 클린 화이트 사이트다. 무엇을 보면 이 스타일임을 아는가 — 모든 콘텐츠가 중앙 축에 정렬되고 배지·태그·아이콘 같은 장식 UI가 하나도 없다, 각 섹션이 풀뷰포트 사진 한 장으로 채워지고 섹션 간 스냅 스크롤로 넘어간다, 색이 순수 무채(흰 배경 + near-black 텍스트)뿐이고 강조색이 없다, 버튼은 외곽선 1px 또는 솔리드 두 가지뿐 — 그것도 한 쌍.

## 빼기의 수치 계약 (이 팩의 핵심)
- 섹션당 시각 요소 4개 이하: 사진(또는 배경) 1 + 헤드라인 1 + 서브카피 1 + 버튼 페어 1(각 버튼 높이 ≈ 40px). 다섯 번째 요소 추가 금지.
- 페이지 전체 텍스트 크기 5종 이하, 색상 4종 이하(`#FFFFFF`·`#F4F4F4`·`#171A20`·`#5C5E62`), 버튼 2종 이하.
- 텍스트 콘텐츠가 차지하는 면적: 섹션당 12% 이하 — 나머지는 사진과 여백이 채운다.
- 헤드라인 1줄(최대 24자, 680px 블록 기준), 서브카피 1줄(최대 40자) — 두 줄 이상은 빼기 실패.
- 아이콘 총량: 페이지 전체 3개 이하(각 20px 박스, 내비 화살표·햄버거 등 필수만).
- 흰 배경 섹션의 콘텐츠 블록 최대 폭 `680px`, 상하 여백은 콘텐츠 높이의 1.5배 이상.

## 색
- 배경: `#FFFFFF`. 패널(가격 카드): `#F4F4F4`.
- 텍스트: `#171A20` (near-black). 보조: `#5C5E62`.
- 강조색 없음 — 순수 무채. 버튼 외곽선·솔리드 모두 `#171A20`. 위 4색 + 사진 외 어떤 색도 등장 금지.
- 대비 실측: `#171A20` on `#FFFFFF` ≈ 16.2:1 (AAA). `#5C5E62` on `#FFFFFF` ≈ 6.3:1 (AA). `#171A20` on `#F4F4F4` ≈ 14.6:1 (AAA).
- 사진 위 텍스트: 사진 명도에 따라 `#FFFFFF` 또는 `#171A20` — 어느 쪽이든 실측 4.5:1 이상 확보, 부족하면 오버레이로 보정.
- 오버레이: `linear-gradient(rgba(23,26,32,0.35), transparent 40%)` 1줄만 허용 — 텍스트 가독 보정 전용.

## 타이포그래피
- 디스플레이: `Inter`(Google Fonts) weight 500, 대체 `Helvetica Neue, Arial, sans-serif`. H1 `clamp(2rem, 3.4vw, 3.4rem)`, `letter-spacing: -0.01em`, line-height 1.15.
- 본문/서브카피: `Inter` 400, `1rem`, line-height 1.6, 측정 50–62자.
- 캡션/메타: `Inter` `0.8rem`, weight 400, 색 `#5C5E62`.
- 버튼 라벨: `Inter` `0.82rem`, weight 500, `letter-spacing: 0.02em`.
- 사용 가능한 텍스트 크기 집합(이외 금지): `0.8rem / 0.82rem / 1rem / 1.75rem / clamp(2rem,3.4vw,3.4rem)` — 딱 5종.
- 웨이트 집합: 400·500만. 600 이상 헤비 디스플레이 금지 — 환원의 미감.

## 레이아웃 / 그리드
- 콘텐츠 텍스트 폭: `680px` 중앙 정렬. 사진 섹션은 풀뷰포트 100vw × 100vh. 데스크탑 1280px 뷰포트 기준.
- 브레이크포인트: `768px`, `1100px`.
- 모든 콘텐츠 중앙 축 정렬(축 이탈 허용 오차 0px) — 좌우 정렬·비대칭 금지.
- 섹션 간 스냅 스크롤: `scroll-snap-type: y mandatory`, 각 섹션 `scroll-snap-align: start`.
- **절제 ≠ 빈약 — 풀뷰포트 사진은 필수 콘텐츠다.** 사진 섹션은 반드시 화면 100%를 채우는 시네마틱 비주얼(실제 사진 또는 깊이감 있는 그라디언트·텍스처 이미지)을 담는다 — 평면 단색 면 금지.
- **간격 리듬:** 8px 베이스. 헤드라인↔서브카피 16px, 서브카피↔버튼 페어 32px, 버튼 간 16px. 가격 카드 내부: 패딩 36px, 옵션명↔가격 12px, 가격↔사양 20px, 사양↔버튼 24px.

## 반응형 (뷰포트별 값)
- 375px: 텍스트 좌우 패딩 `24px`, H1 실효 2rem(clamp 하한), 버튼 페어 세로 스택(버튼 폭 100%, 최대 320px, 간격 12px), 가격 카드 1열.
- 768px: 텍스트 패딩 `40px`, 버튼 페어 가로 복귀(간격 16px), 가격 카드 2열(갭 24px).
- 1280px: 텍스트 블록 680px 중앙, H1 실효 3.4rem, 가격 카드 2–3열(갭 24px).
- 100vh 섹션·스냅 스크롤은 375px 포함 전 구간 유지. 모바일 주소창 대응은 `100dvh` 사용.
- 헤더 높이 전 구간 56px 고정.

## 형태 / 질감
- 모서리: 버튼·카드 radius `4px` — 이 팩의 유일한 곡률, 그 이상 금지.
- 보더: 외곽선 버튼 `1px solid #171A20`만. 카드 보더 없음 — `#F4F4F4` 면 채움으로만 구분. 구분선·룰 사용 금지(푸터 포함).
- 그림자: 일절 없음(`box-shadow: none` 전역).
- 아이콘: 필수 3개 이하, 1px 스트로크 20px 박스. 장식 아이콘·배지·이모지 금지.
- 이미지: 풀뷰포트, radius 0px, `object-fit: cover`, 채도·콘트라스트 자연 그대로(필터 금지). 오버레이 1줄만 예외.
- 버튼: (1) 솔리드 `#171A20` + 흰 텍스트, (2) 외곽선 `1px solid #171A20` + `#171A20` 텍스트. 패딩 `11px 26px`, radius 4px, 최소 폭 160px.

## 상태
- default: 솔리드 배경 `#171A20` + 흰 텍스트 / 외곽선 텍스트 `#171A20`.
- hover: 솔리드 `#171A20 → #393C41`(200ms). 외곽선 → 솔리드로 채워짐(배경 `#171A20` + 흰 텍스트, 200ms). 메뉴 텍스트 opacity 1 → 0.7.
- focus-visible: `outline: 2px solid #171A20; outline-offset: 3px`. 사진 위에서는 `outline: 2px solid #FFFFFF`.
- active: 버튼 `scale(0.98)`, 80ms — 이 팩의 유일한 트랜스폼.
- disabled: opacity 0.35, 색 `#171A20` 유지(대체색 금지).

## 모션
- 전환: `snappy` — `200ms cubic-bezier(0.4, 0, 0.2, 1)`. 대상: opacity·background·color만(active scale 예외).
- 섹션 전환: 스냅 스크롤이 다음 100vh 섹션에 단호하게 안착 — 브라우저 네이티브 스냅, JS 하이재킹 금지.
- 스크롤 진입: 헤드라인·버튼 `opacity 0→1` 200ms, 트리거 뷰포트 30% 지점(`IntersectionObserver threshold 0.3`). translateY 등 트랜스폼 금지.
- 스크롤 거동: 헤더는 sticky 아님 — 각 섹션 위 오버레이로만 존재. 패럴랙스 금지.
- `prefers-reduced-motion: reduce`: `scroll-snap-type: none`으로 해제 + fade 제거 — 전환 0ms 즉시 표시.
- 패럴랙스·바운스·느린 흐름(300ms 초과) 모션 금지.

## 컴포넌트
- **헤더/내비:** 높이 56px, 투명(사진 위) 또는 `#FFFFFF`. 좌측 워드마크(Inter 500 `1rem`), 중앙 메뉴 5개(Inter 400 `0.82rem`, 간격 24px), 우측 보조 링크 2개. 보더·그림자·배경 블러 없음.
- **풀뷰포트 섹션:** 100vh(=100dvh) 사진 + 중앙 헤드라인 + 서브카피 + 버튼 페어. 시각 요소 4개 계약 준수.
- **가격 카드:** `#F4F4F4`, 보더 없음, radius 4px, 패딩 36px, 전부 중앙 정렬. 옵션명(`1rem` 500) + 가격(`1.75rem` Inter 500 tabular-nums) + 사양 리스트(불릿 없음, 행 간 8px, `0.8rem` `#5C5E62`) + 버튼 페어.
- **버튼 페어:** 솔리드 + 외곽선이 항상 한 쌍, 중앙 정렬, 간격 16px. 단독 버튼 금지.
- **캡션:** 사진 하단 중앙, `0.8rem` `#5C5E62`, 하단에서 24px.

## 하지 말 것
- 넓은 자간 럭셔리 라벨·좌우 정렬·풀블리드 비대칭 금지 — 중앙 정렬 + 스냅 스크롤이 정체성.
- 배지·태그·장식 아이콘·일러스트·구분선 추가 금지 — 장식 UI 전부 제거.
- 강조색 금지 — 순수 무채 4색만.
- 그라디언트(가독 오버레이 1줄 예외)·radius 4px 초과·이모지·box-shadow 금지.
- 헤비 디스플레이(600+)·거대 타이포 금지 — weight 500 라이트 지오메트릭.
- 비대칭·다단 콜라주 금지 — 모든 것이 중앙 축.
- 느린 패럴랙스 금지 — 전환은 snappy 스냅.
- 섹션당 시각 요소 5개 이상 금지 — 빼기의 수치 계약 위반.
- 평면 단색 데드 보이드 금지 — 사진 섹션은 시네마틱 비주얼로 100% 채운다.
- 빈 플레이스홀더 블록 금지 — 사진 자리에는 실제 이미지 또는 깊이감 있는 그라디언트/텍스처 비주얼.
- 길 잃은 떠다니는 요소 금지 — 모든 콘텐츠는 중앙 축.
- 정체성 약화 금지 — 풀뷰포트 사진 + 중앙 정렬 + 스냅 스크롤 + 버튼 페어가 모든 페이지에서 또렷해야 한다.
- 카드 그리드 남발·보라 그라디언트·soft shadow 등 기본 AI 미감 금지.

## 상세 페이지 (6종)
전역 규칙(색·타이포·상태·모션·빼기 계약)은 위를 상속한다. 아래는 각 페이지 고유 값만 적는다.

### 1. 히어로 (풀뷰포트 사진)
- 100dvh 풀뷰포트 시네마틱 제품 사진 1장, `object-fit: cover`, radius 0px, 필터 없음.
- 헤드라인: 상단에서 15vh 지점, 중앙 정렬, `clamp(2rem,3.4vw,3.4rem)` Inter 500, 1줄 24자 이내.
- 서브카피: 헤드라인 아래 16px, `1rem`, 1줄 40자 이내.
- 버튼 페어: 하단에서 12vh 지점 중앙 — 솔리드 "Order Now" + 외곽선 "Learn More", 간격 16px, 각 최소 폭 160px.
- 텍스트 색: 사진 상부 명도 기준 `#FFFFFF`/`#171A20` 자동 선택, 대비 4.5:1 미달 시 상단 오버레이 `rgba(23,26,32,0.35)` 적용.
- 시각 요소 수: 사진 1 + 헤드라인 1 + 서브카피 1 + 버튼 페어 1 = 4개(요소 간 최소 16px). 스크롤 힌트·배지 등 5번째 금지.
- 사진 부재 시: 깊이감 있는 무채 그라디언트(`#171A20→#5C5E62` 대각 + 미세 노이즈 텍스처)로 100% 채움.
- 진입: 헤드라인·버튼 opacity 0→1 200ms — 트랜스폼 없음.

### 2. 헤더·내비게이션
- 높이 56px, 사진 위 투명 오버레이(z-index 10), 배경·보더·블러 없음.
- 좌측 워드마크: Inter 500 `1rem`, 좌측 패딩 32px.
- 중앙 메뉴 5개: Inter 400 `0.82rem`, 간격 24px.
- 우측 보조 링크 2개: `0.82rem`, 간격 24px, 우측 패딩 32px.
- 메뉴 hover: opacity 1 → 0.7, 200ms. 밑줄·인디케이터 없음 — 빼기.
- 텍스트 색: 하부 사진 명도에 따라 `#FFFFFF`/`#171A20` 일괄 전환(개별 혼용 금지).
- 모바일(<768px): 중앙 메뉴 숨김, 우측 20px 햄버거(1px 라인 2개, 간격 7px).
- 모바일 메뉴: 풀스크린 `#FFFFFF` 오버레이, 중앙 정렬 세로 메뉴, 행 높이 64px, `1rem` 500, 구분선 없음.
- 열림/닫힘 전환: opacity 200ms.

### 3. 풀뷰포트 기능 스택
- 연속 3개 100dvh 섹션(섹션 간 간격 0px), 각각 `scroll-snap-align: start`.
- 각 섹션 = 사진 1 + 헤드라인 1(24자) + 서브카피 1(40자) + 버튼 페어 1 — 동일 구조 3회 반복이 환원의 리듬.
- 텍스트 위치: 사진 명도 보고 상단(15vh) 또는 하단(12vh) 중 택1 — 섹션마다 달라도 되나 좌우 이동 금지.
- 사진은 기능별 다른 시네마틱 컷 — 구도(클로즈업/와이드/디테일)를 섹션마다 다르게.
- 버튼 페어는 섹션당 1쌍 고정 — 생략 시에도 다른 요소로 대체 금지(3요소로 감소는 허용, 추가는 금지).
- 섹션 간 여백·구분선 0px — 사진이 엣지투엣지로 이어진다.
- 각 섹션 진입 시 텍스트 opacity 0→1 200ms.
- 캡션 필요 시 하단 24px 중앙 `0.8rem` — 이 경우 서브카피 생략(요소 4개 유지).

### 4. 가격·구성 옵션
- `#FFFFFF` 배경 100dvh 섹션, 사진 없음 — 흰 여백이 주인공.
- 상단 헤드라인: 상단에서 12vh, 중앙, `clamp(2rem,3.4vw,3.4rem)`.
- 가격 카드 2–3개 가로 중앙 정렬, 카드 폭 균등(각 300–340px), 갭 24px, 헤드라인과 8vh 간격.
- 카드: `#F4F4F4`, radius 4px, 패딩 36px, 보더·그림자 없음.
- 카드 내부(전부 중앙 정렬): 옵션명(`1rem` 500) → 가격(`1.75rem` 500 tabular-nums) → 사양 3–4줄(`0.8rem` `#5C5E62`, 행 간 8px, 불릿 없음) → 버튼 페어(세로 스택, 폭 100%, 간격 12px).
- 옵션명↔가격 12px, 가격↔사양 20px, 사양↔버튼 24px.
- 추천 카드 강조 금지 — 배지·색 변화 없음, 카드 3장 모두 배경 `#F4F4F4` 동등(빼기).
- 카드 hover: 배경 `#F4F4F4 → #EDEDED` 200ms만.
- 375px: 카드 1열 세로 스택, 카드 폭 100%(최대 340px), 세로 간격 16px.

### 5. 갤러리
- 연속 2–3개 100dvh 풀뷰포트 사진 섹션(간격 0px), 스냅 스크롤로 한 컷씩.
- 각 섹션: 사진 1장 + 하단 중앙 캡션 1줄(`0.8rem` `#5C5E62`, 하단 24px)만 — 요소 2개.
- 헤드라인·버튼 없음 — 사진 자체가 콘텐츠.
- 캡션 색: 사진 하부가 어두우면 `#FFFFFF`, 밝으면 `#5C5E62`.
- 타일 그리드·썸네일·인디케이터 도트 금지.
- 사진 구도: 컷마다 다른 앵글(전면/측면/디테일), 톤은 자연 그대로.
- 사진 부재 시: 무채 그라디언트(`#171A20`→`#5C5E62` 대각) + 노이즈 텍스처 비주얼로 컷 구성.
- 진입: 캡션 opacity 0→1 200ms.

### 6. 예약 CTA·푸터
- CTA: `#FFFFFF` 배경(또는 풀뷰포트 사진 위), 중앙 헤드라인(`clamp(2rem,3.4vw,3.4rem)`, 24자 이내) + 버튼 페어("Schedule a Test Drive" 솔리드 + "Contact" 외곽선), 헤드라인↔버튼 32px.
- CTA 섹션 높이 60vh(최소 480px) 이상, 콘텐츠는 수직 중앙.
- 푸터: `#FFFFFF`, 보더·구분선 없음, 상하 패딩 80px/40px.
- 중앙 단일 축: 워드마크(`1rem` 500) → 메뉴 링크 가로 1줄(Inter 400 `0.82rem`, 간격 24px) → 카피라이트(`0.8rem` `#5C5E62`).
- 워드마크↔메뉴 24px, 메뉴↔카피라이트 16px.
- 컬럼 분할·소셜 아이콘·뉴스레터 폼 금지 — 푸터도 빼기.
- 링크 hover: opacity 0.7, 200ms.
- 375px: 메뉴 링크 2줄까지 줄바꿈 허용(행 간 12px), 그 외 동일.
- 푸터 링크 focus-visible: outline 2px `#171A20` offset 3px.
