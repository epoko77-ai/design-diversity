# 베인 리절츠 덱 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(1280×720px 좌표계, 13.33×7.5in) 슬라이드 덱을 만든다. 베인 리절츠 덱 — 슬라이드 중앙 상단에 거대한 결과 메트릭 한 점(예 `+34%`)이 지배하고, 그 아래 작은 캡션이 맥락을 다는 'results-first' 컨설팅 덱. 베인 레드 단 한 점, 중앙 정렬 단일 축, 넉넉한 흰 여백. 이하 %H = 캔버스 높이 720px 기준 백분율.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 슬라이드마다 거대 숫자 한 점이 시선을 독점한다 — `+34%`·`2.7×`·`$1.2B` 같은 결과 메트릭이 약 130pt 베인 레드로, (2) 모든 것이 캔버스 세로 중심선(x=640px) 기준 정렬 — 비교조차 중앙 좌우 대칭, (3) 무채색 + 레드 단 한 점. 성과를 먼저 보여주고 설명을 나중에 다는 results-first 덱.

## 색 (역할·적용 면적 상한 포함)
- 배경 `#FFFFFF` 순백 — 캔버스 면적의 70% 이상.
- before 패널 `#F4F5F6` — before 상태·근거 스트립·주석 패널에만, 캔버스 면적 20% 이하.
- 본문 잉크/헤딩 `#111827`.
- 캡션 그레이 `#9CA3AF` — 캡션·라벨·축선.
- 강조 베인 레드 `#CC0000` — 거대 결과 숫자·델타 ▲▼·결과 데이터 포인트에만. 레드 합산 면적 캔버스의 6% 이하. 면(배경)·본문 텍스트 사용 금지.
- 무채 데이터 연톤 `#D1D5DB` / 진톤 `#6B7280` — 차트 전용.
- 허용 색은 위 6개 hex가 전부 — 추가 색·그라디언트 0건.
- 통화 표기: `₩` 글리프 금지 — `1,240억`·`KRW 1.24T`·`$1.2B` 형식.

## 타이포그래피
- 폰트: 전부 `Inter`(대체 `Helvetica Neue, Arial, sans-serif`), 한글 `Pretendard`. 2종 외 금지.
- 거대 결과 메트릭: 130pt / 800 / 자간 -0.02em / `#CC0000` / tabular numerals / 슬라이드당 1개.
- 메트릭 캡션: 16pt / 400 / `#9CA3AF` / 중앙 정렬 / 1줄(최대 28자).
- 슬라이드 제목(메트릭 없는 슬라이드): 32pt / 700 / 중앙 정렬 / 최대 2줄·줄당 26자.
- 본문: 20pt / 400 / 행간 1.45 / 슬라이드당 5줄 이하.
- 비교 칼럼 헤더: 14pt / 600 / 자간 +0.12em / 대문자.
- 보조 수치: 28pt / 700 / tabular. 프로세스 거대 번호: 48pt / 800.
- 카드 라벨·근거 라벨: 14pt / 500. 맥락 캡션: 12pt / 400 / `#9CA3AF`.
- 출처 각주: 10pt / 400 / `#9CA3AF`. 페이지 번호: 10pt, 우하단 x=1216px 우정렬.
- pt 위계는 10/12/14/16/20/28/32/48/130pt 9단계가 전부 — 중간 크기 신설 금지.
- 수치 표기: 천 단위 콤마, 델타는 부호 의무(`+34%`), 소수 자릿수 모듈 내 통일.

## 레이아웃 / 그리드
- **중앙 정렬 단일 축 + 고정 외곽 여백.** 좌·우·상 외곽 여백 각 64px, 하단 풋라인 baseline y=664px(92.2%H) 고정 — 전 슬라이드 동일, 드리프트 0px.
- 모든 핵심 요소의 광학 중심을 x=640px 세로 중심선에 정렬. 좌측 정렬 블록 금지(표 행라벨 제외).
- 결과 메트릭 슬라이드 존 배분: 상단 34%(y=64~245px) 영웅 메트릭+캡션 / 중단 44%(y=245~562px) 입증 모듈 / 하단(y=562~640px) 한 줄 종합, 풋라인은 전역 y.
- 영웅 메트릭 baseline y=200px(27.8%H) 고정, 캡션은 그 아래 0.2in(19px).
- 비교 슬라이드: 두 칼럼 폭 각 460px 동일, 칼럼 사이 0.6in(58px), 중심선 좌우 대칭 — 칼럼 엣지 x=122px/582px·x=698px/1158px.
- 구성 균형: 어느 한 연속 빈 영역도 캔버스의 20% 초과 금지. 캔버스 88% 이상을 의미 있는 콘텐츠로.
- 밀도: 영웅 메트릭 1개 + 입증 모듈 3개 이상(KPI 스트립·추이 차트·근거 분해·출처 풋라인). 거대 숫자 하나만 띄운 슬라이드 금지.
- 근거 콜아웃 스트립: `#F4F5F6` 가로 스트립(폭 856px 중앙 배치) — ▲ 레드 델타 + 14pt 라벨 3개 가로 균등, 내부 패딩 상하 0.16in(15px), 높이 = 내용 + 패딩.
- 수직 리듬 24/32/48px 스텝. 대문자 라벨 자간 +0.12~0.16em 통일.
- 모든 본문성 슬라이드: 좌하단 출처 줄 + 우하단 페이지 번호를 풋라인 baseline에 정렬.
- 표: 행 룰 0.75~1px `#D1D5DB` 헤어라인, 평결행 700, 강조 셀/행 1개만, tabular 수치 우정렬, 행 높이 40px 균일.

## 형태 / 질감
- 보더 0, 모서리 반경 0px, 그림자 offset/blur 0px. 완전 평면.
- before 패널만 `#F4F5F6` 채움 — after는 흰 배경 그대로(굵기·색 대비로 차이).
- 아이콘 0개 — 델타는 ▲▼ 삼각형(높이 12px, 레드) 또는 1.5pt 화살표만. 카드 테두리 없음.
- `#F4F5F6` 패널 내부 패딩 24px 통일, 패널 모서리 반경 0px.
- 사진·일러스트·배경 텍스처 0건 — 흰 면과 타이포만으로 구성.
- 구획은 0.75px 무채 디바이더와 간격으로만 — 수직 디바이더 높이는 인접 콘텐츠의 60%.

## 차트·데이터 시각화 (results-first 차트 — 무채 + 레드 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트는 거대 메트릭의 근거를 받친다.
- 데이터 색: 기본 `#D1D5DB`(연) / `#6B7280`(진). 강조 1막대·결과 시점 1개만 `#CC0000` 솔리드 — 차트당 레드 1개.
- 추이 차트: 1.5pt 폴리라인, 면적 채움 0. 시작·중간 포인트 지름 8px 무채 원, 결과(최종) 시점만 지름 0.16in(15px) 레드 원 + 우측 12px에 28pt 레드 델타 라벨.
- 막대: 폭:간격 = 3:2, 모서리 0px, 베이스라인 0 정확(잘린 y축 금지), 개수 4~8개.
- 격자선 0. 차트 테두리·배경 채움 0. x축선 0.75pt `#9CA3AF`, y축선 생략 가능.
- 값 레이블: 막대 끝·꼭짓점 위 8px 직접 표기, 14pt 600 tabular. 결과 값만 28pt 레드. 범례 박스 금지 — 직접 라벨링(라인 끝 8px).
- 축 라벨 12pt `#9CA3AF`, 틱 길이 4px, 단위는 출처 각주에 1회 명기.
- 도넛: 1개만, 조각 3개 이하, 두께 32px, 중앙에 28pt 700 핵심 수치, 핵심 조각만 레드.
- before/after 막대: 두 막대를 중심선 좌우 대칭 배치, before `#D1D5DB`·after `#CC0000`, 막대 폭 각 120px.
- 미니 스파크라인: 1pt 무채 폴리라인, 폭 96px·높이 24px, 마지막 포인트만 지름 4px 레드 원.
- 출처: 차트 슬라이드 좌하단 10pt `#9CA3AF` 출처·단위 각주 의무.
- 타입 매칭: 비교=세로 막대, 추세=라인, 비중=도넛 1개, before/after=대칭 막대. 파이 5조각 이상·3D·다중 도넛 금지.
- 레이블 충돌: 간격 12px 미만이면 강조 계열만 표기.
- 음수 값: 베이스라인 아래로 그리고 값 레이블은 막대 하단 8px — 절댓값 변환 금지.
- 데이터 포인트 수 초과(막대 8개·라인 10개 초과) 시 표로 전환.
- 차트 내부 제목 금지 — 결론은 헤더가 담당, 차트 상단 여백 16px.

## 다이어그램·컴포넌트 (results-first 다이어그램 키트)
모든 컴포넌트를 SVG로 렌더하며 하나의 언어를 공유한다 — 보더 없는 평면, 중앙축 대칭 배치, 커넥터 1.5pt `#9CA3AF` 화살표(화살촉 6px·30°) 또는 ▲ 레드 델타, 거대 수치 + 작은 캡션 위계 공통.
- 프로세스 플로우: 좌→우 3~5단계, 단계당 48pt 800 무채 번호 + 아래 12px에 14pt 캡션. 노드 박스 0 — 번호와 간격(단계 사이 96px)이 흐름. 핵심 단계 번호만 레드.
- 타임라인: 수평 축 0.75pt `#9CA3AF`. 마일스톤 지름 0.14in(13px) 무채 원, 결과 달성 시점만 레드 솔리드 + 위 16px에 28pt 메트릭. 날짜 라벨 축 아래 12px에 12pt.
- 비교(before/after): 좌 before 칼럼 `#F4F5F6` 패널 + 무채 수치, 우 after 칼럼 흰 배경 + 레드 결과 수치. 칼럼 헤더 14pt 600 대문자. 중앙 간격대에 ▲ 델타 삼각형 + 델타 값 600 레드.
- 매트릭스 2×2: 십자축 0.75pt 무채, 교차점은 영역 정중앙. 데이터 포인트 지름 12px 동일 크기 무채 점, 목표 사분면 점만 레드. 사분면 라벨 14pt 600.
- 계층/퍼널: 폭 비례(±2% 오차) 사각 적층 중앙 대칭, 무채 명도 단계, 결과 단만 레드. 각 단 우측 12px에 28pt 수치.
- KPI·스탯 카드: 보더 없는 카드, 14pt 라벨 + 28pt 700 수치 + 14pt ▲▼ 델타 + 미니 스파크라인 + 12pt 맥락 1줄. 카드 폭 균등·간격 24px.
- 목차 행: 28pt 700 무채 번호 + 20pt 항목명 + 14pt 그레이 설명 + 우측 14pt 페이지 번호, 중앙 정렬, 행 사이 0.32in(31px) + 0.75px 무채 디바이더.
- 섹션 디바이더: 흰 배경 중앙에 레드 130pt 섹션 번호 + 32pt 섹션명.
- 인용: 중앙 정렬 28pt 700 풀쿼트(최대 3줄) + 아래 16px에 14pt 출처.
- ▲▼ 델타 삼각형: 높이 12px·밑변 14px, 증가 레드 `#CC0000`·감소 `#6B7280` — 색 규칙 덱 전체 고정.
- 프로세스 플로우 화살표: 1.5pt `#9CA3AF`, 길이 48px, 번호 baseline과 동일 y 중앙.

## 전환 (PPT)
없음(즉시 컷). 빌드 애니메이션 0건 — 거대 메트릭이 등장 효과 없이 즉시 시선을 잡는다.

## 하지 말 것
- 베인 레드를 면(배경)·본문 텍스트에 쓰지 말 것 — 거대 결과 숫자·델타에만(합산 6% 면적 상한).
- 한 슬라이드에 거대 메트릭(130pt) 2개 이상 금지 — 메트릭은 슬라이드당 1개.
- 그라디언트·그림자·둥근 카드·이모지·클립아트 0건.
- 차트 색 2개 이상 금지 — 무채 명도 + 레드 한 점.
- 좌측 정렬 회귀 금지 — 중앙 정렬 단일 축이 정체성.
- 차트 회귀 금지: 3D, 무지개색, 격자선, 범례 박스, 잘린 y축, 출처 누락.
- 거대 숫자 하나만 두고 슬라이드 비우기 금지 — 입증 모듈 3개 이상 + 출처 각주 + 페이지 번호.
- 외곽 여백 64px·풋라인 y=664px·메트릭 baseline y=200px 드리프트 금지. 빈 플레이스홀더 블록 0개. 헤더 문장 중간 단어 비대 금지(거대 메트릭 외 헤더는 일관 크기).

## 상세 페이지 (7종) — 전역 규칙은 위 절이 SSOT, 아래는 페이지 고유 좌표·구성만

### 01 · 표지 (cover)
- 캐치프레이즈: y=210px에 14pt 600 대문자(`RESULTS DELIVERED` 식) `#9CA3AF`, 중앙 정렬 — 핵심 한 단어만 레드.
- 타이틀: baseline y=310px, 32pt 700 중앙 정렬, 1~2줄.
- 부제: 타이틀 아래 0.4in(38px), 16pt `#9CA3AF` 1줄.
- 성과 미리보기 스트립: y=480px에 메트릭 3개 가로 균등(전체 폭 856px 중앙) — 각 36pt 800 레드 수치 + 아래 8px에 14pt 라벨, 항목 사이 0.75px 무채 수직 디바이더 높이 48px.
- 하단 메타: 풋라인 baseline에 중앙 정렬 10pt(클라이언트 · 날짜 · `01`).
- 레드는 캐치프레이즈 1단어 + 미리보기 수치 3개에만. 사진·일러스트 0개.

### 02 · 목차 (agenda)
- 32pt 700 헤더 "성과를 네 단계로 증명한다" — baseline y=140px 중앙 정렬.
- 목차 4행: §다이어그램 목차 행 사양, 리스트 전체 폭 760px 중앙 배치, y=210px 시작.
- 각 행 좌측 24px 바깥에 진행 인디케이터 점 지름 8px — 현재 섹션만 레드, 나머지 무채.
- 리스트 하단 32px 아래 16pt 종합 메시지 1줄 중앙 정렬.
- 항목명과 페이지 번호는 같은 baseline — 번호는 리스트 우측 엣지 x=1020px 우정렬.

- 풋라인: 출처/각주 10pt + 페이지 번호.

### 03 · 결과 메트릭 KPI 히어로 (kpi)
