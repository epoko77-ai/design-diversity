# Pattern 볼드 포스터 키노트 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(1280×720px 좌표계, 13.33×7.5in) 슬라이드 덱을 만든다. Pattern 볼드 포스터 키노트 — 슬라이드 전면을 채도 높은 단색 한 가지로 도배하고, 그 위에 거대한 굵은 산세리프 헤드라인을 포스터처럼 앉히는 정적·미니멀 키노트. 컴포넌트는 최소, 색이 페이지를 정의하고 타이포가 이미지를 대신한다. 이하 %H = 캔버스 높이 720px 기준 백분율.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 슬라이드마다 화면 전체가 채도 높은 단색 한 가지 — 일렉트릭 블루 또는 버밀리언, 슬라이드 넘기면 색이 교대된다, (2) 거대 굵은 산세리프 헤드라인이 약 105pt로 포스터처럼 좌상 또는 중앙에 앉는다, (3) 컴포넌트는 작은 라벨·페이지 번호 정도뿐 — 거대 타이포 주변에 넉넉한 여백. 정적인 포스터 시리즈.

## 색 (역할·적용 면적 상한 포함)
- 페이지 색 A 일렉트릭 블루 `#1F3DFF` — 홀수 슬라이드 전면.
- 페이지 색 B 버밀리언 `#FF4D2E` — 짝수 슬라이드 전면. A/B는 슬라이드마다 교대, 한 슬라이드에 면 1색만(좌우 분할 비교 슬라이드 예외 — 그때만 A/B 반반).
- 반전 타입 `#FFFFFF` — 색면 위 헤드라인·모듈 윤곽·데이터.
- 잉크 `#0E0E0E` — 색면 위 강조 반전 텍스트 전용, 텍스트 면적의 20% 이하.
- 허용 색은 위 4개 hex가 전부 — 그라디언트·사진·파스텔·무채 면 0건.
- 색면은 엣지투엣지 풀블리드(마진 0px) — 콘텐츠만 안전 여백 안에.
- A/B 교대 규칙은 덱 순서 기준 — 같은 색 2연속 금지(분할 비교 슬라이드는 카운트 제외).
- 잉크 `#0E0E0E`는 면으로 쓰지 않는다 — 텍스트·강조 1막대·핵심 원 1개에만.

## 타이포그래피
- 폰트: 헤드라인 `Anton`(대체 `'Arial Black', Impact, sans-serif`), 라벨·본문 `Archivo`(대체 `Arial`), 한글 헤드라인 `Pretendard` 900. 3종 외 금지.
- 헤드라인: 기준 105pt / Anton 400 / 자간 -0.01em / 행간 0.95 / 2~3줄 / 줄당 최대 12자.
- 줄별 스케일 스텝: 1줄 90pt / 2줄 105pt / 3줄 120pt 허용 — 스케일 변화는 줄 경계에서만, 한 줄 내부는 동일 크기. 문장 중간 단어 비대 금지.
- 부제: 24pt / Archivo 600 / 자간 +0.02em / 1줄.
- 라벨·페이지 번호: 13pt / Archivo 600 / 자간 +0.14em / 대문자.
- 본문(스테이트먼트): 28pt / Archivo 600 / 행간 1.3 / 슬라이드당 3줄 이하.
- KPI 영웅 숫자: 200pt / Anton / tabular numerals / 슬라이드당 1개.
- 모듈 내 수치: 80~100pt Anton tabular. 카드 라벨·델타: 24pt Archivo 600. 맥락 캡션: 14pt Archivo 400.
- pt 위계는 13/14/24/28/48/70/90/105/120/200pt — 이 단계 외 크기 신설 금지.
- 수치 표기: 천 단위 콤마, 델타 부호 의무(`+34%`), tabular 우정렬.
- 한글 헤드라인: Pretendard 900 / 자간 -0.02em — Anton과 동일 pt 스케일 적용.
- 헤드라인은 대문자(영문) 고정 — 소문자 혼용 금지. 라벨도 대문자.
- 본문·라벨의 흰색 불투명도 100% — 반투명 텍스트 0건.

## 레이아웃 / 그리드
- **풀블리드 단색 면 + 고정 안전 여백.** 콘텐츠 안전 여백 좌·우·상 각 64px, 하단 풋라인 baseline y=672px(93.3%H) 고정 — 전 슬라이드 동일, 드리프트 0px.
- 헤드라인 위치: 좌상 정렬(좌측 엣지 x=64px) 또는 중앙 정렬 — 슬라이드마다 둘 중 하나, 페이지 절이 지정. 수직 리듬 24/32/48px 스텝.
- 줄별 들여쓰기 스텝: 좌상 정렬 헤드라인은 줄마다 0/48/96px 들여쓰기 허용 — 스텝 단위 48px 고정.
- 라벨은 모서리에: 좌상 라벨 x=64px·y=48px, 페이지 번호 우하단 x=1216px 우정렬·y=672px baseline.
- 강조는 굵기·색 반전(흰↔잉크)·단어 아래 굵은 흰 룰(높이 8px, 단어 폭과 동일)로만 — 크기 변화로 강조 금지.
- **두 종류의 슬라이드:** (1) 포스터 슬라이드(표지·간지·클로징) — 거대 타이포 + 분산된 여백, 절제 유지. (2) 데이터 슬라이드(목차·본문·KPI·비교) — 거대 헤드라인 + 흰 1px 윤곽 데이터 모듈 3개 이상.
- 데이터 모듈: 흰 1px(0.75~1px 일관) 윤곽 직사각형, 채움 0·반경 0px, 내부 패딩 상하좌우 각 0.2in(19px). 모듈 간 간격 0.5in(48px) 일관, 색면이 거터로 보이게. 모듈은 2×2 또는 1×3 그리드에 스냅 — off-grid 0개.
- 흰 윤곽 콜아웃: 흰 1px 윤곽 + 28pt Archivo 600 인사이트 1줄 + 패딩 19px. 높이 = 내용 + 패딩.
- 구성 균형: 어느 한 연속 빈 색면도 캔버스의 20% 초과 금지(포스터 슬라이드의 여백은 상하좌우로 분산). 데이터 슬라이드는 캔버스 80% 이상을 모듈·타이포로.
- 모든 데이터 슬라이드: 좌하단 13pt 출처 라벨 + 우하단 페이지 번호, 풋라인 baseline 정렬.
- 표: 흰 0.75px 행 룰, 행 높이 56px 균일, 셀값 흰 24pt tabular 우정렬, 행라벨 좌정렬.
- 헤드라인과 첫 모듈 사이 수직 간격 최소 48px — 타이포 호흡 확보.
- 모듈 그리드의 좌측 엣지는 x=64px, 우측 엣지는 x=1216px — 그리드 폭 1152px 고정.
- 출처 라벨은 좌하단 x=64px, 풋라인 baseline과 동일 y — 데이터 슬라이드 의무.

## 형태 / 질감
- 모서리 반경 0px. 그림자·아이콘·일러스트 0건. 완전 평면.
- 도형은 흰 솔리드 또는 흰/잉크 1px 윤곽만 — 색면 위 2톤.
- 색면 위 텍스트 대비: 흰 텍스트 기본, 잉크는 강조 반전에만.
- 윤곽선 두께는 덱 전체 2단뿐: 모듈·표 0.75~1px / 타임라인·추세선 4pt.
- 도형 개수: 포스터 슬라이드 0~1개, 데이터 슬라이드 모듈 3~5개 — 6개 이상 금지.

## 차트·데이터 시각화 (포스터 차트 — 단색 면 위 화이트/잉크)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 포스터처럼 거대·단순하되, 데이터 슬라이드에서는 차트가 빈 면을 채우는 모듈이다.
- 데이터 색: 흰 솔리드(핵심 계열) / 흰 1px 윤곽(비교 계열) 2톤만. 추가 색 0건.
- 막대: 거대하게 3~6개만, 폭:간격 = 2:1, 모서리 0px, 베이스라인 0 정확(잘린 y축 금지).
- 격자선 0. 축선은 흰 0.75pt 한 줄 또는 생략. 차트 테두리 박스 0.
- 값 레이블: 막대 끝 위 12px에 28~40pt Archivo 600 흰색 직접 표기. 카테고리명 14pt. 범례 박스 금지.
- 변곡점 콜아웃: 흰 1px 윤곽 박스 2~3개(28pt 인사이트 + 0.75pt 흰 리더선).
- 추세: 굵은 4pt 흰 폴리라인 1개, 포인트 4~6개, 마지막 포인트만 지름 16px 흰 솔리드 원 + 40pt 델타.
- 도넛: 1개만, 조각 2~3개(흰 솔리드/흰 윤곽 교대), 두께 48px, 중앙 80pt Anton 수치.
- 보조 데이터 표: §레이아웃 표 사양, 3~4행, 차트 옆에서 원수치를 받친다.
- KPI 스트립: 하단에 흰 윤곽 모듈 3개 1×3(80pt Anton 수치 + 24pt 라벨).
- 출처: 좌하단 13pt 라벨 1줄.
- 타입 매칭: 비교=거대 세로 막대, 비중=거대 도넛 1개, KPI=거대 숫자, 추세=굵은 폴리라인 1개. 파이 다중·3D·격자선 0건.
- 데이터 포인트 6개 초과 시 표로 전환. 음수는 베이스라인 아래로.
- 차트 내부 제목 0건 — 결론은 헤드라인이 담당.
- 강조 1막대는 잉크 `#0E0E0E` 솔리드 — 나머지 막대 흰색과 대비.
- 레이블 간격 24px 미만이면 핵심 막대만 표기(포스터 스케일 유지).

## 다이어그램·컴포넌트 (포스터 다이어그램 키트)
모든 컴포넌트를 SVG로 렌더하며 하나의 언어를 공유한다 — 단색 면 위 흰 솔리드/잉크 윤곽, 반경 0px, 거대·단순, 텍스트 위계로 흐름 표현(커넥터 최소), 라벨 13pt 대문자.
- 프로세스 플로우: 거대 단계 번호(80~120pt Anton 흰색) 3~4개 가로 나열(간격 96px 균등), 각 번호 아래 16px에 14pt 라벨. 노드 박스 0 — 커넥터는 없거나 굵은 8pt 흰 화살표 1개만.
- 타임라인: 굵은 흰 수평 라인 4pt 1개. 마일스톤 지름 0.2in(19px) 흰 솔리드 원 3~5개, 아래 16px에 24pt 날짜 라벨.
- 비교(2열): 슬라이드를 좌우 두 색면 반반(x=640px 경계, 좌 A/우 B) — 각 면에 헤드라인 + 거대 숫자, 분할선 0(색 경계가 구분).
- 매트릭스 2×2: 흰 0.75pt 십자축(교차점 영역 정중앙), 사분면 라벨 28pt, 데이터 포인트 지름 0.2in(19px) 흰 솔리드 원, 핵심 1개만 잉크 원.
- 계층/퍼널: 거대 흰 사각 적층 3~4단, 폭 비례(±2%), 흰 솔리드/윤곽 교대, 각 단에 28pt 라벨.
- KPI 카드: 흰 1px 윤곽 + 24pt 라벨 + 80~100pt Anton 수치 + 24pt 델타(부호 의무) + 흰 1pt 미니 스파크라인(폭 96px·높이 24px).
- 목차 행: 70pt Anton 번호 + 24pt Archivo 600 항목명 + 14pt 설명 + 우측 13pt 페이지 번호, 행 사이 흰 0.75px 룰, 행 높이 96px.
- 섹션 디바이더: 색면 전환 + 중앙 120pt 헤드라인.
- 인용: 중앙 60~80pt Anton 풀쿼트(흰색, 최대 3줄) + 아래 24px에 13pt 출처 라벨.
- 델타·화살표: 흰색만, 화살촉 각도 45°·길이 24px(포스터 스케일).
- 스파크라인은 카드 수치 아래 12px, 마지막 포인트만 지름 8px 흰 솔리드 원.
- 인접 컴포넌트의 라벨 baseline은 동일 y — 컴포넌트 간 13pt 라벨 위치 통일.

## 전환 (PPT)
없음(즉시 컷). 빌드·페이드 0건 — 슬라이드 넘김 = 색 교대가 유일한 리듬.

## 하지 말 것
- 한 슬라이드 2색 면 금지(좌우 분할 비교 예외) — 페이지 = 단색 1가지.
- 그라디언트·사진·이모지·클립아트·그림자 0건.
- 헤드라인 90pt 미만 금지 — 거대해야 포스터다.
- 파스텔·무채 면 회귀 금지 — `#1F3DFF`/`#FF4D2E` 원색만.
- 차트 회귀 금지: 3D, 격자선, 범례 박스, 작은 차트, 3번째 색.
- 데이터 슬라이드를 거대 숫자/차트 하나만 두고 비우기 금지 — 흰 윤곽 모듈 3개 이상 + 출처 + 페이지 번호.
- 헤드라인 문장 중간 단어 비대 절대 금지 — 스케일 변화는 줄 단위, 강조는 굵기·색 반전·8px 룰로.
- 빈 흰 윤곽 플레이스홀더 모듈 0개 — 모든 모듈은 실제 숫자·차트·표·텍스트를 담는다.
- 안전 여백 64px·풋라인 y=672px 드리프트 금지.

## 상세 페이지 (7종) — 전역 규칙은 위 절이 SSOT, 아래는 페이지 고유 좌표·구성만

### 01 · 표지 (cover)
- 색면: 블루 `#1F3DFF` 전면.
- 좌상단 x=64px·y=48px에 13pt 흰 대문자 라벨.
- 헤드라인: 좌상 정렬 좌측 엣지 x=64px, 첫 줄 baseline y=400px, 2~3줄(줄별 스케일 90/105/120pt 스텝 + 들여쓰기 0/48px), 흰색.
- 강조 1단어만 잉크 `#0E0E0E` 반전 또는 아래 8px 흰 룰.
- 우하단에 흰 1px 윤곽 메타 스트립: `PRESENTED BY`/`DATE` 2행 13pt, 패딩 19px, 우측 엣지 x=1216px 정렬.
- 하단 baseline y=672px에 페이지 라벨 `01`.
- 포스터 슬라이드 — 모듈 추가 금지(메타 스트립 1개 예외), 여백은 상단·우측으로 분산(한 구석 20% 초과 금지).
- 헤드라인 줄 수 2줄 미만 금지 — 표지의 드라마는 줄바꿈 스텝에서 나온다.

### 02 · 섹션 간지 (단색 전환) (section-divider)
- 색면: 직전 슬라이드와 교대(블루→버밀리언).
- 섹션 번호: 중앙 상단 y=200px에 13pt 대문자 `SECTION 02`.
- 헤드라인: 120pt Anton 흰색 중앙 정렬, baseline y=360px, 섹션명 1줄(최대 8자).
- 항목 인덱스 3개: y=470px에 가로 나열(간격 96px, 전체 중앙) — 48pt Anton 번호 + 우측 12px에 24pt 라벨.
- 우하단 페이지 번호. 포스터 슬라이드 — 흰 윤곽 모듈 0개 유지.
