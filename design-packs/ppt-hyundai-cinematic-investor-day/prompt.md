# 현대차 시네마틱 인베스터데이 — ppt 디자인 팩 (v3 · page-mirror plan)

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in / 1280×720) 슬라이드 덱을 만든다. 현대자동차 **2024 CEO Investor Day** 한국어 71페이지 IR 덱의 실측 양식 — 다크 네이비 무대 위 사이안 chevron motif와 HYUNDAI WAY ∞ 인피니티 다이어그램이 시그니처를 만드는, 단일 사이안-블루 패밀리 규율의 컨퍼런스 LED 키노트 미감.

**v3 핵심:** v2의 색·타입·시그니처를 1픽셀도 바꾸지 않고 계승하면서, 10개 슬라이드 카테고리(cover/agenda/section/key-message/chart/diagram/cards/comparison/narrative/closing)를 원본 71페이지 중 anchor 페이지에 **1:1 mirror** 한다. 어떤 슬라이드를 만들 때 어느 원본 페이지를 그대로 따라야 하는지 아래 page mirror plan 표가 SSOT.

## 이 스타일의 정체성

한눈에 알아보는 단서: (1) 배경은 **다크 네이비 `#101030`** (R=16 G=16 B=48 — 순흑이 아니라 푸른 톤이 살짝 도는 짙은 네이비) 단 하나로 71페이지 전부를 통일한다. 라이트 모드·회색 BG·그라디언트 BG 일체 금지. (2) 시그니처 액센트는 **밝은 민트-사이안 `#66FFFF`** 단 하나 — 모든 챕터 슬레이트 영문 타이틀, 좌상단 헤더 chevron 글로우, 강조 차트 데이터, 카드 enumerator가 이 색으로 발광한다. **Hyundai N Blue `#002C5F`는 이 덱에 0건 — 절대 쓰지 말 것**. (3) 챕터 디바이더의 지배적 모티프는 **chevron**(중첩된 우향 `>` 3~5개 스택 + 안쪽 V-vertex에 흰-사이안 글로우 + 바깥으로 미디엄 블루 → 다크 네이비 fade). **거대 outline 숫자(240~360pt)는 이 덱에 절대 존재하지 않는다 — 큰 사이안 숫자는 오직 p-64 카드 안 enumerator(80~100pt SOLID fill)로만 등장**. (4) **HYUNDAI WAY ∞ 다이어그램**(좌 사이안-블루 lobe = Mobility Game Changer + 우 teal-green lobe = Energy Mobilizer)이 이 덱 전체의 컨셉 아키텍처를 정의 — high-concept hero 자리에 1순위 사용. (5) **풀-블리드 단일 사진 0장** — 사진/렌더링은 5종 양식(하단 반 히어로 / 인라인 cut-out / dim underlay ≤30% / 좌 50% 분할 패널 / 로고 인라인)으로 분산.

## 레이아웃 / 그리드 — 세 슬라이드 모드 + 영구 헤더 마크

- **캔버스:** 16:9 와이드 (13.33 × 7.5in / 1280 × 720px, 또는 원본 export 1170 × 827px). 좌·우 마진 5%, 상 3.5%, 하 4.5%.
- **세 슬라이드 모드를 엄격히 구분한다.**
  - **Mode A — 챕터 슬레이트·표지·종료 (cover / section / closing):** 전체 `#101030` BG + chevron motif (한쪽 edge) + 거대 영문 타이틀 (#66FFFF — 표지·종료만 #FFFFFF) + (선택) 한글 부제. **콘텐츠 블록·차트·페이지 번호·헤더 마크 일체 없음.** 풀스크린 타이포그래피의 압도.
  - **Mode B — 본문 콘텐츠 (agenda / key-message / chart / diagram / cards / comparison / narrative):** 좌상단 영구 헤더 마크 + 하단 가운데 페이지 번호 + 좌 x=5% 타이틀 (y=9%) + 그 아래 eyebrow 부제 + y=15~92% 영역에 콘텐츠 (차트/도식/카드 그리드/표/지도/사진).
  - **Mode C — 서브챕터 분할 패널 (section secondary):** 좌 50% 어두운 사진 패널 (공장 항공뷰 / 배터리 팩 / EV / 수소 플랜트) + 우 50% `#101030` 다크 패널 (영문 cyan eyebrow `#66FFFF` + 한글 메인 타이틀 흰색 + 우측 작은 chevron glow). 두 패널 사이는 대각선 soft transition (~80° 수직).
- **영구 헤더 마크 (시그니처 — 빼먹지 말 것):** Mode B 모든 페이지 좌상단에 동일 위치 고정. 구성: `<미니어처 3-stack chevron glow (폭 ~50px, 흰-사이안 core → 미디엄 블루 fade)> 2024 CEO Investor Day` — chevron x=3%, y=4% / 텍스트 x=5~22%, y=4%, 색 `#00B0F0` 12pt Regular. Mode A·C에서는 omit 가능 (Mode A는 항상 omit, Mode C는 사진 패널 위에 얹지 말 것).
- **페이지 번호 위치 고정:** Mode B 페이지 **하단 가운데** (x=50%, y=96%), 작은 흰 numeral 50% opacity, 형식 `10` / `24` / `48` 단독 (fraction `10/71` 아님, 장식 없음). Mode A는 페이지 번호 omit.
