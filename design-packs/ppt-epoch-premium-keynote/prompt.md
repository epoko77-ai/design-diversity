# Epoch 프리미엄 키노트 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 본 문서의 px 좌표는 1280×720 캔버스 기준이며 렌더 해상도에 비례 확대한다. Epoch 프리미엄 키노트 — 차분한 딥 슬레이트 배경에 가는 세리프 헤딩과 산세리프 본문을 혼합하고, 1pt 룰 라인이 콘텐츠를 정연히 구획하는 차갑고 모던한 하이엔드 코퍼레이트 키노트. 강조는 cool steel 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 딥 슬레이트 `#1A1E26` 배경 — 따뜻하지 않은 차가운 다크, (2) 가는 트랜지셔널 세리프 헤딩 + 산세리프 본문의 절제된 혼합 타이포, (3) 1pt 룰 라인이 헤더·섹션·콘텐츠를 정연히 구획하고 cool steel `#7FA9C9`이 차트·라벨에 차갑게 한 점. heritage 럭셔리와 달리 따뜻함 없이 정제된 코퍼레이트.

## 색 (역할·면적 상한 포함)
- 배경 딥 슬레이트 `#1A1E26` — 캔버스 기본 채움
- 룰/패널 `#2C313B` — 1pt 룰 라인·패널 채움, 패널 노출 면적 합계 슬라이드의 40% 이하
- 강조 cool steel `#7FA9C9` — 차트 강조 1계열·강조 라벨·작은 룰에만. 노출 면적 합계 슬라이드의 5% 이하
- 텍스트 `#E6E8EC`
- 보조 텍스트 `#9298A4`
- 차트 무채 데이터 계열: 연 `#4A5160` / 진 `#9298A4`
- 계층/퍼널 명도 단계: `#2C313B` → `#353B47` → `#3E4553`(3단, 명도 차 균등)
- 디바이더 거대 섹션 번호 윤곽: steel `#7FA9C9` 1pt, 채움 없음
- 강조색은 cool steel 1개뿐. 골드·따뜻한 강조·그라디언트 금지
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 헤딩 `Newsreader`(트랜지셔널 세리프, 대체 `Georgia, serif`). 본문 `Inter`(대체 `Helvetica Neue, sans-serif`). 한글 헤딩은 `Pretendard`(Medium), 본문도 `Pretendard`.
- 허용 크기 집합: {11, 12, 14, 16, 17, 24, 28, 30, 40, 42, 80}pt — 이 집합 밖의 임의 크기 사용 금지
- 슬라이드 헤딩: 30pt / Newsreader 500 / 자간 0 / 행간 1.2 / 최대 2줄 (표지 타이틀만 40pt)
- 섹션 라벨: 11pt / Inter 500 / 자간 +8% / 대문자 / 색 cool steel
- 본문: 17pt / Inter 400 / 행간 1.45 / 슬라이드당 6줄 이하
- 캡션·리드·설명: 12pt / Inter 400 / 색 보조 텍스트
- 미니헤더·값 레이블·사건 라벨: 14pt / Inter 400~600 또는 세리프
- 항목명·평결·다음 단계: 16pt / 세리프 500
- 풀쿼트: 24pt / 세리프 500, 블록 메트릭: 28pt / 세리프 500
- KPI 대형 수치: 42pt / Newsreader 500 / tabular
- 디바이더 거대 섹션 번호: 80pt / 세리프 / steel 윤곽(채움 없음·윤곽 1pt)
- 표 숫자: 14pt / Inter 400 / tabular numerals
- 행간 집합: 헤딩 1.2 / 본문 1.45 / 수치·KPI 1.1 — 그 외 행간 사용 금지

## 레이아웃 / 그리드
- **중앙 정렬 축(balanced) + 고정 외곽 여백.** 좌·우·상 외곽 여백 각 64px(콘텐츠 폭 1152px, x=64~1216), 하단 풋라인 baseline y=664(하단에서 56px) 고정 — 모든 슬라이드 동일, 드리프트 금지.
- 12열 그리드, 거터 0.2in, 핵심 콘텐츠는 캔버스 중심선(x=640) 기준 정렬 경향, 떠다니는(off-grid) 요소 금지.
- 텍스트 안전영역: y=88~664 — 이 밖으로 텍스트를 내보내지 않는다.
- 슬라이드 헤더 공통: 11pt steel 섹션 라벨(자간 +0.14em) baseline y=104 → 30pt 세리프 헤딩 baseline y=140 → 1pt 룰 라인 `#2C313B` y=160(콘텐츠 폭 전체). 덱 전체 동일 y 고정.
- 헤딩은 일관 크기, 강조는 steel 색으로(문장 중간 단어 비대 금지). 수직 리듬 24/32/48px 스텝.
- 1pt 룰 라인이 콘텐츠 구획 장치 — 섹션 분리·표 행·카드 경계, 덱 전체 1pt 일관.
- **구성 균형:** 캔버스의 어느 한 영역도 ~20%를 넘게 비우지 않는다. 빈 슬레이트 공간을 한 구석에 고이게 두지 않고 1pt 룰로 구획된 모듈로 고르게 채운다.
- **밀도 원칙:** 정연한 코퍼레이트 미감이라고 슬라이드가 비어도 된다는 뜻이 아니다 — 1pt 룰로 구획된 **모듈 3개 이상**(본문 분해 + 차트/표 + KPI 카드 또는 콜아웃)이 정연히 공존한다. 본문 슬라이드는 캔버스 87% 이상을 의미 있는 모듈로 채운다. 거대 슬레이트 여백에 차트 하나만 띄우는 것 금지.
- **모듈 좌표 컨벤션:** 6:6 분할(경계 x=640, 좌 본문 + 우 차트/카드) 또는 헤더 하단 풀폭 차트 + 1pt 룰 + KPI 스트립의 상하 2단. 모듈 사이 거터 0.2in, 경계는 1pt 룰.
- **콜아웃 모듈:** 슬레이트 패널 `#2C313B` + 좌측 1pt steel 룰, 안에 14pt 인사이트 1~2줄 + 11pt steel 라벨. 패널 높이는 내용 높이 + 패딩 0.16in — 하단 절반이 비지 않는다. 차트·표 옆에 1개 두어 해석을 명시.
- 대문자 steel 라벨: 자간 +0.14em / 11pt 일관
- 모든 본문성 슬라이드: 좌하단 출처 각주 12pt + 우하단 페이지 번호 12pt를 풋라인 baseline y=664에 정렬
- 수치는 tabular figures 우정렬, 표 안 소수점 정렬·소수 자릿수·단위 일관
- 표: 헤더행 하단 1pt steel 룰 + 데이터 행 1pt 헤어라인 룰 + 합계행 굵게, 강조 셀/행은 슬라이드당 1개만

## 형태 / 질감
- 모서리 반경 0px(각진). 보더는 1pt 룰 라인 `#2C313B` — 두껍게 쓰지 말 것(강조 시에만 1pt steel).
- 그림자: offset 0 / blur 0 / alpha 0. 그라디언트·글로우 전면 금지.
- 패널은 `#2C313B` 채움, 내부 기본 패딩 24px. cool steel은 면으로 절제 — 라벨·차트·룰에.
- 룰 라인 굵기 집합: {0.5pt(격자·헤어라인), 0.75pt(축), 1pt(구획·보더·강조)} — 그 외 굵기 금지.
- 아이콘은 1pt 가는 라인 단색 steel, 20×20px 그리드. 정제된 평면.

## 차트·데이터 시각화 (코퍼레이트 차트 — 슬레이트 + steel 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 차갑고 정제된 코퍼레이트 미감.
- **데이터 색:** 막대·선 기본 `#4A5160`(연) / `#9298A4`(진). 강조 1개만 cool steel `#7FA9C9` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px. 베이스라인 0(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선은 y축 주요 눈금 2~3개 0.5pt `#2C313B`만. 차트 테두리 박스 제거. x축선 0.75pt `#9298A4`.
- **값 레이블:** 막대 상단·꼭짓점 위 8px 직접 표기, 14pt Inter 400 tabular `#E6E8EC`. 범례 박스 금지 — 직접 라벨링.
- **라인 차트:** 1pt steel 폴리라인, 면적 채움 없거나 steel 8%, 강조 시점만 지름 8px steel 원 마커.
- **도넛:** 1개만, 외경 240px·링 두께 40px·조각 3개 이하. 파이 다중·3D 금지.
- **가로 막대(순위):** 막대 높이 32px·간격 20px, 라벨 좌측 14pt·값 우측 14pt tabular.
- **스택 막대:** 세그먼트 2~3개(무채 명도 단계 + 강조 1세그먼트 steel), 세그먼트 사이 1px 배경색 구분선.
- **축 카테고리 라벨:** x축 아래 +16px, 12pt `#9298A4` — 회전 금지(길면 축약).
- **출처:** 차트 하단 좌측 12pt Inter `#9298A4` 출처·단위 각주.

## 다이어그램·컴포넌트 (코퍼레이트 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 슬레이트 패널 `#2C313B` + 1pt 룰 보더, 커넥터는 1pt 가는 라인(셰브론 화살촉 8×8px), 단계 번호는 11pt steel, 강조는 steel 텍스트·1pt steel 룰.
- **프로세스 플로우:** 좌→우 사각 노드 4~5단계(각 폭 190~220px·높이 100px) — 슬레이트 패널 + 1pt 룰 보더, 노드 사이 1pt 셰브론. 각 노드 좌상단 11pt steel 단계 번호. 현재 단계만 좌측 1pt steel 룰.
- **타임라인:** 수평 축 0.75pt `#9298A4`. 마일스톤 0.12in steel 윤곽 원(현재 시점만 steel 솔리드). 날짜 라벨 축 아래 12pt, 사건 라벨 축 위 세리프 14pt.
- **비교(2~3열):** 1pt 룰 격자 칼럼 — 헤더 행 11pt 대문자 + 하단 1pt steel 룰. 수치 셀 tabular 우정렬. 우세 칼럼만 헤더 steel 텍스트.
- **매트릭스 2×2:** 1pt 룰 십자축. 사분면 라벨 세리프 14pt. 데이터 포인트 0.14in steel 윤곽 원(핵심만 steel 솔리드). 축 라벨 바깥 11pt 보조 텍스트.
- **계층/퍼널:** 폭 비례 사각 적층(각 단 높이 64px) — 슬레이트 명도 단계, 핵심 단만 steel 룰. 레벨 라벨 우측 세리프 14pt.
- **KPI·스탯 카드:** 슬레이트 패널 + 1pt 룰 보더, 11pt 대문자 라벨 + 42pt Newsreader 500 수치 + 14pt steel 델타. 카드 3~4개 가로 균등, 1pt 룰 구분.
- **목차 컴포넌트:** `01`~`NN` steel 번호 + 세리프 16pt 항목명 + 1pt 룰 구분 + 페이지 번호 tabular.
- **섹션 디바이더:** 슬레이트 전면 + 중앙 80pt 세리프 steel 윤곽 섹션 번호 + 30pt 세리프 섹션명 + 1pt steel 룰 폭 288px.
- **인용:** 슬레이트 패널 + 좌측 1pt steel 룰 + 24pt 세리프 풀쿼트(최대 3줄) + 12pt 출처.

## 전환 (PPT)
subtle — 1pt 룰 라인과 콘텐츠가 200ms ease-out으로 짧게 페이드 인하는 정도만. 슬라이드·바운스·글로우 모션 금지.

## 하지 말 것
- 골드·따뜻한 강조 금지 — 차가운 cool steel만(골드는 다른 다크 IR·heritage 팩의 자리).
- 글로우·라디얼 그라디언트 금지(SaaS 다크 팩의 자리).
- 둥근 카드·이모지·클립아트 금지. 룰 라인을 두껍게 쓰지 말 것 — 1pt 유지.
- 헤딩에 산세리프만 쓰지 말 것 — 세리프 헤딩 + 산세리프 본문 혼합이 정체성.
- 허용 크기 집합 {11~80}pt 밖의 임의 폰트 크기 금지.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.
- **거대 슬레이트 여백에 차트/표 하나만 두고 비우기 금지.** 정연함 ≠ 빈약 — 본문/차트/비교/타임라인 슬라이드는 1pt 룰로 구획된 모듈 3개 이상 + 출처 각주 + 페이지 번호.
- **캔버스 한 구석에 죽은 슬레이트 공백 금지 / 빈 플레이스홀더 패널 금지 / 헤딩 문장 중간 단어 비대 금지 / 외곽 여백 64px·풋라인 baseline y=664·헤딩 baseline y=140 드리프트 금지.**

## 상세 페이지 (7종)
전역 규칙(색·타이포·헤더 공통부·풋라인)은 상속한다. 아래는 각 페이지 고유의 좌표·구성만 기술한다(1280×720 기준).

### 01 · 표지 (cover)
- 상단 대문자 steel 라벨 11pt: baseline y=200 중앙 정렬
- 타이틀 40pt Newsreader 500: baseline y=320 중앙 정렬, 최대 2줄(줄 간격 56px)
- 타이틀 하단 1pt steel 룰: 폭 288px(3in) 중앙, y=352
- 부제 17pt Inter: baseline y=396 중앙 정렬
- 도큐먼트 메타 행(`PREPARED FOR`·`DATE`·`VERSION`): 셀 3개 각 폭 240px·높이 48px, 셀 사이 1pt 룰 구분, 중앙 배치 y=452~500 — 라벨 11pt 대문자 + 값 12pt
- 하단 메타 12pt 보조 텍스트 + 페이지 번호: baseline y=664 중앙 정렬
- 표지는 절제 허용 — 모듈 4개(라벨·타이틀·부제·메타 행), 전 요소 중심 x=640 정렬
- 표지 배경은 전면 `#1A1E26` — 패널·차트·사진 없음

### 02 · 목차 (agenda)
- 공통 헤더부(라벨 y=104·헤딩 y=140·1pt 룰 y=160) 적용
- 좌측 7열 x=64~736: 목차 5항목, 행 높이 76px, y=200부터 적층, 항목 사이 1pt 룰
- 항목 구성: steel 번호 16pt → 세리프 16pt 항목명 → 12pt 보조 설명 1줄 → 우측 끝 12pt 페이지 번호 tabular 우정렬
- 현재 섹션: 좌측 1pt steel 룰(진행 인디케이터), 강조 1항목만
- 우측 5열 x=760~1216: 슬레이트 패널 + 1pt 룰 보더, 내부 패딩 24px, y=200~580
- 패널 내부: 11pt steel 라벨 + 핵심 takeaway 3개(steel 번호 + 14pt 본문, 행 간격 32px)
- 좌우 영역 사이 거터 24px — 경계에 룰 없음, 여백으로 분리
- 페이지 번호 12pt: baseline y=664 우정렬
