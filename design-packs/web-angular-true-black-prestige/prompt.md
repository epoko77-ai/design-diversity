# 앵귤러 트루블랙 프레스티지 — web 디자인 팩

spec_version: v3.1-2026-08-16

## 이 스타일의 정체성
순흑(true black) 캔버스 위에 헥사곤·예각 사선으로 clip-path된 패널이 비대칭으로 날카롭게 맞물리고, all-caps 압축 Neo-Grotesk가 공격적으로 외치며, 골드 1px 보더가 각진 모서리를 따라 빛나는 프레스티지 사이트다. 무엇을 보면 이 스타일임을 아는가 — 둥근 모서리가 단 하나도 없고 모든 패널이 헥사곤이나 예각 사선으로 잘려 있다, 배경은 회색조차 아닌 완전한 `#000000`이다, 헤드라인이 세로로 길게 압축된 콘덴스드 산세리프 대문자다, 골드는 면이 아니라 각진 1px 보더와 작은 라벨로만 등장한다.

## 색
- 배경: `#000000` (true black). 헥스 패널·표면: `#161616`.
- 텍스트: `#E8E8E8`. 보조·라벨: `#7C7C7C`.
- 강조: 골드 단 하나 — `#C9A24A`. 각진 1px 보더·라벨·구분선에만. 큰 면 배경 절대 금지. 적용 면적 6% 이하.
- 색 역할 면적 배분(뷰포트 기준): `#000000` 55% 이상, `#161616` 패널 35% 이하, 골드 6% 이하.
- 대비 실측: 본문 `#E8E8E8` on `#000000` ≈ 17.9:1 (AAA). 보조 `#7C7C7C` on `#000000` ≈ 5.0:1 (AA). 골드 `#C9A24A` on `#000000` ≈ 8.7:1 (AAA).
- 패널 경계 `#161616` on `#000000` ≈ 1.4:1 — 의도적 저대비 표면 차. 경계 시인성은 골드 1px 보더가 담당하므로 패널을 이보다 밝게 올리지 않는다.
- 헥사곤 와이어프레임 배경 패턴: 골드 opacity 0.06–0.12 — 장식 전용, 텍스트와 겹칠 때 0.06 이하.

## 타이포그래피
- 디스플레이: `Saira Condensed`(Google Fonts) weight 700, 대체 `Oswald, 'Arial Narrow', sans-serif`. H1 `clamp(2.6rem, 6vw, 5.5rem)`, 대문자, line-height 0.98, `letter-spacing: 0.01em`.
- H3(카드 제목): `Saira Condensed` 700 `1.4rem` 대문자, line-height 1.1.
- 본문: `Saira`(Google Fonts) weight 400, `1rem`, line-height 1.6, 측정 58–66자, 본문 블록 폭 상한 `560px`.
- 키커/섹션 라벨: `Saira` weight 600, `0.72rem`, 대문자, `letter-spacing: 0.22em`, 색 `#C9A24A`.
- 스펙/인덱스 숫자: `Saira` weight 700, `font-variant-numeric: tabular-nums`, 큰 수치 `clamp(2rem,3vw,3rem)`, 단위 접미사 `0.7em`.
- 사용 가능한 텍스트 크기 집합(이외 금지): `0.72rem / 1rem / 1.4rem / clamp(2rem,3vw,3rem) / clamp(2.6rem,6vw,5.5rem)`.
- 웨이트 집합: Saira 400·600 / Saira Condensed 700만.

## 레이아웃 / 그리드
- 콘텐츠 최대 폭: `1320px`. 브레이크포인트: `768px`, `1120px`.
- 비대칭 — 균등 그리드가 아니라 크기·각도가 어긋난 헥사곤/사선 패널이 긴장감 있게 겹쳐 맞물림. 패널 오버랩 16–32px 일관.
- 섹션 수직 리듬: `clamp(72px, 9vw, 112px)` (dense). 데스크탑 1280px 뷰포트 기준.
- 헥사곤·사선 패널은 `clip-path: polygon()` — 사선 각도 12–22° 범위만(이외 각도 금지).
- **구성 균형 — 평면 보이드 금지.** 빈 순흑 영역에는 옅은(opacity 0.06–0.12) 헥사곤 와이어프레임 SVG 패턴, 골드 1px 사선 액센트 라인 2–3개, 또는 골드 인덱스 라벨 그룹을 깐다. 이미지 패널은 clip-path된 실제 비주얼 또는 와이어프레임 SVG로 채운다.
- **간격 리듬:** 8px 베이스 스케일. 키커↔H1 16px, H1↔본문 24px, 본문↔CTA 32px, 패널 내부 패딩 32px. 골드 보더 1px 두께 통일.

## 형태 / 질감
- 헥사곤·예각 사선 `clip-path`가 형태 정체성. radius `0px` 전역 — 둥근 모서리 절대 금지.
- 보더: `1px solid #C9A24A` — clip-path 패널 가장자리를 따라(가상요소 또는 SVG stroke). 일반 패널 보더 `1px solid #161616`.
- 그림자 없음(`box-shadow: none` 전역). 깊이는 패널 명도 차와 골드 보더로.
- 아이콘: 1.5px 스트로크 각진 지오메트릭 라인, 28px 박스, 색 `#7C7C7C`. 헥사곤·예각 모티프로 크래프트. 둥근 아이콘·이모지·제너릭 세트 금지.
- 이미지: 헥사곤 또는 사선 clip-path 필수, `filter: saturate(0.9) brightness(0.85)`, `object-fit: cover`. 직사각형 그대로 금지.
- 버튼: 평행사변형(`clip-path: polygon()` 사선 12–22°) — 투명 + `1px solid #C9A24A` + 골드 텍스트, 패딩 `12px 28px`, 대문자 `0.72rem` letter-spacing 0.16em.

## 상태
- default: 패널 골드 보더 `#C9A24A` 1px, 라벨 letter-spacing 0.22em.
- hover: 골드 보더 `#C9A24A → #E0BC66`(180ms), 사선 엣지 라인 1px → 1.5px, 라벨 letter-spacing 0.22em → 0.26em. 패널 이동·확대 금지.
- focus-visible: `outline: 2px solid #C9A24A; outline-offset: 3px` — clip-path 밖으로 보이도록 offset 유지.
- active: 골드 텍스트 `brightness(0.9)`, 100ms.
- 버튼 hover: 보더·텍스트 `#C9A24A → #E0BC66`, 채움 없음.

## 모션
- 전환: `subtle` — `180ms cubic-bezier(0.4, 0, 0.2, 1)`. 대상: border-color·color·opacity·clip-path·letter-spacing.
- 스크롤 진입: 패널이 `clip-path` 4% 확장 + `opacity 0→1`, 200ms, 패널 간 80ms stagger. 트리거: 뷰포트 20% 지점(`IntersectionObserver threshold 0.2`).
- 스크롤 거동: 헤더 `position: sticky; top: 0; z-index: 100`. 패럴랙스·핀 금지.
- `prefers-reduced-motion: reduce`: clip-path 확장·stagger 제거, opacity 120ms + 보더 색 변화만.
- playful·바운스·스냅 클립 리빌 금지 — 절제된 120–200ms 마이크로모션만.
