# Folio 포트폴리오 키노트 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 본 문서의 px 좌표는 1280×720 캔버스 기준이며 렌더 해상도에 비례 확대한다. Folio 포트폴리오 키노트 — 슬라이드 한쪽을 큰 작품 이미지 한 점이 채우고 반대쪽에 거대 인덱스 번호(01, 02… 120~160px)와 짧은 케이스 캡션이 비대칭으로 앉는 크리에이티브 포트폴리오/케이스 스터디 키노트. 강조는 coral 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 거대 인덱스 번호(`01`·`02`… Space Grotesk 700, 120~160px)가 모든 케이스 슬라이드의 형태 정체성 — 작품 인덱스, (2) 슬라이드 한쪽은 큰 직사각 작품 이미지 한 점, 반대쪽은 거대 번호 + 짧은 케이스 캡션의 비대칭 배치, (3) 밝은 오프화이트 배경에 coral `#FF5C35` 한 점. 케이스 스터디처럼 흐른다.

## 색 (역할·면적 상한 포함)
- 배경 `#F7F7F5` (밝은 오프화이트) — 캔버스 기본 채움
- 표면(카드) `#FFFFFF`
- 잉크/인덱스 번호 `#141414`
- 강조 coral `#FF5C35` — 인덱스 번호 강조·작은 태그·룰·차트 강조 1계열에만. 노출 면적 합계 슬라이드의 8% 이하(거대 coral 인덱스 번호 포함), 큰 면 채움 금지
- 캡션 `#9A9A9A`
- 차트 무채 데이터 계열: 연 `#CFCFCB` / 진 `#141414`
- 델타 표기: 상승 coral `#FF5C35`·하락 잉크 `#141414`, 부호 +/− 명기
- 강조색은 coral 1개뿐. 그라디언트·다른 컬러 금지
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 전부 `Space Grotesk`(대체 `General Sans, Inter, sans-serif`). 한글은 `Pretendard`.
- 허용 크기 집합: 텍스트 {12, 14, 18, 26, 36, 56}pt + 인덱스 번호 {80, 100, 110, 120~160}px — 이 밖의 임의 크기 사용 금지
- 거대 인덱스 번호: 120~160px(케이스), 100~110px(표지·본문 코너), 80px(목차·프로세스) / Space Grotesk 700 / 자간 -3% / tabular numerals
- 슬라이드 제목: 36pt / Space Grotesk 700 / 자간 -1% / 행간 1.15 / 최대 2줄
- 케이스 캡션·본문: 18pt / Space Grotesk 400 / 행간 1.45 / 슬라이드당 6줄 이하
- 작은 태그·라벨: 12pt / Space Grotesk 500 / 자간 +6% / 대문자
- 미니헤더·값 레이블·델타: 14pt / Space Grotesk 600
- 풀쿼트: 26pt / Space Grotesk 700
- KPI 대형 수치: 56pt / Space Grotesk 700 / tabular
- 행간 집합: 제목 1.15 / 본문·캡션 1.45 / 인덱스 번호·KPI 수치 1.0 — 그 외 행간 금지
- 페이지 번호 형식: `03 / 12` — 12pt tabular

## 레이아웃 / 그리드
- **비대칭(asymmetric) + balanced + 고정 외곽 여백.** 좌·우·상 외곽 여백 각 64px(콘텐츠 폭 1152px, x=64~1216), 하단 풋라인 baseline y=668(하단에서 52px) 고정 — 모든 슬라이드 동일, 드리프트 금지.
- 12열 그리드 좌우 비대칭 분할: 7:5(경계 x=736) 또는 5:7(경계 x=544), 거터 0.25in.
- 텍스트 안전영역: y=88~668 — 이 밖으로 텍스트를 내보내지 않는다(엣지 크롭 인덱스 번호만 예외).
- 작품 이미지 면적: 케이스·표지 슬라이드에서 캔버스의 35~55% — 이미지가 이보다 작으면 케이스 스터디로 읽히지 않는다.
- 케이스 슬라이드: 한쪽(5~7열)에 큰 직사각 작품 이미지, 반대쪽에 거대 인덱스 번호 + 제목 + 캡션. 분할 경계는 그리드에 스냅 — 떠다니는 요소 금지. 헤딩 baseline·텍스트 좌측 엣지는 슬라이드 타입별로 동일 위치 고정, 수직 리듬 24/32/48px 스텝.
- 거대 인덱스 번호는 슬라이드 가장자리에 부분적으로 걸치는 엣지 크롭 허용(크롭 폭은 글자 폭의 25% 이하) — 의도적 정렬이며 임의 위치가 아니다.
- **구성 균형:** 캔버스의 어느 한 영역도 ~20%를 넘게 비우지 않는다. 콘텐츠 쪽 빈 오프화이트 공간을 한 구석에 고이게 두지 않고 KPI 카드·태그·콜아웃 모듈로 고르게 채운다.
- **밀도 원칙:** 케이스 스터디 슬라이드는 거대 번호 + 이미지만으로 끝나지 않는다 — 콘텐츠 쪽에 **모듈 3개 이상**(케이스 캡션 + 결과 KPI 카드 + 메타 태그 행, 또는 차트/표 + 콜아웃)을 비대칭으로 정연히 채운다. 본문성 슬라이드는 캔버스 86% 이상을 의미 있는 모듈로. 거대 번호 하나만 두고 비우는 것 금지(간지 예외).
- **모듈 좌표 컨벤션:** 7:5 또는 5:7 분할 — 한쪽 이미지, 다른 쪽 세로 스택(거대 번호 + 제목 + 캡션 + KPI 카드 행 + 태그). 모듈 사이 거터 0.25in.
- **콜아웃 모듈:** 흰 카드(각진, 보더 없음) + 좌측 0.08in coral 룰, 안에 18pt 인사이트 1~2줄 + 12pt 대문자 태그. 카드 높이는 내용 높이 + 패딩 0.2in — 하단 절반이 비지 않는다. 차트·케이스 옆에 1개 두어 결과를 명시.
- **이미지 블록은 실제 비주얼을 담는다:** 작품 사진, 무채 톤 필드 + 12pt 라벨, 또는 차트 — 평면 단색 빈 블록 금지.
- 대문자 태그·라벨: 자간 +0.12em / 12pt 일관
- 모든 본문성 슬라이드: 좌하단 출처 태그 12pt + 우하단 페이지 번호 12pt를 풋라인 baseline y=668에 정렬
- 수치는 tabular figures 우정렬, 소수 자릿수·단위 일관. 비교 표 행 룰 0.5pt `#CFCFCB` 일관, 평결행 굵게, 강조 셀/행은 슬라이드당 1개만.

## 형태 / 질감
- 이미지는 직사각형 그대로(클립·둥근 모서리 없음). 모서리 반경 0px.
- 그림자: offset 0 / blur 0 / alpha 0 — 전면 금지.
- 거대 인덱스 번호가 형태 정체성 — 잉크 `#141414` 솔리드 또는 coral.
- coral 룰 굵기: 카드 상단·좌측 0.08in 고정.
- 아이콘 거의 안 씀 — 쓴다면 1.5pt 가는 라인 단색, 24×24px.

## 차트·데이터 시각화 (포트폴리오 차트 — 잉크 + coral 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 케이스 스터디 미감.
- **데이터 색:** 막대·선 기본 `#CFCFCB`(연) / `#141414`(진). 강조 1개만 coral `#FF5C35` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px. 베이스라인 0(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 2~3개 0.5pt `#CFCFCB`). 차트 테두리 박스 제거. x축선 0.75pt `#141414`.
- **값 레이블:** 막대 상단·꼭짓점 위 8px 직접 표기, 14pt Space Grotesk 600 tabular. 범례 박스 금지 — 직접 라벨링.
- **라인 차트:** 2pt coral 폴리라인, 면적 채움 없음, 강조 시점만 지름 8px coral 원 마커.
- **도넛:** 1개만, 외경 240px·링 두께 40px·조각 3개 이하. 파이 다중·3D 금지.
- **가로 막대(순위):** 막대 높이 32px·간격 20px, 라벨 좌측 14pt·값 우측 14pt tabular.
- **축 카테고리 라벨:** x축 아래 +16px, 12pt `#9A9A9A` — 회전 금지(길면 축약).
- **숫자 포맷:** 천 단위 콤마, 소수 1자리 고정, 단위는 축이 아니라 출처 각주에.
- **출처:** 차트 하단 좌측 12pt Space Grotesk `#9A9A9A` 출처·단위 각주.

## 다이어그램·컴포넌트 (포트폴리오 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 요소는 각진(반경 0px) 흰/오프화이트, 거대 인덱스 번호가 단계·항목을 색인, 커넥터는 2pt 가는 라인(화살촉 8×8px), 강조는 coral 텍스트·0.08in 룰.
- **프로세스 플로우:** 좌→우 거대 인덱스 번호(80px Space Grotesk 700) 3~5개 + 각 아래 18pt 단계 라벨 + 12pt 캡션. 노드 박스 없음 — 거대 번호와 2pt 라인 커넥터가 흐름. 핵심 단계 번호만 coral.
- **타임라인:** 수평 축 0.75pt `#141414`. 마일스톤은 인덱스 번호 라벨 + 0.14in 무채 원(현재 시점만 coral 솔리드). 날짜 라벨 12pt 대문자.
- **비교(2~3열):** 흰 카드 칼럼(각진, 보더 없음) — 각 칼럼 상단에 80px 인덱스 번호 + 12pt 대문자 태그. 우세 칼럼만 상단 0.08in coral 룰.
- **매트릭스 2×2:** 0.75pt 무채 십자축. 데이터 포인트 0.16in 무채 원(핵심만 coral 솔리드) + 옆에 14pt 인덱스 번호. 사분면 라벨 12pt 대문자.
- **계층/퍼널:** 폭 비례 사각 적층(각 단 높이 64px) — 무채 명도 단계, 핵심 단만 coral. 각 단에 인덱스 번호 + 18pt 라벨.
- **KPI·스탯 카드:** 흰 카드(각진, 보더 없음), 좌상단 12pt 태그 + 56pt Space Grotesk 700 수치 + 14pt coral 델타. 카드 3~4개 비대칭 가로 배치, 거터 16px.
- **목차 컴포넌트:** 80px `01`~`NN` 인덱스 번호 세로 나열 + 18pt 케이스명 + 12pt 페이지 번호.
- **섹션 디바이더:** 오프화이트 배경 + 엣지 크롭 거대 인덱스 번호 140px + 36pt 섹션명.
- **인용:** 흰 카드 + 인덱스 번호 80px + 26pt 700 풀쿼트(최대 3줄) + 12pt 출처 태그.

## 전환 (PPT)
playful — 거대 인덱스 번호가 한쪽에서 빠르게 슬라이드 인하며 살짝 오버슈트(220ms ease-out, 오버슈트 6%), 작품 이미지는 100ms 늦게 페이드 인. 케이스 스터디를 넘기는 경쾌한 리듬.

## 하지 말 것
- 둥근 이미지 프레임 금지 — 직사각 이미지(둥근 프레임은 다른 룩북 팩의 자리).
- 그라디언트·그림자·이모지·클립아트 금지.
- 인덱스 번호를 작게 쓰지 말 것 — 케이스 슬라이드는 120~160px 거대해야 한다(형태 정체성).
- coral을 큰 면으로 도배하지 말 것 — 노출 면적 8% 이하, 인덱스 번호·작은 태그·룰에만.
- 강조색 2개 이상 금지. 대칭 중앙 정렬로 회귀 금지 — 비대칭이 정체성.
- 허용 크기 집합 밖의 임의 폰트 크기 금지.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.
- **거대 인덱스 번호 하나만 두고 슬라이드 비우기 금지(간지 예외).** 케이스 스터디는 번호 + 이미지 + 모듈 3개 이상으로 채운다.
- **캔버스 한 구석에 죽은 오프화이트 공백 금지 / 빈 단색 플레이스홀더 이미지 블록 금지 / 케이스 제목 문장 중간 단어 비대 금지(거대 인덱스 번호 외 제목은 일관 크기) / 외곽 여백 64px·풋라인 baseline y=668·헤딩 baseline 드리프트 금지.**

## 상세 페이지 (7종)
전역 규칙(색·타이포·그리드·풋라인)은 상속한다. 아래는 각 페이지 고유의 좌표·구성만 기술한다(1280×720 기준).

### 01 · 표지 (cover)
- 비대칭 분할 5:7 — 좌 콘텐츠 x=64~536 / 우 작품 이미지 x=560~1216·y=64~656(직사각, 보더·그림자 없음)
- coral 대문자 라벨 12pt: baseline y=150
- 거대 인덱스 번호 110px 700: baseline y=330, 좌측 엣지 크롭 허용(x=64에서 -20px까지)
- 타이틀 36pt 700: baseline y=410, 최대 2줄(줄 간격 52px)
- 부제 18pt: 타이틀 마지막 baseline +40px
- 메타 태그 행(`STUDIO`·`YEAR`·`EDITION`): 12pt 대문자 3셀, 셀 간격 32px, baseline y=580
- 우측 이미지 우하단 안쪽 16px에 12pt 캡션 태그(작품명·연도)
- 하단 메타 태그 12pt + 페이지 번호 12pt: baseline y=668
- 표지는 절제 허용 — 모듈 5개(라벨·번호·타이틀·부제·태그 행)

### 02 · 케이스 인덱스 목차 (agenda)
- coral 라벨 12pt baseline y=104 → 헤딩 `Index` 36pt 700 baseline y=148
- 좌측 8열 x=64~832: 목차 5행, 행 높이 88px, y=190부터 적층
- 행 구성: 인덱스 번호 80px 700 → 케이스명 18pt → 캡션 12pt 1줄 → 우측 끝 페이지 번호 12pt tabular 우정렬
- 행 사이 디바이더 0.5pt `#CFCFCB`
- 현재 항목: 번호만 coral(진행 인디케이터), 강조 1항목
- 우측 4열 x=856~1216: 흰 카드(패딩 24px), y=190~630 — 포트폴리오 요지 18pt 2~3줄 + 핵심 케이스 썸네일 1점(폭 312px·높이 220px)
- 좌우 영역 거터 24px

### 03 · 케이스 스터디 본문 (body)
