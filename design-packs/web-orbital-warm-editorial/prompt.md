# 오비탈 웜 에디토리얼 — web 디자인 팩

spec_version: v3.1-2026-08-16 · reference_mode: style_synthesis

## 이 스타일의 정체성
따뜻한 크림 캔버스 위에 완전 라운드 알약(pill) 도형이 궤도처럼 겹쳐 모듈러 블록 그리드로 배치되고, 세리프 헤딩과 산세리프 본문이 에디토리얼 위계를 만들며, 코랄·앰버 듀오가 강조하는 따뜻한 핀테크 브랜드 사이트다. 무엇을 보면 이 스타일임을 아는가 — 알약(border-radius 999px) 도형이 콘텐츠를 담고 또 장식으로 궤도처럼 겹친다, 배경이 따뜻한 크림이고 코랄·앰버만 강조에 쓰인다, 헤딩은 세리프(Fraunces)인데 본문은 산세리프(Inter)다, 알약들이 부드럽게 회전·겹치며 등장하는 playful 모션이 있다.

## 색 — 역할·면적·대비 실측
- 배경 크림 `#F4ECDD`: 기본 캔버스. 카드 표면 `#FFFFFF`.
- 잉크 `#2B2620`: 본문·헤딩. 대비 실측: on `#F4ECDD` = 12.8:1 / on `#FFFFFF` = 15.0:1 (AAA).
- 코랄 `#EB7B4C`: 알약 면·아이콘·장식 전용 — 크림 위 2.4:1이므로 **텍스트 색 사용 금지**(장식 한정, 이것이 의도적 저대비).
- 코랄 딥 `#B04818`: 텍스트용 코랄 — 키커·라벨·링크. on `#F4ECDD` = 4.7:1 / on `#FFFFFF` = 5.6:1 (AA).
- 앰버 `#F3A623`: 보조 알약 면·장식 전용(크림 위 1.7:1 — 텍스트 금지).
- 코랄 면 위 텍스트는 잉크 `#2B2620`(5.3:1) — 흰 텍스트는 2.8:1로 금지. 앰버 면 위도 잉크(7.4:1).
- 메타 그레이 `#7A6E5E`: 4.2:1 — `1.2rem` 이상 캡션·비필수 메타만, 본문 금지.
- 위 6색+흰색 외 hex 0개. 그라디언트 0개.
- 장식 알약 면적: 섹션당 코랄+앰버 장식 합계 8–18% — 콘텐츠보다 커지지 않게.

## 타이포그래피 — 크기 집합 고정
- 헤딩: `Fraunces`(Google Fonts) weight 500, 대체 `Georgia, serif`.
- 본문·UI: `Inter`(Google Fonts) weight 400·500·600, 대체 `sans-serif`. 이 2 family 외 금지 — 헤딩 산세리프 금지.
- H1: `clamp(2.4rem, 4.6vw, 4rem)`, line-height 1.12, letter-spacing `-0.01em`.
- H2: `clamp(1.7rem, 3vw, 2.6rem)`, Fraunces 500, line-height 1.18.
- 카드 제목: `1.3rem`, Fraunces 500, line-height 1.25.
- 본문: `1.05rem`, Inter 400, line-height 1.65, 측정 60–70자.
- 키커/라벨: `0.78rem`, Inter 600, 대문자, letter-spacing `0.12em`, 색 `#B04818`.
- 알약 태그: `0.85rem`, Inter 500.
- 인용문: `clamp(1.3rem, 2.2vw, 1.7rem)`, Fraunces italic, line-height 1.4.
- 크기 집합은 위 7단만 — 집합 밖 임의 크기 금지.

## 반응형 — 브레이크포인트별 값
- CSS 브레이크포인트 2개: `768px`, `1120px`.
- 375px 뷰포트: 1열 스택, 좌우 패딩 24px, 섹션 수직 88px, 장식 알약 섹션당 2점으로 축소, 히어로 이미지 알약이 텍스트 아래.
- 768px 뷰포트: 2열 시작, 좌우 패딩 40px, 섹션 수직 ≈112px, 기능 모듈 2열.
- 1280px 뷰포트: content_max 1180px, 좌우 패딩 56px, 섹션 수직 140px, 모듈러 그리드 풀 컴포지션.
- 장식 알약의 그리드 밖 돌출은 768px 이상에서만 — 375px에서는 뷰포트 안쪽으로 수렴(가로 스크롤 0).

## 레이아웃 / 그리드
- 콘텐츠 최대 폭 `1180px`, 12열 그리드, 거터 24px. 섹션 수직 리듬 `clamp(88px, 10vw, 140px)` — airy.
- 모듈러 블록 — 알약·카드 모듈이 span 4/6/8을 제각각 잡고, 일부 장식 알약은 그리드 밖으로 최대 80px 돌출(궤도 겹침).
- 간격 스케일: 8px 베이스. 키커↔헤딩 16px, 헤딩↔리드문 24px, 리드문↔CTA 32px, 모듈 갭 24px.
- 카드·알약 내부 패딩 28–32px 일관, 텍스트는 형태 안 광학 중앙 정렬.
- 빈 크림 면 처리: 궤도 장식 알약(면 또는 1.5px 윤곽) + 옅은 큰 알약 윤곽 워터마크(opacity 0.12–0.18, 크기 `min(36vw, 420px)`) 1–2점 — 평면 보이드 0.

## 형태 / 질감
- 알약: `border-radius: 999px` — 콘텐츠 컨테이너 + 장식. 가로 pill·세로 pill·원형(1:1) 세 변주.
- 카드·이미지: radius 12–16px — 이 두 단계 외 radius 값 금지.
- 그림자: `0 8px 24px rgba(43,38,32,0.08)` — 떠 있는 알약·hover 상태에만, 정적 카드 전체에 깔기 금지.
- 아이콘: 2px 스트로크 라운드 캡, 색 `#EB7B4C`, 24px 그리드 — 궤도·동전·차트 모티프 크래프트. 이모지 금지.
- 이미지: radius 16px 또는 알약 마스크, 따뜻한 톤.

## 모션
- 기본 전환: `360ms cubic-bezier(0.34, 1.15, 0.64, 1)` — 부드러운 오버슈트.
- 스크롤 진입: 뷰포트 threshold 0.25 트리거, `opacity 0→1` + `translateY(16px→0)` 360ms, stagger 80ms.
- 장식 알약 진입: 궤도 경로 따라 `rotate` + `translate` 600ms. 콘텐츠 알약: `scale(0.92→1)` + 페이드.
- 배경 궤도 회전: `@keyframes orbit` 40s linear infinite — 장식 알약만.
- `prefers-reduced-motion: reduce`: 궤도 회전·rotate·scale 제거, opacity 240ms만.
- 200ms 미만 기계적 스냅 금지 — playful 곡선 이징만.

## 인터랙션 상태
- 버튼(프라이머리) default: 코랄 `#EB7B4C` 솔리드 알약 + **잉크 `#2B2620` 라벨**(5.3:1 — 흰 라벨 금지), 패딩 `13px 32px`, radius 999px.
- 버튼 hover: `scale(1.04)` + 배경 `#D96A3C`(8% 어둡게), 360ms.
- 버튼 focus-visible: `outline: 2px solid #B04818; outline-offset: 3px` — 모든 인터랙티브 요소 공통, outline 제거 금지.
- 버튼 active: scale 0.97, 120ms.
- 세컨더리 버튼: 잉크 1.5px 알약 외곽선 + 잉크 라벨. hover: 배경 잉크 5% 틴트.
- 링크: default `#B04818` + 밑줄 없음. hover: 1.5px 밑줄 등장 + 텍스트 잉크로, 240ms. active: `#9E3F14`.
- 카드 hover: `translateY(-4px)` + `rotate(1.5deg)` + 그림자 등장, 360ms.
- 메뉴 hover: 항목 뒤에 앰버 알약 배경(패딩 `6px 16px`) 페이드 인 240ms + 잉크 텍스트 유지.

## 컴포넌트
- **헤더/내비:** 높이 72px, 크림 배경. 좌 워드마크(Fraunces 500 `1.3rem`), 중앙 메뉴가 흰 알약 컨테이너(radius 999px, 패딩 `8px 12px`)에 담김, 우 코랄 알약 CTA.
- **알약 모듈 카드:** 가로 pill 또는 radius 16px 카드, 흰 표면, 패딩 28–32px. 아이콘↔키커 16px, 키커↔제목 8px, 제목↔본문 12px.
- **궤도 장식:** 코랄·앰버 알약(면:윤곽 = 약 1:1 혼합), 크기 48–200px, 궤도 경로 위 배치 — 무작위 부유 금지.
- **알약 태그:** 코랄 딥 `#B04818` 1.5px 윤곽 + 같은 색 텍스트 `0.85rem`, 패딩 `5px 14px`.
- **로고월 알약:** 흰 알약 컨테이너 높이 64px 균일, 패딩 `0 28px`.

## 하지 말 것
- 알약 없이 둥근 사각형만 쓰기 금지 — pill(999px)이 형태 정체성. radius는 999px/12–16px 두 단계만.
- 코랄·앰버 위 흰 텍스트 금지(2.8:1) — 색 면 위 텍스트는 항상 잉크.
- `#EB7B4C`·`#F3A623`을 텍스트 색으로 쓰기 금지 — 텍스트용 코랄은 `#B04818`.
- 채도 높은 원색·그라디언트·이모지·하드 섀도·글래스 패널 0건.
- 모든 카드에 균일 그림자 금지 — 떠 있는 알약·hover에만.
- 200ms 미만 스냅 모션·직선적 기계 이징 금지 — playful 곡선.
- 평면 크림 보이드·플레이스홀더 박스·궤도 밖 무작위 부유 알약 0건.
- 팔레트 7색(잉크·크림·흰·코랄·코랄 딥·앰버·메타 그레이) 외 hex 0개.

## 상세 페이지 (6종) — 전역 규칙 상속, 아래는 페이지 고유 값

### 1. 히어로 (알약 궤도)
- min-height 86vh, 크림 배경. 좌 6열 텍스트 / 우 6열 알약 모듈 컴포지션.
- 텍스트: 키커 `#B04818` → H1(`clamp(2.4rem,4.6vw,4rem)`, 최대 3줄) → 리드문 `1.15rem`/1.6 → CTA 페어(코랄 알약 + 잉크 외곽선 알약, 간격 16px).
- 우측 중심: 흰 가로 pill 모듈(약 480×220px, 제품 미리보기 비주얼 필수) + 그림자.
- 중심 모듈 주위 장식 알약 4점: 코랄 면 pill 160×64px / 앰버 윤곽 원 96px / 코랄 윤곽 pill 200×56px / 앰버 면 원 48px — 궤도상 배치, 2점은 모듈과 24–40px 겹침.
- 배경 워터마크: 옅은 알약 윤곽 1점(opacity 0.15, 크기 420px, 우상단).
- 장식 알약 orbit 회전 40s, 진입 시 궤도 드로우 600ms + stagger 120ms.
- 375px: 모듈이 텍스트 아래, 장식 알약 2점만(면 pill + 윤곽 원), 겹침 유지.
- 히어로 내 코랄+앰버 장식 면적 합계 ≤ 화면 15%.

### 2. 헤더·내비게이션
- 높이 72px, 크림 배경, 하단 보더 `1px solid #E3D8C2`.
- 좌 워드마크 Fraunces 500 `1.3rem` 잉크, 중앙 메뉴 5개(Inter 500 `0.92rem`)가 흰 알약 컨테이너에 담김 — 컨테이너 그림자 전역 규칙.
- 메뉴 항목 간격 8px(항목 자체 패딩 `6px 16px`), hover 시 앰버 알약 하이라이트 240ms.
- 현재 페이지: 코랄 딥 `#B04818` 텍스트 + 앰버 알약 배경 상시.
- 우측 코랄 알약 CTA(패딩 `10px 24px`, 잉크 라벨).
- 375px: 메뉴 컨테이너 숨김, 우측 원형 햄버거 알약 44×44px(잉크 1.5px 윤곽).
- 모바일 오버레이: 크림 풀스크린, 메뉴 Fraunces `1.8rem` 세로 스택 행 간 28px, 배경에 궤도 장식 알약 2점.
- 오버레이 진입 360ms + 항목 stagger 70ms.

### 3. 기능 그리드 (알약 모듈)
- 모듈 5개 모듈러 배치: 가로 pill 모듈 2개(span 8, 높이 180px) + radius 16px 카드 3개(span 4, 높이 260px) — 높이 위계 2단.
- 각 모듈: 코랄 2px 아이콘 32px → 키커 → Fraunces 제목 `1.3rem` → 본문(최대 3줄).
- 섹션 헤더: 키커 + H2, 좌측 정렬, 헤더↔그리드 48px.
- pill 모듈은 내부 좌우 패딩 40px(곡률 보정 광학 정렬), 카드는 28px.
- 모듈 사이 갭 24px, hover 시 translateY(-4px) + rotate(1.5deg).
- 그리드 우하단 빈 셀 1개는 앰버 윤곽 장식 알약(크기 140px, orbit 회전)으로 채움.
- 768px: 2열(pill 모듈 풀폭), 375px: 1열, pill 모듈 높이 auto(최소 140px).
- 모듈 아이콘은 5개 모두 다른 모티프 — 동일 아이콘 반복 금지.

### 4. 콘텐츠 상세
- 좌 5열 이미지 / 우 7열 텍스트, 컬럼 간 갭 48px.
- 이미지: 알약 마스크(세로 pill 420×560px) 또는 radius 16px, 따뜻한 톤.
- 텍스트: 키커 → H2 → 본문 2단(1120px 이상, 단 간격 40px).
- 본문 아래 알약 태그 3개(간격 8px) — `#B04818` 윤곽 태그.
- 이미지 뒤 배경에 코랄 면 장식 알약 1점(120×48px, 이미지와 32px 겹침) + 앰버 윤곽 원 1점(80px).
- 섹션 배경 워터마크 알약 윤곽 1점(opacity 0.12, 좌하단 360px).
- 인용 1건 삽입: Fraunces italic `clamp(1.3rem,2.2vw,1.7rem)` + 좌측 코랄 4px 라운드 룰.
- 768px 미만: 본문 1단, 이미지 폭 100%(가로 pill 마스크로 전환, 높이 240px).

### 5. 후기·로고월
- 상단 후기 카드 3개(span 4, radius 16px, 흰 표면, 패딩 32px), 갭 24px.
- 카드 구성: 인용문 Fraunces italic → 알약 아바타 48px 원형 + 인물명 Inter 600 `0.95rem` 잉크 + 직함 `0.85rem` 잉크 opacity 0.7(메타 그레이는 0.85rem에서 대비 미달이라 금지).
- 인용문↔인물 행 24px, 아바타↔이름 12px.
- 가운데 카드만 상단 32px 오프셋(모듈러 어긋남) — 768px 미만에서 해제.
- 하단 로고월: 흰 알약 컨테이너 6개, 높이 64px 균일, 갭 16px, 가로 1행(넘치면 2행 랩).
- 로고월 위 라벨: 키커 스타일 중앙 정렬, 라벨↔로고월 32px.
- 후기 섹션 배경: 크림 유지 + 우상단 앰버 윤곽 장식 알약 1점(160px, orbit).
- 후기↔로고월 수직 간격 80px.

### 6. CTA·푸터
- CTA 패널: 코랄 `#EB7B4C` 솔리드, radius 999px(데스크탑 가로 pill, 높이 ≈320px) — 내부 좌우 패딩 `clamp(48px,8vw,96px)`.

- 375px: 패널 radius 48px(pill 해제), 내부 패딩 32px, 세로 중앙 정렬.
- 푸터: 크림 배경, CTA↔푸터 96px. 4컬럼(워드마크+소개 / 제품 / 회사 / 법적고지), 갭 24px.

- 소셜: 원형 알약 40px(잉크 1.5px 윤곽), 간격 12px, hover 시 코랄 면+잉크 아이콘.

- 375px: 컬럼 2열 랩(워드마크 풀폭), 컬럼 행 간 40px.
