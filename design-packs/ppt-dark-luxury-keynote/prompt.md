# 다크 럭셔리 키노트 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 본 문서의 px 좌표는 1280×720 캔버스 기준이며 렌더 해상도에 비례 확대한다. 다크 럭셔리 키노트 — 거의 순흑 무대에 풀블리드 제품/라이프스타일 사진이 떠 있고, 샴페인 골드 0.5pt 헤어라인 프레임이 사진·텍스트 군집을 절제되게 두르며, 넓은 자간의 가는 디스플레이 세리프 라벨이 럭셔리를 만드는 키노트.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 거의 순흑 `#0B0B0C` 무대에 풀블리드 제품/라이프스타일 사진이 한쪽 또는 전면을 채운다, (2) 샴페인 골드 0.5pt 헤어라인이 사진·텍스트 군집을 절제된 프레임으로 두른다 — 절대 면으로 안 쓴다, (3) 가는 디스플레이 세리프(Cormorant Garamond) 라벨이 넓은 자간(0.12em)으로 럭셔리 카탈로그처럼 앉는다. 넓은 여백.

## 색 (역할·면적 상한 포함)
- 배경 near-black `#0B0B0C` — 캔버스 기본 채움
- 패널 `#1A1A1C` — 패널·톤 필드 하한 채움
- 강조 샴페인 골드 `#C9A36A` — 0.5pt 헤어라인 프레임·라벨·차트 강조 1계열에만. 노출 면적 합계 슬라이드의 3% 이하, 면 채움 절대 금지
- 텍스트 `#EDEAE3`
- 보조 텍스트 `#8E8A82`
- 차트 무채 데이터 계열: 연 `#3A3A3C` / 진 `#8E8A82`
- 모노그램 톤온톤: `#232326`(패널보다 한 단계 밝은 톤, 배경 대비 명도 차 ≤10%)
- 강조색은 샴페인 골드 1개뿐. 화려한 컬러 그라디언트·글로우 금지(순흑↔`#1A1A1C` 미세 톤 필드만 예외)
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 헤딩·본문 `Cormorant Garamond`(하이콘트라스트 디스플레이 세리프, 대체 `'Times New Roman', serif`). 캡션 `Inter` 300(대체 `Helvetica Neue, sans-serif`). 한글 헤딩은 `Pretendard`(Light), 본문도 `Pretendard`.
- 허용 크기 집합: {10, 11, 13, 14, 20, 28, 34, 48, 52, 54}pt — 이 집합 밖의 임의 크기 사용 금지
- 디스플레이 타이틀: 표지 54pt·간지 48pt / Cormorant Garamond 500 / 자간 +0.12em / 행간 1.1 / 최대 2줄
- 슬라이드 헤딩: 34pt / Cormorant Garamond 500 / 자간 +0.08em / 최대 2줄
- 본문: 20pt / Cormorant Garamond 400 / 행간 1.5 / 슬라이드당 5줄 이하
- 캡션·라벨: 11pt / Inter 300 / 자간 +0.2em / 대문자 / 색 보조 텍스트 또는 골드
- 값 레이블·델타·미니 리스트: 13~14pt / Inter 300 또는 세리프 400
- 풀쿼트: 28pt / Cormorant Garamond 500
- KPI 대형 수치: 52pt / Cormorant Garamond 500 / 자간 +0.04em / tabular
- 출처·차트 각주: 10pt / Inter 300 / `#8E8A82`

## 레이아웃 / 그리드
- **풀블리드(airy) + 고정 안전 여백.** 콘텐츠 안전 여백 좌·우·상 각 72px(콘텐츠 폭 1136px, x=72~1208), 하단 풋라인 baseline y=664(하단에서 56px) 고정 — 모든 슬라이드 동일. 풀블리드 사진은 마진을 무시하고 엣지투엣지, 텍스트·헤어라인 모듈은 안전 여백 안에 정렬.
- 풀블리드 사진 영역과 텍스트 영역의 경계는 12열 그리드 분할선에 스냅: 2/3 분할 = 8열:4열, 절반 = 6열:6열(경계 x=640).
- 텍스트 군집은 0.5pt 골드 헤어라인 프레임으로 두름(프레임 내부 패딩 32px). 텍스트 좌측 엣지는 덱 전체 동일 x. 수직 리듬 24/32/48px 스텝.
- **타이틀 baseline·풋라인 고정:** 콘텐츠 슬라이드 헤딩 baseline은 덱 전체 y=148 통일, 풋라인(캡션 + 페이지 번호)은 baseline y=664 — 드리프트 금지.
- **두 종류의 슬라이드:** (1) **에디토리얼**(표지·간지·클로징) — 풀블리드 사진/비주얼 필드가 캔버스 전체를 균형 있게 채우고 절제된 텍스트를 얹는다. (2) **콘텐츠**(본문·비교·차트·갤러리) — 사진은 절반 정도, 나머지 절반을 0.5pt 골드 헤어라인 프레임으로 구획된 **모듈 3개 이상**(본문 + KPI 카드 또는 표 + 콜아웃)으로 채운다. "럭셔리하지만 빈약하지 않다".
- **구성 균형 — 죽은 공백 금지:** 캔버스의 어느 한 영역도 ~20%를 넘게 비우지 않는다. 사진이 덜 채우는 자리는 따뜻한 조명톤 필드(`#0B0B0C`→`#1A1A1C` 미세 톤차)·거대 세리프 모노그램·골드 헤어라인 디테일로 채운다 — 평면 빈 검정 공백 절대 금지. 여백은 모듈 사이 호흡으로 분산.
- **모듈 좌표 컨벤션:** 콘텐츠 슬라이드는 좌 절반 사진(x=0~640) + 우 절반 세로 스택(헤딩 + 본문 + KPI 헤어라인 카드 행 + 콜아웃). 모듈은 모두 0.5pt 골드 헤어라인 프레임, 모듈 사이 거터 0.25in, 12열 그리드 스냅 — 떠다니는 요소 금지.
- **골드 헤어라인 콜아웃:** 0.5pt 골드 헤어라인 프레임(채움 없음) + 20pt 세리프 인사이트 1~2줄 + 11pt 골드 캡션 라벨. 박스 높이는 내용 높이 + 패딩 0.2in — 하단 절반이 비지 않는다. 차트·본문 옆에 1개.
- 대문자 캡션·라벨: 자간 +0.12~0.2em / 11pt 일관, 골드 또는 보조 텍스트
- 헤어라인: 덱 전체 0.5pt 일관(강조 시만 1pt)
- 모든 콘텐츠 슬라이드: 좌하단 출처 캡션 10pt + 우하단 페이지 번호 11pt를 풋라인 baseline y=664에 정렬
- 수치는 tabular figures, 소수 자릿수·단위 일관, 강조 셀/행은 슬라이드당 1개만

## 형태 / 질감
- 모서리 반경 0px. 보더는 0.5pt 골드 헤어라인 프레임만.
- 그림자: offset 0 / blur 0 / alpha 0. 그라디언트·글로우 전면 금지(미세 톤 필드 예외).
- 골드 헤어라인 프레임 — 사진·텍스트 군집을 가는 직사각 라인으로 두름(면 채움 없음).
- 사진은 어둡고 무드 있게: 노출 -15~-30%, 비네트 허용(가장자리 명도 -10% 이내).
- 아이콘 거의 안 씀 — 쓴다면 0.75pt 가는 라인 골드 단색, 20×20px.

## 차트·데이터 시각화 (럭셔리 차트 — 순흑 + 골드 헤어라인)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 럭셔리 헤어라인 미감.
- **데이터 색:** 막대·선 기본 `#3A3A3C`(연) / `#8E8A82`(진). 강조 1개만 샴페인 골드 `#C9A36A` 솔리드 또는 골드 헤어라인 윤곽. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 1 : 1(넓은 간격 — 럭셔리 여백). 모서리 0px. 베이스라인 0(잘린 y축 금지). 막대는 0.5pt 헤어라인 윤곽 또는 무채 솔리드, 강조만 골드.
- **라인 차트:** 0.75pt 골드 헤어라인 폴리라인, 면적 채움 없음, 마커 0.1in 골드 윤곽 원(선 굵기 0.5pt).
- **데이터 잉크 최소화:** 격자선 전면 제거. 차트 테두리 박스 제거. 축선 0.5pt `#3A3A3C` 또는 생략.
- **값 레이블:** 막대 상단·꼭짓점 위 8px 직접 표기, 13pt Inter 300 자간 +0.1em `#EDEAE3`. 범례 박스 금지 — 직접 라벨링.
- **도넛:** 1개만, 외경 240px·링 두께 32px·조각 3개 이하·0.75pt 헤어라인 분할. 파이 다중·3D 금지.
- **출처:** 차트 하단 좌측 10pt Inter 300 `#8E8A82` 출처·단위 각주.

## 다이어그램·컴포넌트 (럭셔리 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 0.5pt 골드 헤어라인 프레임(채움 없음 또는 패널 `#1A1A1C`), 커넥터는 0.5pt 골드 헤어라인(화살촉 8×8px), 단계 번호는 넓은 자간 세리프, 강조는 골드 헤어라인 1pt 또는 골드 텍스트.
- **프로세스 플로우:** 좌→우 사각 노드 4~5단계(각 폭 190~220px·높이 110px) — 0.5pt 골드 헤어라인 프레임(채움 없음), 노드 사이 0.5pt 골드 커넥터. 각 노드에 세리프 단계 번호 20pt(자간 +0.12em). 현재 단계만 1pt 골드 헤어라인.
- **타임라인:** 수평 축 0.5pt 골드 헤어라인. 마일스톤 0.1in 골드 윤곽 원(현재 시점만 골드 솔리드). 날짜 라벨 11pt 캡션체 자간 +0.16em.
- **비교(라인업):** 0.5pt 골드 헤어라인 격자 칼럼 — 헤더 11pt 대문자 골드 캡션체. 각 칼럼에 제품 사진 + 세리프 본문. 우세 칼럼만 1pt 골드 헤어라인.
- **매트릭스 2×2:** 0.5pt 골드 헤어라인 십자축. 사분면 라벨 세리프 20pt 자간 +0.08em. 데이터 포인트 0.12in 골드 윤곽 원(핵심만 골드 솔리드).
- **계층/퍼널:** 폭 비례 사각 적층(각 단 높이 72px) — 0.5pt 골드 헤어라인 프레임, 핵심 단만 1pt. 레벨 라벨 우측 세리프 20pt.
- **KPI·스탯 카드:** 0.5pt 골드 헤어라인 프레임 카드(채움 없음 또는 패널), 11pt 대문자 골드 라벨 + 52pt Cormorant Garamond 500 수치 + 13pt 델타. 카드 3~4개 넓은 간격(거터 ≥32px).
- **목차/섹션 디바이더/인용:** 목차는 세리프 `01`~`NN` 골드 번호(자간 +0.12em) + 20pt 세리프 항목명 + 0.5pt 골드 헤어라인 구분. 디바이더는 풀블리드 다크 사진 + 0.5pt 골드 헤어라인 프레임 + 중앙 48pt 세리프 섹션명 + 11pt 골드 캡션 번호. 인용은 0.5pt 골드 헤어라인 프레임 + 28pt 세리프 풀쿼트 + 11pt 출처 캡션.

## 전환 (PPT)
subtle — 골드 헤어라인 프레임이 220ms ease-out으로 가늘게 그려지듯 페이드 인, 풀블리드 사진은 250ms 페이드. 우아하고 절제되게, 슬라이드·바운스·글로우 금지.

## 하지 말 것
- 골드를 큰 면·버튼 배경으로 쓰지 말 것 — 노출 면적 3% 이하, 0.5pt 헤어라인·라벨·차트 1계열에만.
- 산세리프 헤딩 금지 — 디스플레이 세리프(Cormorant Garamond)가 정체성(시네마틱 다크 팩과의 분리선).
- 글로우·컬러 그라디언트·그림자·둥근 모서리·이모지 금지.
- 사진 없이 텍스트만으로 채우지 말 것 — 풀블리드 비주얼이 정체성.
- 자간을 좁게 쓰지 말 것 — 라벨은 넓은 자간(+0.12~0.2em)이 럭셔리.
- 허용 크기 집합 {10~54}pt 밖의 임의 폰트 크기 금지.
- 차트 회귀: 3D, 무지개색, 격자선, 범례 박스, 잘린 y축, 출처 누락.
- **콘텐츠 슬라이드(본문·비교·차트)를 사진 하나 + 텍스트 한 줄로 비우기 금지** — 골드 헤어라인 모듈 3개 이상으로 채운다.
- **캔버스 한 구석에 죽은 평면 검정 공백 금지** — 특히 표지의 작은 패널 + 우측 평면 빈 검정 구성 절대 금지. 빈 영역은 조명톤 필드·세리프 모노그램·골드 헤어라인 디테일로 채운다.
- **빈 골드 헤어라인 플레이스홀더 프레임 금지** — 프레임은 반드시 실제 렌더된 비주얼(사진·톤 필드·차트·모노그램)을 담는다.
- **헤드라인 문장 중간 단어 비대 금지 / 여백·풋라인 baseline y=664·타이틀 baseline 드리프트 금지.**

## 상세 페이지 (6종)
전역 규칙(색·타이포·그리드·풋라인)은 상속한다. 아래는 각 페이지 고유의 좌표·구성만 기술한다(1280×720 기준).

### 01 · 표지 (cover)
- 구성 (a) 풀블리드: 캔버스 전체(1280×720) 다크 사진(노출 -15~-30%), 좌측 텍스트 군집을 사진 위에 직접 얹음 / 구성 (b) 분할: 좌측 텍스트 + 우측 x=640~1280 조명톤 필드(`#0B0B0C`→`#1A1A1C` 세로 방향) + 거대 세리프 모노그램
- 모노그램(구성 b): 브랜드 이니셜 1~2자, 높이 460px(캔버스의 64%), 색 `#232326` 톤온톤, 중심 x=960
- 골드 디테일(구성 b): 코너 브래킷 4개(각 40×40px·0.5pt) + 수직 헤어라인 1~2줄(높이 200px)
- 텍스트 군집 프레임: x=72~470을 0.5pt 골드 헤어라인으로 두름, 내부 패딩 32px
- 대문자 라벨 11pt 골드(자간 +0.16em): baseline y=200
