# 과기정통부 정통 정부 라이트 (네이비 리본) — PPT 디자인 팩

> spec_version: v3.1-2026-08-16

## 이 스타일의 정체성

대한민국 과학기술정보통신부 2026년 업무계획(별첨2) 발표자료의 시각 언어를 9p PNG 정독으로 증류한 팩이다. 옅은 블루(`#E7F1FA`) 배경 위에 딥 네이비(`#002060`) 본문 타이틀이 얹히는 **라이트 정통 정부 톤**이며, 본문 6페이지 + 클로징 1페이지를 일관되게 관통하는 시그니처는 **하단 11% 네이비 리본**이다(왼쪽 '상반기 핵심과제' 라벨 + 흰 텍스트로 콤마 구분된 핵심 키워드 3~4개). 본문 골격은 거의 항상 **좌 와이드 60~70% + 우 좁은 보조 30~40%의 비대칭 2-컬럼**이며, 시각적 클라이맥스는 마지막 본문 페이지의 **방사형 허브-스포크 거버넌스 다이어그램**(중앙 부처 + 8~12개 위성 노드 + `#C5D3E2` 가는 회색-옅은블루 직선 연결선 + 상하 보조 박스). 한 슬라이드를 보면 안다 — "정부 보고서 톤인데 단조롭지 않은 비대칭 분할 + 네이비 리본 + 체크리스트(✓) + 블루→퍼플 알약 패턴."

## 레이아웃 / 그리드

캔버스: **16:9 (1467×825 px / 13.33×7.5in 등가)**. 12열 그리드. 좌우 마진 각 3.5%.

### 본문 페이지의 표준 수직 분할 (04 ~ 10 공통)
1. **상단 인디케이터 영역** — y 0~6%에 좌측 상단 'NN ─ 섹션명' (네이비 `#002060`, 15pt SemiBold).
2. **메인 타이틀 영역** — y 8~22%에 본문 메인 타이틀 2줄 (34pt Bold `#002060`), 좌측 정렬.
3. **본문 영역** — y 25~85%에 카드 그리드/다이어그램. **거의 항상 비대칭 2-컬럼** (좌 60~70% + 우 30~40%).
4. **하단 네이비 리본** — y 89~100%의 **높이 캔버스 11%**, `#002060` 풀블리드, 좌측 '상반기 핵심과제' 흰색 13pt Bold + 우측 콤마 구분 키워드 13pt 흰색.

### 비대칭 2-컬럼 시그니처
본문·다이어그램 페이지 다수(05, 06, 07, 09, 10)가 **좌 와이드 60~70% + 우 좁은 보조 30~40%의** 패턴. **균등 2분할·균등 3분할·균등 6분할 금지** — 이것이 baseline과 구별되는 시그니처다.

## 형태 / 질감

- 카드 모서리: **6~12px 라운드**(일반 카드), **풀라운드 알약**(p-3 3대 전략 카드, 행 헤더 칩), 헤더 칩 12~20px.
- 보더: 카드가 채움 배경을 가지면 보더리스, 흰 카드면 0.5pt #D3DAE6 헤어라인.
- 리본: 풀블리드 사각, 모서리 라운드 0px.
- **그림자·글로우·3D·글래스모피즘 모두 사용 금지**. 예외 — p-9 중앙 허브 노드의 매우 옅은 0~2px 그림자, p-9 다이어그램 뒤 옅은 블루 원형 글로우 opacity ~20%.
- 아이콘: 평면 모노크롬 블루(#0F41BD 또는 #2277F2). 카드 헤더 옆 24~36px 또는 2×2 아이콘 카드 중앙 상단 60~80px 원형 배경 + 흰 아이콘.
- 사진(실사) 사용 0. 일러스트는 다음 다섯 군데만:
  - 01 표지 우측 옅은 블루 반투명 구체 글로우 클러스터(장식, opacity ~40%)
  - 04 좌측 'AI' 큰 글씨 블루 그라디언트 정사각 박스(#2366D9~#5398FF)
  - 07 우측 누리호 로켓 사실적 일러스트(수직, 화염 + 발사대), 폭 ~15%의 우측 끝 배치
  - 09 중앙 부처 엠블럼 위치 — **실제 정부 로고 사용 금지**, 일반 원형 플레이스홀더(지름 ~0.9in 허브 내)로 대체
  - 09 위성 노드 부처별 미니 로고 — 일반 원형 플레이스홀더(부처식 아이콘 분위기, 지름 ~24px)

## 다이어그램·컴포넌트 키트

이 팩의 본체. 모든 다이어그램은 **라이트 톤 정부 인포그래픽 언어**를 공유한다 — 옅은 블루 카드, 0.5pt 회색 헤어라인 보더(또는 보더리스), 네이비/로열블루 텍스트, **그림자·글로우·3D 절대 금지**, **사이언/청록 사용 금지**.

### 1. 색띠 3컬럼 체크리스트 (회고 양식 — 02-agenda)
- 상단 작은 캡슐: '국가 최대 위기를 극복' (`#E0EEF9` 풀라운드 + 13pt `#002060` 중앙).
- 가로 3개 동등 카드, 각 ~3.8in × 4.5in, 거터 0.15in.
- 카드 상단 ~0.45in 색띠 `#1A4BC6` 채움 + 흰 15pt Bold 헤더 중앙 정렬.
- 카드 본문 흰색 #FFFFFF, 체크리스트 4행: `✓ 마크 (9pt #002060) + 굵은 핵심어 (13pt #1C2848 Bold) + 일반 설명 (11pt #1C2848)`.
- 카드 하단 직후 옅은 띠에 한 줄 요약 (이탤릭 14pt `#3C4860`). **네이비 리본 아님**.

### 2. 병렬 3-전략 알약 카드 (인트로 양식 — 03-section)
- 가로 3개 풀라운드 알약, 각 ~3.4in × 2.2in, 거터 0.25in.
- 카드 01 단색 `#2366D9`, 카드 02 단색 `#4369EE`, 카드 03 단색 `#4857D6`.
- 카드 내용 좌측 정렬: 작은 캡션(13pt 흰 Medium) + 큰 숫자 `01`/`02`/`03` (28pt 흰 Bold) + 2줄 본문(14pt 흰 SemiBold, 행간 1.3).
- 배경 장식: 좌상단·우하단 옅은 블루 원형 글로우(opacity ~30%, 카드와 겹치지 않게).
- 이는 병렬 3대 전략이지 순위가 아니다 — 왕관·골드 마커·1위 강조 막대 0. 세 카드 비주얼 무게 동등, 폭 동일 ~3.4in.

### 3. 비대칭 상2+하 박스 안 3컬럼 (AI 3강 양식 — 04-key-message)
- 본문 영역 y 25~85%를 상단 ~45% + 하단 ~50%로 분할.
- 상단: 가로 2분할 칩 — 좌 35% : 우 65%의 비대칭.
  - 좌(약 35%): 칩 헤더 '국민 모두가 함께 누리는 K-AI' (17pt `#0F41BD`) + 큰 정사각 'AI' 박스(블루 그라디언트 채움 `#2366D9~#5398FF`, ~1.4in 정사각, 흰 'AI' 32pt) + 우측 텍스트 캡션.
