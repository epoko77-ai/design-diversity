# 모뉴멘탈 하이퍼카 디스플레이 — web 디자인 팩

spec_version: v3.1-2026-08-16

## 이 스타일의 정체성
시네마 블랙(near-black) 캔버스 위에 거대한 모뉴멘탈 디스플레이 타이포가 한 단어씩 화면을 가로지르며, 타이포 자체가 콘텐츠이고 이미지·컴포넌트는 거의 등장하지 않는 하이퍼카 절제의 사이트다. 무엇을 보면 이 스타일임을 아는가 — 헤드라인 한 단어가 뷰포트 폭의 80–100%를 차지할 만큼 압도적으로 크다, 색은 거의 순흑이고 EB 블루는 페이지 전체에 단 한 점만 찍힌다, 섹션 하나가 곧 풀스크린 스테이트먼트 한 컷이다, 모션은 느린 페이드뿐 — 스냅·클립 리빌이 없다.

## 색
- 배경: `#080809` (시네마 블랙). 패널·표면: `#14151A`. ghost 레이어: `#0E0F12`. 윤곽선: `#1B1D24`.
- 텍스트(디스플레이): `#ECECEC`. 보조·캡션: `#76787F`.
- 강조: EB 블루 단 하나 — `#1A2D5A`. 페이지 전체에 단 한 점(작은 라벨·1px 라인·인덱스 숫자)에만. 큰 면 사용 절대 금지, 적용 면적 1% 이하.
- 색 역할 면적 배분(뷰포트 기준): `#080809`/`#14151A` 합산 90% 이상, 텍스트 `#ECECEC` 8% 이하, EB 블루 1% 이하.
- 대비 실측: 디스플레이 `#ECECEC` on `#080809` ≈ 16.6:1 (AAA). 보조 `#76787F` on `#080809` ≈ 4.5:1 (AA 하한 — 이보다 어둡게 조정 금지).
- EB 블루 `#1A2D5A` on `#080809` ≈ 1.5:1 — **의도적 저대비 장식 액센트.** 단독 정보 전달 금지: EB 블루 인덱스 숫자 옆에는 항상 `#76787F` 라벨을 병기한다.
- ghost 모노그램 `#0E0F12` on `#080809` ≈ 1.1:1 — near-invisible 장식 전용, 텍스트 콘텐츠 사용 금지.

## 타이포그래피
- 디스플레이: `Anton`(Google Fonts) weight 400, 대체 `'Arial Black', Impact, sans-serif`. 모뉴멘탈 헤드라인 `clamp(4rem, 16vw, 16rem)`, line-height 0.92, `letter-spacing: -0.02em`. 한 단어 또는 두 단어만, 대문자.
- 본문: `Inter`(Google Fonts) weight 400, `1.0625rem`, line-height 1.7, 측정 56–66자, 본문 블록 폭 상한 `540px`. 본문은 작게 — 디스플레이와의 스케일 대비(최소 6배)가 정체성.
- 캡션/인덱스 라벨: `Inter` `0.74rem`, weight 500, 대문자, `letter-spacing: 0.2em`, 색 `#76787F`. 인덱스 숫자(01·02)만 EB 블루.
- 스펙 리드아웃 수치: `Inter` `1.6rem` weight 500, `font-variant-numeric: tabular-nums`, 단위 접미사 `0.7em`.
- 사용 가능한 텍스트 크기 집합(이외 금지): `0.74rem / 1.0625rem / 1.1rem / 1.6rem / clamp(4rem,16vw,16rem)`.
- 웨이트 집합: Anton 400 / Inter 400·500만. Inter 600 이상 금지 — 무게는 크기로만 낸다.

## 레이아웃 / 그리드
- 풀블리드 — content_max 없음, 엣지투엣지(데스크탑 1280px 뷰포트 기준). 텍스트 블록만 좌우 패딩 `clamp(24px, 6vw, 96px)`.
- 브레이크포인트: `768px`, `1200px`.
- 각 섹션 = 풀스크린(min-height 100vh) 스테이트먼트 한 컷. 거대 타이포 한 점 + 작은 보조 텍스트.
- 디스플레이 타이포는 좌하단 정렬 또는 화면 가로지름(`white-space: nowrap`, 좌우 4% 이내 오버플로 허용).
- **구성 균형 — 평면 보이드 금지.** 빈 상단·측면에는 아래 4종 중 최소 2개를 겹쳐 깐다: (a) `#080809→#14151A` 미세 시네마틱 그라디언트(리니어 또는 라디얼), (b) 조각적 하이퍼카 실루엣 SVG(단색 `#14151A` 면 또는 1px `#1B1D24` 윤곽, 폭 40–55vw), (c) 거대 ghost 모노그램(Anton, `#0E0F12`, 화면 높이 70%), (d) 우측 세로 스펙 리드아웃 3–4행.
- **간격 리듬:** 8px 베이스 스케일. 인덱스 라벨↔디스플레이 16px, 디스플레이↔본문 24px. 텍스트 블록은 좌하단 패딩 `clamp(40px,6vw,96px)` 안쪽 광학 정렬.

## 반응형 (뷰포트별 값)
- 375px: 좌우 패딩 `24px`, 디스플레이 실효 크기 ≈ 4rem(clamp 하한), 스펙 리드아웃은 디스플레이 아래 가로 1행으로 이동, 실루엣 SVG 폭 70vw.
- 768px: 좌우 패딩 ≈ `46px`(6vw), 디스플레이 ≈ 7.7rem, 스펙 리드아웃 우측 세로 스택 복귀.
- 1280px: 좌우 패딩 `77–96px`, 디스플레이 ≈ 12.8–16rem, 실루엣 SVG 폭 40–55vw.
- 섹션 min-height는 전 구간 100vh 유지 — 모바일에서도 잘라내지 않는다.
- 푸터 3컬럼은 768px 미만에서 1열 스택, 컬럼 간 세로 32px.

## 형태 / 질감
- 보더·그림자·아이콘 거의 없음. 모서리 radius `0px` 전역, `box-shadow: none` 전역.
- 구분이 필요하면 `1px solid #14151A` 라인 하나만.
- 이미지: 거의 쓰지 않음. 쓸 경우 풀블리드 단일 컷, `filter: saturate(0.85)`, 어두운 그레이딩, 좌하단에서 위로 `rgba(8,8,9,0.85)→transparent` 그라데이션 오버레이(높이 45%).
- 버튼: 텍스트 링크형 — `Inter` 대문자 `0.74rem` letter-spacing 0.2em + 하단 1px EB 블루 언더라인(텍스트에서 8px 아래). 박스 버튼 금지.

## 상태
- default: 텍스트 링크 `#ECECEC`, 언더라인 EB 블루 1px.
- hover: 언더라인이 좌→우 600ms 드로우(width 0→100%). 텍스트 색 변화 없음. 디스플레이 타이포는 호버 무반응.
- focus-visible: `outline: 2px solid #76787F; outline-offset: 4px` — 저대비 EB 블루를 포커스 링에 쓰지 않는다(시인성).
- active: 텍스트 opacity 0.7, 100ms.
- 내비 현재 항목: 하단 1px EB 블루 언더라인 상시.

## 모션
- 전환: `subtle` — `600ms cubic-bezier(0.16, 1, 0.3, 1)` (느린 ease-out). 대상: opacity·transform만.
- 스크롤 진입: 요소가 뷰포트 25% 지점 진입 시(`IntersectionObserver threshold 0.25`) 디스플레이 타이포가 `opacity 0 → 1` + `translateY(40px → 0)`, 700ms, 단어별 90ms stagger.
- 패럴랙스: 디스플레이 타이포가 배경보다 0.85배 느리게 — 미세하게만, 최대 이동량 60px.
- 스크롤 거동: 헤더는 고정하지 않음(투명 오버레이, 스크롤 시 함께 사라짐). 섹션 스냅 없음 — 자유 스크롤.
- `prefers-reduced-motion: reduce`: 진입 translateY·패럴랙스·언더라인 드로우 제거, opacity 300ms만.
- 스냅·클립 리빌·바운스·600ms 미만 빠른 전환 금지 — 모든 전환은 느리고 무겁다.

## 컴포넌트
- **헤더/내비:** 투명 오버레이, 높이 72px, 좌우 패딩 `clamp(24px,6vw,96px)`. 좌측 워드마크(Anton `1.1rem`), 우측 메뉴 3–4개(Inter 대문자 `0.74rem` letter-spacing 0.2em, 항목 간격 32px). 스크롤해도 배경 채우지 않음.
- **스테이트먼트 블록:** 풀스크린 100vh, 좌하단 Anton 디스플레이 1–2단어 + 위 인덱스 숫자(EB 블루 + `#76787F` 라벨 병기) + 아래 Inter 본문 1–2줄(폭 540px 이하).
- **스펙 리드아웃:** 우측 세로 스택 3–4행 — 각 행 라벨(Inter 대문자 `0.7rem` `#76787F`) + 수치(`1.6rem` `#ECECEC` tabular-nums) + 단위(0.7em). 행 간 구분 `1px solid #14151A`, 행 높이 64px. 박스 보더 없음.
- **하이퍼카 실루엣 SVG:** 직선·완만한 곡선으로 추상화한 차체 윤곽 단일 폼. 단색 `#14151A` 면 또는 `1px #1B1D24` 윤곽선. 사진 아님.
- **인용 블록:** 보더 없음 — 거대 Anton 한 단어 + 작은 Inter 출처(`0.74rem` 대문자 `#76787F`). 카드 박스 그리지 않음.
- **ghost 모노그램:** Anton 한 글자, 색 `#0E0F12`, 높이 70vh, z-index는 텍스트 아래·배경 위.

## 하지 말 것
- 스냅 클립 리빌·마스크 와이프 금지 — 느린 페이드만.
- 사진 콜라주·미디어 타일 그리드 금지 — 이미지는 풀블리드 단일 컷만, 그것도 최소로.
- 컴포넌트(카드·배지·태그)를 늘려 화면 채우기 금지 — 타이포가 콘텐츠.
- 디스플레이 타이포를 작게(clamp 상한 8rem 미만) 쓰기 금지 — 모뉴멘탈해야 함.
- EB 블루를 큰 면·버튼 배경·포커스 링으로 쓰기 금지 — 페이지 전체 단 한 점.
- 그라디언트 텍스트·둥근 카드·이모지·글로우·box-shadow 금지.
- content_max 박스에 콘텐츠 가두기 금지 — 풀블리드 엣지투엣지.
- 빠른 스냅·바운스 모션 금지 — 600ms 이상의 무거운 페이드.
- 평면 단색 데드 보이드 절대 금지 — 시네마틱 그라디언트/실루엣 SVG/ghost 모노그램/스펙 리드아웃 중 최소 2개로 해소.
- 빈 플레이스홀더 채움 블록(회색 사각형·"이미지 영역") 금지.
- 길 잃은 떠다니는 요소 금지 — 모든 요소는 좌하단 정렬축 또는 우측 스펙 스택에 묶인다.
- 정체성 약화 금지 — 거대 모뉴멘탈 타이포는 모든 섹션에서 압도적이어야 한다. 일반 다크 사이트로 회귀 금지.
- 중앙정렬 히어로 카드·보라 그라디언트·균일 soft shadow 등 기본 AI 미감 금지.

## 상세 페이지 (5종)
전역 규칙(색·타이포·상태·모션)은 위를 상속한다. 아래는 각 페이지 고유 값만 적는다.

### 1. 히어로 (모뉴멘탈 타이포)
- 100vh `#080809` 캔버스, 상단 투명 내비 오버레이(높이 72px).
- 좌하단 Anton 헤드라인 1단어: `clamp(4rem,16vw,16rem)`, line-height 0.92, 화면 폭의 80–100%, 좌우 4% 이내 오버플로 허용.
- 헤드라인 위 16px에 인덱스 라벨: `01`(EB 블루) + `/ HYPERCAR`(`#76787F`), `0.74rem` letter-spacing 0.2em.
- 헤드라인 아래 24px에 Inter 본문 1줄(56–66자, 폭 540px 이하).
- 상단 빈 ~55% 해소(필수): 캔버스 전체 `#080809→#14151A` 리니어 그라디언트(상단이 미세하게 밝게).
- 우상~중앙에 하이퍼카 실루엣 SVG: 폭 40–55vw, `1px #1B1D24` 윤곽 또는 `#14151A` 면.
- 우측 세로 스펙 리드아웃 3행: `0–100 / 2.8`·`TOP SPEED / 350`·`POWER / 1500`, 행 높이 64px, 행 간 1px `#14151A`.
- ghost 모노그램 추가 레이어 허용: Anton 1글자 `#0E0F12`, 높이 70vh, 우측 정렬.
- 헤드라인 진입: opacity 0→1 + translateY 40px→0, 700ms, 단어별 90ms stagger.
- 텍스트 블록 좌하단 패딩 `clamp(40px,6vw,96px)`.

### 2. 풀스크린 스테이트먼트
- 연속 2–3개 100vh 섹션, 배경 `#080809`/`#14151A` 교대.
- 각 섹션 좌하단: Anton 1–2단어(`clamp(4rem,16vw,16rem)`) + 인덱스 숫자(02·03… EB 블루는 페이지 최초 1회만, 이후 `#76787F`) + 본문 1–2줄.
- 인덱스↔디스플레이 16px, 디스플레이↔본문 24px, 본문 폭 540px 이하.
- 섹션마다 ghost 모노그램 글자를 다르게(섹션 키워드 이니셜), `#0E0F12`, 높이 70vh.
- `#14151A` 배경 섹션의 실루엣 SVG·구분선은 한 단계 밝은 `#1B1D24`로 — 표면 위 경계 유지.
- 스크롤 진입 시 타이포 700ms 페이드+업, 패럴랙스 0.85배(최대 60px).
- 우측 스펙 리드아웃은 섹션당 최대 1개 — 두 컷 연속 배치 금지.
- 섹션 간 구분선·간격 없음 — 100vh 컷이 바로 이어진다.

### 3. 갤러리
- 각 항목 100vh 풀블리드 단일 컷, `filter: saturate(0.85)` + 어두운 그레이딩.
- 좌하단 `rgba(8,8,9,0.85)→transparent` 그라데이션 오버레이, 높이 45%.
- 오버레이 위 좌하단: 인덱스 숫자(`0.74rem`, 갤러리 첫 컷에만 EB 블루) + 모델명 Anton(`clamp(2rem,6vw,5rem)` — 갤러리 전용 축소 스케일) + Inter 캡션 1줄(`1.0625rem`).
- 인덱스↔모델명 16px, 모델명↔캡션 16px, 좌하단 패딩 `clamp(40px,6vw,96px)`.
- 타일 그리드 금지 — 한 번에 한 컷, 자유 스크롤로 넘김.
- 이미지 부재 시: `#080809→#14151A` 그라디언트 + 실루엣 SVG(폭 60vw)로 컷을 구성 — 회색 플레이스홀더 금지.
- 컷 진입 시 캡션 블록 opacity 0→1, 700ms.

### 4. 헤리티지·인용
- 100vh `#14151A` 패널, 상단 30%에 `#14151A→#080809` 역방향 미세 그라디언트.
- 중앙 좌측: Anton 인용 키워드 1단어(`clamp(4rem,12vw,10rem)` — 히어로보다 한 단계 작게).
- 키워드 아래 24px: Inter 인용문 2–3줄(56자 이내, `1.0625rem`, `#ECECEC`).
- 인용문 아래 16px: 출처 라벨(`0.74rem` 대문자 `#76787F`).
- 인용 블록 좌측에 1px EB 블루 세로 룰(높이 = 인용문 블록 높이, 텍스트에서 좌측 24px) — 이 페이지의 EB 블루 단 한 점.
- 우측 빈 영역: ghost 모노그램(`#0E0F12`, 높이 70vh) 또는 실루엣 SVG(1px `#1B1D24`) 중 1개 이상.
- 카드 박스·보더 없음 — 텍스트가 패널 위에 직접 앉는다.
- 좌측 패딩 `clamp(40px,6vw,96px)`, 인용 블록 폭 상한 640px.
