# Every 골든 그리드 키노트 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(1280×720px 좌표계, 13.33×7.5in) 슬라이드 덱을 만든다. Every 골든 그리드 키노트 — 황금비(1:1.618)로 분할된 그리드가 모든 슬라이드의 골격이고, 이미지 블록·텍스트 컬럼·여백·폰트 크기까지 전부 황금 스케일을 따르는 비례 일관성의 미니멀 키노트. 무채색 + muted gold 한 점. 이하 %W/%H = 캔버스 1280×720px 기준 백분율. 황금비 분할점은 61.8% / 38.2%로 계산한다(가로 분할선 x=791px, 세로 분할선 y=445px, 나선 초점 x=791px·y=275px).

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 모든 슬라이드가 큰 블록 1.618 : 작은 블록 1로 분할되고 그 안이 다시 황금비로 재분할된다 — 균등 12열이 아니다, (2) 폰트 크기도 황금 스케일(13/21/34/55pt) — 인접 크기 비율이 1.618, (3) 무채색 캔버스에 차분한 muted gold `#B5A642` 단 한 점. 황금나선 초점이 콘텐츠 무게중심.

## 색 (역할·적용 면적 상한 포함)
- 배경 `#FAFAF8` 따뜻한 오프화이트 — 캔버스 면적의 65% 이상.
- 본문 잉크/헤딩 `#161616`.
- 본문 그레이 `#6E6E68` — 보조 텍스트·축선·라벨.
- 강조 muted gold `#B5A642` — 라벨·차트 핵심 1계열·0.08in 룰·번호에만. 골드 합산 면적 캔버스의 4% 이하. 면 채움 금지.
- 그리드 라인 `#D8D8D2` — 1px, 황금비 분할선을 옅게 노출하는 가이드.
- 무채 데이터 연톤 `#C4C4BE` / 진톤 `#6E6E68` — 차트 전용.
- 허용 색은 위 6개 hex가 전부 — 추가 색·그라디언트 0건.
- 통화 표기: `₩` 글리프 금지 — `1,240억`·`KRW 1.24T`·`$1.2B` 형식.

## 타이포그래피 (황금 스케일)

- 크기는 황금 스케일 4단만: 캡션 13pt / 본문 21pt / 부제 34pt / 헤딩 55pt — 인접 비율 1.618, 중간 크기 신설 금지.
- 슬라이드 헤딩: 34pt(본문 슬라이드) 또는 55pt(표지·디바이더) / 600 / 자간 -0.01em / 행간 1.15 / 최대 2줄·줄당 20자.
- 본문: 21pt / 400 / 행간 1.5 / 슬라이드당 6줄 이하 / 줄당 최대 38자.

- KPI 대형 수치: 55pt / 600 / tabular numerals. 보조 메트릭: 34pt / 600 / tabular.

## 레이아웃 / 그리드
- **황금비 블록 그리드 + 고정 외곽 여백.** 좌·우·상 외곽 여백 각 60px, 하단 풋라인 baseline y=668px(92.8%H) 고정 — 전 슬라이드 동일, 드리프트 0px.
- 안전 영역(1160×556px, x=60~1220px·y=60~616px) 안에서 큰 블록 : 작은 블록 = 1.618 : 1 분할 — 가로 분할이면 경계 x=777px, 세로 분할이면 경계 y=404px(안전 영역 기준 61.8%).
- 큰 블록은 다시 1.618:1로 재분할 가능 — 모든 모듈 경계가 황금비 분할선과 일치(오차 ±4px 이내).
- 콘텐츠 무게중심(헤딩 또는 핵심 비주얼)을 나선 초점(x=791px 또는 x=489px, y=275px 또는 y=445px 중 택1)에 맞춘다 — 슬라이드 타입별로 초점 선택을 고정.
- 1px `#D8D8D2` 그리드 라인을 분할선 위에 옅게 노출 가능(가이드처럼) — 두께 0.75~1px 덱 전체 일관.
- 수직 리듬은 황금 스케일 13/21/34px 스텝. 임의 크기·off-grid 배치 0개.
- 구성 균형: 어느 한 연속 빈 영역도 캔버스의 20% 초과 금지. 본문 슬라이드는 캔버스 85% 이상을 의미 있는 모듈로.
- 밀도: 본문 슬라이드는 황금비로 재분할된 모듈 3개 이상(헤딩 + 본문 + 차트/KPI/콜아웃).
- 콜아웃 모듈: 1px 그리드 라인 윤곽 + 좌측 0.08in(≈8px) 골드 룰 + 내부 패딩 21px + 13pt 인사이트 1줄. 높이 = 내용 + 패딩.
- 이미지/비주얼 블록은 실제 비주얼(부드러운 톤 필드 + 라벨, 비례 차트, 다이어그램)을 담는다 — 평면 단색 빈 블록 금지.
- 풋라인: 좌하단 13pt 출처 캡션 + 우하단 13pt 페이지 번호, baseline y=668px 정렬 — 모든 본문성 슬라이드 의무.
- 텍스트 좌측 엣지는 블록 좌측 경계 + 21px 패딩으로 통일.

## 차트·데이터 시각화 (비례 차트 — 무채 + 골드 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 황금비 블록 안에 비례적으로 앉는다.
- 데이터 색: 기본 `#C4C4BE`(연) / `#6E6E68`(진). 강조 1개만 `#B5A642` 솔리드 — 차트당 골드 1개.
- 차트 영역 자체가 황금비 직사각형: 폭:높이 = 1.618:1(오차 ±2%).
- 막대: 폭:간격 = 1.618:1(황금비), 모서리 0px, 베이스라인 0 정확(잘린 y축 금지), 개수 3~8개.
- 라인: 1pt 폴리라인, 면적 채움 0, 포인트 4~8개, 핵심 포인트만 지름 8px 골드 원.
- 격자선: 제거 또는 y축 주요 눈금 2~3개만 0.5pt `#D8D8D2`. 차트 테두리 박스 0. x축선 0.75pt `#6E6E68`, 틱 길이 4px.
- 값 레이블: 막대·꼭짓점 위 8px, 13pt 500 tabular. 범례 박스 금지 — 직접 라벨링(계열명 라인·막대 끝 8px).
- 도넛: 1개만, 조각 3개 이하, 두께는 반지름의 38.2%, 중앙 34pt 600 수치, 핵심 조각만 골드.
- 미니 스파크라인: 0.75pt 무채 폴리라인, 폭 89px·높이 55px(황금비), 마지막 포인트만 지름 4px 골드.
- 출처: 풋라인 좌하단 13pt `#6E6E68` 출처·단위 각주.
- 타입 매칭: 비교=세로 막대, 추세=라인, 비중=도넛 1개. 파이 다중·3D·격자선 과다 금지.
- 데이터 포인트 초과(막대 8개 초과) 시 표로 전환. 레이블 간격 12px 미만이면 강조 계열만 표기.
- 차트 내부 제목 금지 — 해석은 인접 텍스트 존이 담당.

## 다이어그램·컴포넌트 (황금비 다이어그램 키트)
모든 컴포넌트를 SVG로 렌더하며 하나의 언어를 공유한다 — 노드는 반경 0px 황금비(1.618:1) 직사각형 + 1px `#D8D8D2` 보더, 커넥터 1pt 무채 라인(화살촉 6px·30°), 크기·간격이 황금비, 강조는 골드 텍스트·8px 골드 룰.
- 프로세스 플로우: 좌→우 3~5단계, 노드 폭:간격 = 1.618:1, 노드 자체도 1.618:1 비율. 노드 안 13pt 골드 번호 + 21pt 단계명. 핵심 단계만 좌측 8px 골드 룰.
- 타임라인: 수평 축 0.75pt `#6E6E68`. 마일스톤 간격이 황금비로 증감(각 구간 = 직전 구간 ×1.618 또는 ÷1.618). 마커 지름 0.12in(12px) 무채 원, 현재 시점만 골드. 라벨 13pt 축 아래 13px.
- 비교(2~3열): 칼럼 폭 황금비(1.618:1) 또는 균등 황금 재분할, 1px 그리드 라인 구분. 헤더 13pt 500 대문자. 우세 열만 골드 텍스트.
- 매트릭스 2×2: 십자축을 황금비 위치(가로 61.8%·세로 61.8%)에 두는 비대칭 2×2 — 0.75pt 그리드 라인. 데이터 포인트 지름 12px 무채 점, 핵심만 골드. 사분면 라벨 13pt.
- 계층/퍼널: 단 폭이 황금비(×0.618)로 감소하는 적층 3~4단, 무채 명도, 핵심 단만 골드. 레벨 라벨 우측 13px에 21pt.
- KPI·스탯 카드: 황금비 직사각형 카드 + 1px 보더 + 패딩 21px, 13pt 라벨 + 55pt 600 수치 + 13pt 골드 델타. 카드 간격 = 카드 폭 ÷ 1.618 ÷ 1.618(≈카드 폭의 38.2%의 61.8%).
- 목차 행: 13pt 골드 번호 + 21pt 항목명 + 13pt 그레이 설명 + 우측 13pt 페이지 번호. 행 간격이 황금비로 증감.
- 섹션 디바이더: 나선 초점에 55pt 헤딩 + 13pt 골드 섹션 번호.
- 인용: 황금비 블록 + 34pt 풀쿼트(최대 2줄) + 13pt 출처.
- 델타 표기: `+`/`−` 부호 + 골드(증가)·그레이(감소) — 삼각형·화살표 아이콘 금지.
- 커넥터 화살촉은 좌→우 방향에만 — 양방향·곡선 커넥터 0건.
- 노드 내부 패딩 13px, 노드 텍스트는 좌상단 정렬.

## 상세 페이지 (6종) — 전역 규칙은 위 절이 SSOT, 아래는 페이지 고유 좌표·구성만

### 01 · 표지 (cover)
- 세로 분할: 큰 블록 상단(y=60~404px) : 작은 블록 하단(y=404~616px) = 1.618:1, 분할선에 1px 그리드 라인 노출.
- 타이틀: 55pt 600, 나선 초점 x=791px에 좌측 엣지가 아닌 광학 중심을 맞춰 배치, baseline y=275px, 최대 2줄.
- 작은 블록을 가로 1.618:1 재분할(경계 x=777px): 좌측에 13pt 골드 대문자 라벨 + 21pt 부제 1줄, 우측에 메타 스트립 `PREPARED BY`/`DATE`/`VERSION` 3행 — 각 13pt 라벨 + 13pt 값, 행 높이 55px, 행 사이 1px 그리드 라인.
- 골드는 라벨 1개 + 메타 라벨에만(면적 1% 이하). 사진 0개.
- 우하단 13pt 페이지 메타(y=668px baseline).
- 타이틀 주변 여백은 황금비 블록 경계가 만드는 의도된 호흡 — 분할선 노출로 빈 공백이 아님을 보인다.

### 02 · 목차 (agenda)
- 가로 분할: 큰 블록 좌(x=60~777px) : 작은 블록 우(x=777~1220px), 분할선 1px 노출.
- 좌측에 목차 5행(§다이어그램 목차 행): y=140px 시작, 행 간격 55/89px 황금 증감, 현재 섹션 행만 좌측 8px 골드 룰.
- 목차 번호 열 폭 55px 고정 — 항목명 좌측 엣지 5행 동일 x.
- 우측 작은 블록을 세로 1.618:1 재분할(경계 y=404px): 상단에 34pt 섹션 헤딩(초점 y=275px), 하단에 핵심 takeaway 3개 — 13pt 골드 번호 + 13pt 텍스트, 항목 간 21px.
- 상단 x=60px·y=60px에 13pt 골드 대문자 라벨 `CONTENTS`.
- 풋라인: 출처 캡션 + 페이지 번호.

### 03 · 섹션 간지 (section-divider)
- 오프화이트 전면, 세로 분할선 y=404px·가로 분할선 x=791px을 1px 그리드 라인으로 노출.
- 섹션명: 55pt 600, 나선 초점(x=791px·y=275px)에 광학 중심 정렬, 1줄.
- 그 위 21px에 13pt 골드 섹션 번호(`02 ─` 형식), 그 아래 21px에 21pt 요지 1줄.
- 하단 작은 블록(y=404~616px)에 섹션 항목 인덱스 3개: 13pt 골드 번호 + 13pt 라벨, 좌측 엣지 x=81px, 항목 간 34px.

### 04 · 핵심 본문 (황금비 블록) (body)
- 가로 분할(경계 x=777px): 큰 블록 좌 / 작은 블록 우, 분할선 1px 노출.
