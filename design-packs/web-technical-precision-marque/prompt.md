# 테크니컬 프리시전 마퀴 — web 디자인 팩

spec_version: v3.1-2026-08-16

## 이 스타일의 정체성
딥 차콜 배경 위에 1px 헤어라인 사양 그리드가 계기판처럼 옅게 깔리고, 등폭 숫자 스펙 라벨(0–100 km/h · kW · Nm)이 계측기 눈금처럼 정렬되는 독일 엔지니어링 정밀의 다크 프리미엄 사이트다. 무엇을 보면 이 스타일임을 아는가 — 발광·글로우가 일절 없고 깊이는 헤어라인과 표면 명도 차로만 만든다, 모든 수치가 IBM Plex Mono 등폭으로 소수점까지 정렬돼 있다, 스틸 블루 단 한 색만 데이터 라인·강조 라벨에 쓰이며 그 외는 무채다, 호버하면 카드가 들뜨는 대신 헤어라인이 한 단계 또렷해지고 스펙 숫자가 계측기처럼 조용히 페이드 인한다.

## 색
- 배경: `#16181C` (딥 차콜). 섹션 교차 시 `#1B1E23`.
- 표면(패널·카드): `#2A2D33`. 헤어라인 그리드선도 같은 톤 `#2A2D33`.
- 텍스트: `#E4E6EA` (본문·헤드라인). 보조·스펙 라벨: `#9296A0`.
- 강조: 스틸 블루 단 하나 — `#5AA9E6`. 데이터 라인·차트 시리즈·강조 라벨·포커스 링·CTA 보더에만. 뷰포트당 적용 면적 7% 이하. 스틸 블루 외 강조색 절대 금지.
- 색 역할 면적 배분(뷰포트 기준): 배경 `#16181C`/`#1B1E23` 합산 70% 이상, 표면 `#2A2D33` 25% 이하, 스틸 블루 7% 이하.
- 대비 실측: 본문 `#E4E6EA` on `#16181C` ≈ 13.4:1 (AAA). 보조 `#9296A0` on `#16181C` ≈ 6.0:1 (AA). 스틸 블루 `#5AA9E6` on `#16181C` ≈ 7.1:1 (AA).
- 헤어라인 `#2A2D33` on `#16181C` ≈ 1.5:1 — 의도적 저대비, 장식 그리드 전용. 정보 전달 텍스트에 이 대비 사용 금지.

## 타이포그래피
- 헤드라인: `IBM Plex Sans`(Google Fonts) weight 600, 대체 `Inter, Arial, sans-serif`. H1 `clamp(2.2rem, 3.4vw, 3rem)`, `letter-spacing: -0.01em`, line-height 1.2.
- H2: `IBM Plex Sans` 600, `clamp(1.6rem, 2.4vw, 2rem)`, line-height 1.25. H3: `1.25rem` 600, line-height 1.35.
- 본문: `IBM Plex Sans` `1rem`, weight 400, line-height 1.65, 측정 62–70자. 본문 블록 최대 폭 `640px`.
- 스펙 숫자·계측 라벨: `IBM Plex Mono`(Google Fonts) weight 500, `font-variant-numeric: tabular-nums`. 큰 수치 `clamp(1.5rem, 2.4vw, 2.2rem)`, 단위 접미사(`kW`·`Nm`·`s`)는 `0.7em`로 축소, 수치와 단위 사이 `0.25em`. 소수점 정렬 필수.
- 키커/섹션 라벨: `IBM Plex Mono` `0.72rem`, weight 500, 대문자, `letter-spacing: 0.16em`, 색 `#5AA9E6`.
- 캡션: `IBM Plex Sans` `0.82rem` 400, 색 `#9296A0`, line-height 1.5.
- 사용 가능한 텍스트 크기 집합(이외 금지): `0.72rem / 0.78rem / 0.82rem / 1rem / 1.25rem / clamp(1.5rem,2.4vw,2.2rem) / clamp(1.6rem,2.4vw,2rem) / clamp(2.2rem,3.4vw,3rem)`.
- 웨이트 집합: 400·500·600만. 300·700 이상 금지.

## 레이아웃 / 그리드
- 콘텐츠 최대 폭: `1280px`. 브레이크포인트: `768px`, `1120px`.
- 12열 strict-grid, 컬럼 갭 24px. 모든 요소가 컬럼 경계에 스냅.
- 배경에 1px 헤어라인 사양 그리드를 옅게 노출 — 수직 12선 + 96px 간격 수평선, 색 `#2A2D33`, opacity 0.5.
- 섹션 수직 리듬: 일정한 `96px`(balanced — 불규칙 리듬 금지). 데스크탑 1280px 뷰포트 기준.
- 히어로는 좌 7열 제품 비주얼 + 우 5열 스펙 컬럼 비대칭이되 strict-grid 경계 준수.
- **구성 균형 — 평면 보이드 금지.** 큰 빈 차콜 면은 미완성으로 읽힌다. 빈 영역에는 헤어라인 사양 그리드 연장, L자 크롭마크(길이 16px), 옅은 계측 눈금 SVG, 1px 헤어라인 차트 중 하나 이상을 반드시 담는다.
- **간격 리듬:** 8px 베이스 스케일. 키커↔H1 16px, H1↔본문 24px, 스펙 행 간 16px, 카드 내부 패딩 32px 일관. 모든 헤어라인 1px 두께 통일. 스펙 숫자는 소수점 기준 광학 정렬.

## 반응형 (뷰포트별 값)
- 375px: 좌우 패딩 `24px`, 그리드 1열 스택, 섹션 수직 리듬 `64px`, 스펙 카드·갤러리 1열, 히어로는 비주얼 위 + 스펙 컬럼 아래 세로 스택.
- 768px: 좌우 패딩 `40px`, 그리드 6열, 섹션 리듬 `80px`, 기능 카드 2열, 갤러리 2열.
- 1280px: 좌우 패딩 `64px`, 12열 풀 그리드, 섹션 리듬 `96px`, 기능 카드 3열, 갤러리 2열.
- 배경 헤어라인 그리드: 375px에서는 수직선 4선으로 축소, 768px 8선, 1120px 이상 12선. 수평선 간격은 전 구간 `96px` 고정.
- 히어로 높이: 375px `min(92vh, 640px)`, 1280px `min(88vh, 720px)`.

## 형태 / 질감
- 모서리: 카드·이미지·버튼 radius 최대 `2px` — 거의 직각.
- 보더: 1px 헤어라인만 — `1px solid #2A2D33`. 강조 보더는 `1px solid #5AA9E6`. 2px 이상 보더는 비교 테이블 표시선(2px) 단 한 곳만.
- 그림자: 일절 없음(`box-shadow: none` 전역). 깊이는 표면 명도 차(`#2A2D33` 패널)와 헤어라인으로만.
- 아이콘: 1.25px 스트로크 라인 아이콘, 24px 박스, 색 `#9296A0`. 계측·엔지니어링 모티프(눈금·게이지·캘리퍼)로 크래프트. 면 아이콘·이모지·제너릭 세트 금지.
- 이미지: radius 2px, `1px solid #2A2D33`, `filter: saturate(0.92)`, `object-fit: cover`, 비율 16:10 고정. 4모서리에 1px L자 크롭마크(길이 16px) 허용.

## 상태 (컴포넌트 공통)
- default: 보더 `#2A2D33`, 텍스트 규정색.
- hover: 헤어라인 보더 `#2A2D33 → #5AA9E6`(200ms), 스펙 숫자 `#9296A0 → #E4E6EA`. `translateY`·스케일 변화 금지.
- focus-visible: `outline: 2px solid #5AA9E6; outline-offset: 2px` — 모든 인터랙티브 요소 필수, outline 제거 금지.
- active: 보더 `#5AA9E6` 유지 + 텍스트 밝기 -8%(`filter: brightness(0.92)`), 100ms.
- disabled: opacity 0.4, 커서 not-allowed. 색 대체 금지.

## 모션
- 전환: `subtle` — `200ms cubic-bezier(0.22, 1, 0.36, 1)` (ease-out 계열). 대상: border-color·color·opacity만.
- 스크롤 진입: 뷰포트 하단에서 요소 상단이 15% 지점 진입 시(`IntersectionObserver threshold 0.15`) 스펙 숫자·헤어라인 그리드가 `opacity 0 → 1`, 220ms, 요소 간 60ms stagger.
- 호버: 카드는 들뜨지 않음(`translateY` 금지). 상태 절의 값을 따른다.
- 숫자 카운트업: 0에서 목표값까지 240ms, ease-out. 소수점 자릿수는 목표값과 동일하게 유지.
- 스크롤 거동: 헤더만 `position: sticky; top: 0`. 그 외 패럴랙스·핀 고정 금지.
- `prefers-reduced-motion: reduce`: 진입 트랜스폼·카운트업·stagger 제거, opacity 전환 120ms만. 호버는 보더 색 변화만.
- 스냅·바운스·발광 펄스·400ms 초과 모션 금지.

## 컴포넌트
- **헤더/내비:** 높이 64px, 배경 `#16181C` + 하단 `1px solid #2A2D33`. 좌측 워드마크(Plex Sans 600 `1.1rem`), 중앙 메뉴(Plex Mono `0.78rem` 대문자, 항목 간격 28px), 우측 CTA 보더 버튼. 스크롤 시 배경 유지, 하단 헤어라인만 opacity 0.5→1.
- **스펙 카드:** `#2A2D33` 표면, `1px solid #2A2D33`, radius 2px, 패딩 32px. 상단 Plex Mono 키커 + 거대 등폭 수치(소수점 정렬) + 단위 접미사(0.7em) + 하단 1px 구분선 + 캡션. 내부 간격: 키커↔수치 12px, 수치↔구분선 20px, 구분선↔캡션 12px.
- **L자 크롭마크:** 카드·이미지 4모서리에 1px 헤어라인 L자(변 길이 16px, 모서리에서 0px 오프셋).
- **헤어라인 차트:** 1px `#2A2D33` 그리드 위에 스틸 블루 1px 라인 그래프 또는 바(바 폭 8px, 간격 16px). 데이터 시각화가 곧 장식.
- **비교 테이블:** 행 구분 1px 헤어라인, 행 높이 52px, 헤더행 Plex Mono 대문자 `0.72rem`, 숫자 셀 우측 정렬·tabular-nums. 강조 열만 좌측에 2px 스틸 블루 표시선.
- **폼 입력:** 투명 배경 + 하단 `1px solid #2A2D33` 언더라인만(박스 보더 없음), 높이 44px, 텍스트 `1rem`. focus-visible 시 언더라인 `#5AA9E6` + 두께 1px 유지(굵어지지 않음).
- **버튼(CTA):** 투명 배경 + `1px solid #5AA9E6` + 스틸 블루 텍스트, 패딩 `12px 28px`, radius 2px, Plex Mono 대문자 `0.78rem` letter-spacing 0.1em. hover: 보더·텍스트 `#5AA9E6 → #8CC4EF`(채움 없음).

## 하지 말 것
- 발광 보더·라디얼 글로우·네온 펄스 금지 — 깊이는 헤어라인과 명도 차로만.
- 둥근 카드(radius > 2px)·그라디언트·이모지·box-shadow 금지.
- 스펙 숫자를 프로포셔널 폰트로 쓰기 금지 — 반드시 IBM Plex Mono tabular-nums.
- 스틸 블루 외 강조색 금지. 스틸 블루를 큰 면 배경으로 칠하기 금지 — 라인·라벨·보더에만.
- 카드 호버 시 `translateY`·scale 금지 — 헤어라인·숫자 밝기 변화로만.
- 순흑(`#000000`) 배경 금지 — 딥 차콜 `#16181C`.
- 불규칙 섹션 리듬 금지 — 데스크탑 96px 일정.
- 평면 단색 데드 보이드 금지 — 빈 차콜 면은 헤어라인 그리드·크롭마크·계측 눈금·헤어라인 차트로 해소.
- 빈 플레이스홀더 채움 블록 금지 — 비주얼 프레임에는 실제 이미지 또는 헤어라인 와이어프레임/차트를 담는다.
- 길 잃은 떠다니는 요소 금지 — 모든 요소는 12열 strict-grid 경계에 스냅.
- 정체성 약화 금지 — 헤어라인 사양 그리드·등폭 스펙 숫자가 모든 페이지에서 또렷해야 한다.
- 중앙정렬 히어로·보라 그라디언트·균일 soft shadow 등 기본 AI 미감으로 회귀 금지.

### 3. 기능 그리드
- 12열 그리드에 카드 3개, 각 4열 span, 갭 24px. 768px 미만 1열, 768–1120px 2열(3번째 카드 풀폭).
- 카드: `#2A2D33` 표면 + `1px solid #2A2D33` + radius 2px + 패딩 32px.
- 카드 내부 순서: 24px 라인 아이콘(1.25px 스트로크 `#9296A0`) → 키커(Plex Mono `0.72rem` `#5AA9E6`) → H3(`1.25rem` Plex Sans 600) → 본문(`1rem`, 3줄 이내) → 하단 1px 구분선 → 보조 수치 1개(Plex Mono tabular).
- 내부 간격: 아이콘↔키커 16px, 키커↔H3 12px, H3↔본문 12px, 본문↔구분선 20px, 구분선↔수치 12px.
- 카드 hover: 보더 `#2A2D33 → #5AA9E6` 200ms, 보조 수치 `#9296A0 → #E4E6EA`.
- 섹션 헤더: 키커 + H2(`clamp(1.6rem,2.4vw,2rem)`), 카드 그리드와 48px 간격.
- 카드 높이 균등(그리드 stretch) — 들쭉날쭉 금지.
