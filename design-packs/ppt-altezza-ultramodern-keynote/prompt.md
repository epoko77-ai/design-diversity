# Altezza 울트라모던 키노트 — ppt 디자인 팩

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 본 문서의 px 좌표는 1280×720 캔버스 기준이며 렌더 해상도에 비례 확대한다. Altezza 울트라모던 키노트 — 사진·컬러 면을 각진 사선 클립 마스크(대각 12~18°)로 잘라 동적 긴장을 만들고, 거대 산세리프 헤드라인과 얇은 라벨이 강하게 대비하는 빽빽한 다크 에이전시 키노트. 강조는 electric mint 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 사진·컬러 면이 직사각형이 아니라 12~18° 각진 사선으로 잘려 있다 — clip-path 사선 마스크가 형태 정체성, (2) 거대 산세리프 헤드라인(800)과 얇은 라벨(300)이 같은 슬라이드에서 강하게 대비, (3) near-black 배경 + electric mint 한 점, 콘텐츠가 사선 분할선 기준으로 빽빽이 맞물린다. 둥근 모서리·발광 없음.

## 색 (역할·면적 상한 포함)
- 배경 near-black `#13141A` — 캔버스 기본 채움, 노출 면적 슬라이드의 30~60%
- 패널 `#3A3C46` — 사선 클립 패널·카드·행 카드 채움 전용, 노출 면적 합계 20~45%
- 강조 electric mint `#2EE6A6` — 강조 텍스트·1.5pt 사선 엣지 라인·단계 배지·차트 강조 1계열에만. 노출 면적 합계 슬라이드의 6% 이하, 큰 면 채움 금지
- 텍스트 `#F4F4F6`
- 얇은 라벨·보조 텍스트 `#9A9CA6`
- 차트 무채 데이터 계열: 연 `#5A5C66` / 진 `#9A9CA6` — 비강조 막대·선 전용
- 강조색은 mint 1개뿐. 그라디언트·라디얼 글로우 금지(사선 클립 면 안의 무채 톤 필드만 예외)
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 전부 `Archivo`(대체 `Inter, Helvetica Neue, sans-serif`). 한글은 `Pretendard`.
- 허용 크기 집합: {11, 12, 14, 17, 20, 28, 32, 56, 60, 72}pt — 이 집합 밖의 임의 크기 사용 금지
- 거대 헤드라인: 표지 72pt·클로징 56pt / Archivo 800 / 자간 -2% / 행간 1.0 / 최대 3줄
- 슬라이드 헤딩: 32pt / Archivo 800 / 자간 -1% / 최대 2줄
- 얇은 라벨: 12pt / Archivo 300 / 자간 +12% / 대문자 / 색 `#9A9CA6`
- 본문: 17pt / Archivo 400 / 행간 1.4 / 슬라이드당 7줄 이하(dense 허용)
- 미니헤더·인사이트·값 레이블·델타: 14pt / Archivo 600
- 컬럼 메트릭: 20pt / Archivo 800 / tabular
- 풀쿼트: 28pt / Archivo 800
- KPI 거대 수치: 60pt / Archivo 800 / tabular numerals
- 출처·차트 각주: 11pt / Archivo 400 / `#9A9CA6`

## 레이아웃 / 그리드
- **비대칭(asymmetric) + dense + 고정 외곽 여백.** 좌·우·상 외곽 여백 각 56px 고정, 하단 풋라인 baseline y=672(하단에서 48px) 고정 — 모든 슬라이드 동일, 드리프트 금지.
- 12열 그리드: 콘텐츠 폭 1168px(x=56~1224), 거터 24px — 사선 분할선이 이 그리드를 가로지른다.
- 슬라이드를 12~18° 사선으로 2~3 영역 분할 — 한쪽은 사진/컬러 클립 면, 다른 쪽은 콘텐츠. 분할선 각도는 덱 전체에서 14~16°로 일관, 한 슬라이드 안에서는 동일 각도만.
- 콘텐츠는 사선 분할선 기준 비대칭 배치 — 텍스트 군집이 사선 가장자리에 맞물린다. 헤딩 baseline·텍스트 좌측 엣지는 슬라이드 타입별로 동일 위치 고정, 수직 리듬 24/32/48px 스텝. 모듈은 12열 그리드에 스냅 — 떠다니는 요소 금지.
- **구성 균형:** 캔버스의 어느 한 영역도 ~20%를 넘게 비우지 않는다(간지 예외). 사선 면이 콘텐츠를 덜 채우면 사선 클립 패널 모듈·KPI 카드·차트로 빽빽이 채워 죽은 near-black 공백이 한 구석에 고이지 않게 한다.
- **밀도 원칙(dense가 정체성):** 거대 헤드라인 + 본문 + 라벨 + **데이터 모듈 3개 이상**이 사선 분할선 기준으로 맞물려 캔버스 90% 이상을 채운다. 핵심 메시지는 1개지만 사선 클립 패널·KPI 카드·차트·콜아웃이 빽빽이 공존한다. 거대 사선 면에 헤드라인 하나만 두는 것 금지(간지 예외).
- **모듈 좌표 컨벤션:** 14~16° 사선 분할선 기준 — 한쪽 영역에 헤딩+본문, 다른 쪽에 사선 클립 패널 모듈 묶음(KPI 카드 2~3개 사선 엣지 맞물림 + 차트 또는 표). 모듈 사이 사선 거터 0.18in.
- **사선 콜아웃:** 사선 클립 패널 `#3A3C46` + 1.5pt mint 사선 엣지, 안에 14pt 인사이트 1~2줄 + 12pt 라벨체 라벨. 패널 높이는 내용 높이 + 일관 패딩(상하 좌우 0.16in) — 하단 절반이 비지 않는다. 차트·본문 옆에 1개 맞물려 배치.
- **사선 클립 면은 실제 비주얼을 담는다:** 다크 무드 사진, 무채 톤 필드(명도 차 ≤8%) + 12pt 라벨, 또는 차트 — 평면 단색 빈 클립 면 금지.
- 얇은 대문자 라벨: 자간 +0.12em / 12pt 일관
- mint 사선 엣지 라인: 덱 전체 1.5pt 일관
- 모든 본문성 슬라이드: 좌하단 출처 각주 11pt + 우하단 페이지 번호 12pt를 풋라인 baseline y=672에 정렬
- 수치는 tabular figures 우정렬, 소수 자릿수·단위 일관. 비교 행 카드 룰은 헤어라인 일관, 강조 셀/행은 슬라이드당 1개만.

## 형태 / 질감
- 사진·컬러 면은 직사각형 금지 — 12~18° 각진 사선 clip-path 마스크 필수.
- 모서리 반경 0px(직각·사선만, 둥근 클립 금지).
- 그림자: offset 0 / blur 0 / alpha 0 — 전면 금지. 발광 금지.
- 사선 엣지 라인은 1.5pt mint 또는 흰 라인으로 강조 가능.
- 패널 `#3A3C46` 채움. 아이콘은 1.5pt 가는 라인 단색, 각진, 24×24px 그리드.

## 차트·데이터 시각화 (울트라모던 차트 — 다크 + mint 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 사선·각진 미감을 입는다.
- **데이터 색:** 막대·선 기본은 `#5A5C66`(연) / `#9A9CA6`(진). 강조할 1개만 electric mint `#2EE6A6` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px(각진). 베이스라인 0(잘린 y축 금지). 강조 막대만 상단을 12~18° 사선으로 자르는 옵션.
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 2~3개 0.5pt `#3A3C46`). 차트 테두리 박스 제거. x축선 0.75pt `#9A9CA6`.
- **값 레이블:** 막대 상단·꼭짓점 위 8px에 직접 표기, 14pt Archivo 600 tabular `#F4F4F6`. 범례 박스 금지 — 직접 라벨링.
- **라인 차트:** 2pt mint 폴리라인, 면적 채움 없음(또는 mint 10% 사선 클립 면적), 강조 시점만 지름 8px mint 원 마커.
- **도넛:** 1개만, 외경 260px·링 두께 44px·시작각 12시, 조각 3개 이하. 파이 다중·3D 금지.
- **출처:** 차트 하단 좌측 11pt Archivo `#9A9CA6` 출처·단위 각주.

## 다이어그램·컴포넌트 (사선 클립 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진 패널(반경 0px), 사선 12~18° 엣지로 잘림, 커넥터는 2pt 각진 라인(셰브론 화살촉 10×10px), 단계 번호는 사선 클립된 28×28px mint 배지(번호 14pt 800 `#13141A`), 강조는 mint 텍스트·1.5pt mint 사선 엣지.
- **프로세스 플로우:** 좌→우 사선 평행사변형 노드 4~5단계(12~18° 기울임, 각 폭 180~220px·높이 96px) — 패널 채움, 노드 사이 2pt 각진 셰브론. 각 노드에 28×28px mint 단계 배지. 현재 단계만 1.5pt mint 사선 엣지.
- **타임라인:** 사선 12~18° 기울인 축 1.5pt. 마일스톤은 0.14in 각진 다이아몬드(현재 시점만 mint 솔리드). 날짜 라벨 12pt 라벨체.
- **비교(사선 분할):** 슬라이드를 12~18° 사선으로 2~3 영역 분할 — 각 영역에 헤딩 + 본문 + 수치. 사선 분할선이 열 구분선, 1.5pt mint 엣지 라인.
- **매트릭스 2×2:** 축을 8~12° 기울인 2×2 — 0.75pt 패널 십자축. 데이터 포인트는 0.16in 각진 마름모(핵심만 mint 솔리드). 사분면 라벨 14pt.
- **계층/퍼널:** 사선 클립된 폭 비례 적층 — 각 단이 12~18° 평행사변형·높이 64px, 패널 명도 단계, 핵심 단만 mint. 레벨 라벨 우측 14pt.
- **KPI·스탯 카드:** 사선 클립된 패널 카드(한쪽 모서리 12~18° 잘림, 클립 깊이 24px), 12pt 라벨 + 60pt Archivo 800 수치 + 14pt mint 델타. 카드 3~4개, 사선 엣지가 맞물림.
- **목차/섹션 디바이더/인용:** 목차는 사선 클립 mint 번호 배지(28×28px) + 17pt 항목명. 디바이더는 사선 클립된 거대 컬러/사진 면 + 72pt 헤드라인. 인용은 사선 클립 패널 + 1.5pt mint 사선 엣지 + 28pt 800 풀쿼트 + 12pt 출처.

## 전환 (PPT)
snappy — 사선 클립 면이 한쪽에서 사선 방향으로 빠르게 슬라이드 인(140~180ms ease-out), 헤드라인은 100ms 늦게 따라 들어옴. 절도 있고 빠르게, 바운스 없음.

## 하지 말 것
- 둥근 모서리·둥근 클립 금지 — 각진 사선 12~18°만.
- 글로우·라디얼 그라디언트 금지(다른 다크 SaaS 팩의 자리).
- 사진을 직사각형 그대로 쓰지 말 것 — 사선 clip-path 마스크 필수.
- electric mint를 큰 면으로 도배하지 말 것 — 노출 면적 6% 이하, 강조 텍스트·사선 엣지·차트 1계열에만.
- 이모지·클립아트 금지. 대칭 중앙 정렬로 회귀 금지 — 비대칭이 정체성.
- 허용 크기 집합 {11~72}pt 밖의 임의 폰트 크기 금지.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.
- **거대 사선 면에 헤드라인 하나만 두고 비우기 금지(간지 예외).** dense가 정체성 — 본문/차트/KPI/비교 슬라이드는 사선 모듈 3개 이상으로 빽빽이 채운다.
- **캔버스 한 구석에 죽은 near-black 공백을 고이게 두지 말 것 / 빈 단색 플레이스홀더 클립 면 금지 / 헤드라인 문장 중간 단어 비대 금지 / 외곽 여백 56px·풋라인 baseline y=672·헤딩 baseline 위치 드리프트 금지.**

## 상세 페이지 (6종)
전역 규칙(색·타이포·그리드·풋라인)은 상속한다. 아래는 각 페이지 고유의 좌표·구성만 기술한다(1280×720 기준).

### 01 · 표지 (사선 클립) (cover)
- 사선 분할선: 상단 엣지 x=760 → 하단 엣지 x=581(14°), 분할 엣지에 1.5pt mint 라인 1줄
- 분할선 우측 전체(캔버스의 약 45~50%)는 사선 클립 비주얼 면 — 다크 무드 사진 또는 무채 톤 필드 + 12pt 라벨, 빈 단색 금지
- 좌측 콘텐츠 컬럼: x=56~720, 전 요소 좌정렬
- 대문자 라벨 12pt 300: baseline y=150
- 타이틀 72pt 800 2~3줄: 첫 줄 baseline y=270, 줄 baseline 간격 76px
- 부제 17pt: 타이틀 마지막 baseline +44px
- 메타 배지 행(`PROJECT`·`DATE`·`VERSION`): 사선 클립(14°) 셀 3개, 각 높이 40px·좌우 패딩 16px·셀 간격 12px, y=560~600
- 배지 라벨: 12pt 300 대문자
- 우하단 페이지 메타 12pt: baseline y=672 우정렬
- 표지 모듈 4개(라벨·타이틀·부제·배지 행) — 표지는 비교적 절제 허용

### 02 · 섹션 간지 (section-divider)
- 사선 클립 거대 컬러/사진 면: 우상(1280,0)→좌하 16°, 면적 캔버스의 55~65%
- 섹션 번호 배지: 40×40px mint 사선 클립, 번호 20pt 800 `#13141A`, 위치 x=56·y=180
- 섹션명 72pt 800: x=56, baseline y=330, 최대 2줄
- 섹션 요약 라벨 12pt 300 대문자: baseline y=390
- 섹션 항목 미니 배지 3개: 각 폭 300px·높이 48px 사선 클립 패널 `#3A3C46`, x=56부터 가로 나열·간격 16px, y=560~608
- 미니 배지 내부: mint 번호 14pt 800 + 항목 라벨 12pt
- 사선 분할 엣지 1.5pt mint 라인 1줄
- 페이지 번호 12pt: baseline y=672 우정렬

### 03 · 핵심 본문 (body)
- 영역 분할 14°: 좌 콘텐츠 x=56~736(폭 680px) / 우 사선 패널 묶음 x=756~1224(폭 468px)
- 라벨 12pt baseline y=110 → 헤딩 32pt 800 baseline y=150
- 리드 17pt 1줄: baseline y=192
- 3컬럼 분해: 각 컬럼 폭 208px·거터 28px, 영역 y=230~500
- 각 컬럼 구성: mint 번호 14pt 800 → 미니헤더 14pt 600 → 근거 14pt 2개(행간 1.4) → 하단 메트릭 20pt 800 tabular(3컬럼 메트릭 baseline y=490 통일)
