# 네이버 통합보고서 어워드 — PPT 디자인 팩 (v3 페이지 1:1 미러 재집필)

spec_version: v3.1-2026-08-16

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in / 1456×819 PNG 네이티브) 슬라이드 덱 10장을 만든다. 이 팩은 **iF Design Award 2024 Communication Design 부문 수상작 NAVER Integrated Report 2024(NAVER Corporation × Talantone Creative Group)** 보고서의 1~50p 실측 디자인을 PPT 데크 문법으로 증류했다. v3는 v2의 5대 시그니처 시스템을 100% 유지하면서, 어떤 PDF 페이지에서 무엇을 가져오는지 **페이지 1:1 미러 플랜**을 10장 슬라이드에 못박는다.

> **v2 → v3 변경 핵심.** v2는 페이지 10종 표준만 정의해 "느낌 따라 만들기" 여지가 있었다. v3는 슬라이드별로 **소스 PDF 페이지·아키타입 ID·must-have 체크리스트**를 1:1 매핑해 동일 시각을 두 번 재현하지 못하는 여지를 제거했다. v1의 'CIRCLE/DOT/LINE/BLOCK/WAVE 5종 모티프' 가설은 v2에서 폐기, v3에서도 사용 금지.


## 이 스타일의 정체성 — 어워드 수상의 5대 시그니처 (반드시 동시에 작동)

이 팩을 한눈에 알아보는 단서 다섯 가지가 한 덱 안에서 동시에 작동한다. 하나라도 빠지면 어워드 강도가 즉시 무너진다.

1. **거대 영문 디스플레이 타이포.** 표지 'INTEGRATED REPORT', 섹션 슬레이트 'Business Report'·'Business Portfolio'를 페이지 폭의 **60~75%** 점유하도록 깐다. PDF 원본 환산 **140~180pt**(표지) / **96pt**(섹션 슬레이트). 작게 쓰면 즉시 실패다.
2. **NAVER Green 메쉬 그라디언트 페이드.** 솔리드 풀블리드 컬러 배경 금지. 표지·섹션 슬레이트는 흰 캔버스 위에 그린이 안개처럼 떠다니는 메쉬 페이드만 허용. 풀블리드는 On-Service AI 인트로 1종에 한정.
3. **5개 사업부문 시그니처 컬러 시스템.** Search Platform `#03C75A` / Commerce `#7C5BFF` / Fintech `#1ED2C0` / Contents `#FF6A4A` / Enterprise/Cloud `#4FB8FF`. 한 페이지 = 한 부문 컬러(다부문 비교 도넛 1종만 예외 — 6색 동시 허용).
4. **거대 솔리드 컬러 원 + 가운데 흰 수치 KPI.** 직경 페이지 폭의 **22~25%**(PPT 환산 2.9~3.3in), 그 부문 컬러 100% 솔리드 채움, 정중앙에 **60pt Bold 흰 수치 + Mixed-size 단위**. 한 KPI를 한 비주얼로 끝낸다.
5. **Mixed-size 한국식 단위 타이포.** '4'천'8'백만 명에서 **숫자만 36pt Bold + 한글 단위만 14pt Medium**으로 리듬화. '50.3 조원'은 '50.3'(60pt) + '조원'(24pt). 한국식 단위(천/만/억/조)를 시각적으로 분해하는 NAVER 보고서의 매우 독특한 활자 처리 — 반드시 적용한다.


## v3 페이지 1:1 미러 플랜 (10장 ← NAVER 보고서 50p)

NAVER 217p 보고서의 첫 50p에서 시그니처가 가장 응축된 10페이지를 골라 v3 10장 미니 덱에 1:1 매핑한다. 슬라이드별 소스 PDF 페이지·아키타입·시그니처 모티프를 못박는다.

| 슬라이드 | 소스 PDF 페이지 | 아키타입 | 시그니처 모티프 |
| --- | --- | --- | --- |
| s1 cover | p1 | L1 표지 + 우측 그린 페이드 | M1 거대 영문 + M2 메쉬 페이드 |
| s2 agenda | p3 | CONTENTS 5열 그리드 | 그린 챕터 헤더 |
| s3 section | p6 | L7 OVERVIEW + 세계지도 + ESG 알파벳 | M5 Mixed-size '13' + M6 데이터 알파벳 |
| s4 key-message | p8 | L8 수평 마일스톤 타임라인 | M8 그린 도트 마일스톤 |
| s5 chart | p11 | L4 On-Search AI 풀블리드 그린 메쉬 | M3 부문 컬러 풀블리드 인트로 |
| s6 diagram | p20 또는 p23 | L2 섹션 슬레이트 + 중앙 96pt 거대 영문 | M1 + M2 |
| s7 cards | p21 | L9 BUSINESS HIGHLIGHTS 3패널 + 6색 도넛 | 다부문 도넛 6색 (5개 부문 컬러 일괄 노출) |
| s8 comparison | p24 | L3 SEARCH PLATFORM 2x2 데이터 카드 | M4 거대 솔리드 원 + M5 Mixed-size + M7 카드 템플릿 |
| s9 narrative | p10 | L5 On-Service AI 4컬러 노드 네트워크 | 부문 컬러 노드(그린/퍼플/블루/시안) |
| s10 closing | p47 | L10 Commerce 지속가능 사진 + 해시태그 + 인용 카드뉴스 | M10 |

**커버리지 보증.**
- 5대 시그니처(M1~M5 + M7·M8·M10): 모두 1번 이상 등장.
- 5개 부문 컬러: 그린(s5/s7/s8/s9) + 퍼플(s7/s9/s10) + 민트(s7) + 코랄(s7) + 스카이블루(s7/s9). s7 다부문 도넛 6색 + s9 4색 노드가 5색 일괄 노출의 핵심.
- 고정 chrome(상단 네비 + 하단 푸터): s2·s3·s4·s6·s7·s8·s9·s10 총 8장. s1·s5는 chrome 숨김 또는 흰색 토글.


## 색

### 무채색 기반 (페이지의 70~80%)
- 배경 `#FFFFFF` (순백 지배). 표지·섹션 슬레이트는 흰 캔버스 + 그린 메쉬 페이드.
- 본문·제목 텍스트 `#0A0A0A` (거의 순흑).
- 보조 텍스트 `#7B7B7B` (중간 회색 — 축 라벨·캡션).
- 비활성/네비 비활성 `#B4B4B4`.
- 비교 막대(전년) `#C8C8C8`, 도넛 비강조 조각 `#E8E8E8`.
- 헤어라인·카드 보더 `#E8E8E8`.

### NAVER Green (브랜드 정본)
- `#03C75A` — Search Platform 부문 시그니처이자 표지·섹션 그라디언트 코어. 본문 페이지 1~3% 면적, 표지·섹션 그라디언트에서는 30~40% 면적이지만 매우 옅은 톤.
- 그라디언트 보조 톤: `#5BDF92`(중간) / `#A8F0C4`(엣지) / `#C8F2D6`(외곽 페이드 시작) / `#03A047`(On-Search AI 풀블리드 중심 진한 톤).

**핵심 규칙.**
- 한 페이지 = 한 부문 시그니처 컬러. 다른 부문 컬러 혼용 절대 금지.
- 유일한 예외 = s7 BUSINESS HIGHLIGHTS 다부문 도넛 → 6색(`#03C75A` / `#7C5BFF` / `#1ED2C0` / `#FF6A4A` / `#4FB8FF` / `#FFD24A`) 동시 사용.
- s9 On-Service AI 다이어그램은 4컬러 노드(SEARCH 그린 / COMMERCE 퍼플 / ADVERTISING 블루 / PLACE 시안)가 한 페이지에 공존하지만 각 노드가 자기 부문을 명확히 가리키는 다이어그램 1종으로만 허용.
- 도넛 한 조각, 막대 한 줄, 거대 솔리드 원, % 수치, ▲ 화살표가 모두 그 부문 컬러로 일관 채색.

### 그라디언트 처방 (메쉬 페이드만 허용)

표지·섹션 슬레이트는 페이지 위치에 따라 처방이 다르다.

- **s1 표지 우측 세로띠 (p1 패턴):**
  `흰색 0% → #C8F2D6 60% → #5BDF92 80% → #03C75A 95% → #03C75A 100%` (가로 방향, 좌측 80%가 거의 흰 캔버스, 우측 20%에 세로띠 형태 그린 페이드).
- **s6 섹션 슬레이트 중앙 박스 (p20 패턴):**
  `흰색 0% → #C8F2D6 35% → #5BDF92 65% → #03C75A 80% → #5BDF92 90% → 흰색 100%`, 중앙에 부드러운 라운드 사각 박스 형태로 그린이 안개처럼 떠 있음.
- **s6 섹션 슬레이트 좌측 가로 fade-out (p23 패턴, 택1):**
  `#5BDF92 0% → #A8F0C4 15% → 흰색 50% → 흰색 100%`, 좌→우 fade-out으로 중앙 거대 라벨로 시선 유도.
- **s5 On-Search AI 풀블리드 (p11 패턴):**
  중심 `#03A047` → 외곽 `#5BDF92`, 둥근 가로 슈퍼타원 형상이 풀블리드 안에 별도로 떠 있는 부드러운 메쉬.
- **금지:** 솔리드 풀블리드 컬러 배경 / 무지개 그라디언트 / 텍스처 / 노이즈.


## 타이포그래피

### 폰트 패밀리
- **한글:** `Pretendard` (대체 `Noto Sans KR`). Nanum 시리즈 금지.
- **영문:** `Inter` (대체 `Helvetica Neue`, `SF Pro Display`). 거대 디스플레이는 표준 너비 + Bold/Black + 자간 `-2~-3%`로 매우 타이트.

### 사이즈 스케일 (PDF 네이티브 pt 기준 / PPT 16:9 환산 동일)

- **표지 거대 디스플레이 (s1):** `140~180pt Bold`, 자간 `-2.5%`, 행간 `1.0`, 페이지 폭 `60~75%` 점유. (예: 'INTEGRATED REPORT')
- **표지 연도 (s1):** `100pt Bold`, 자간 `-2%`. (예: '2024')
- **섹션 슬레이트 거대 라벨 (s6):** `96pt Bold`, 자간 `-2%`, 중앙 정렬. (예: 'Business Report' / 'Business Portfolio')
- **섹션 부제 (s6):** `14pt Medium`, 행간 `1.6`, 중앙 정렬 2~5줄.
- **페이지 H1 영문 ALL CAPS (s8):** `40~44pt Bold`. (예: 'SEARCH PLATFORM' / 'COMMERCE' / 'FINTECH' / 'CONTENTS')
- **페이지 H1 영문 ALL CAPS 32pt (s2/s3/s4/s7):** `32pt Bold`. (예: 'CONTENTS' / 'OVERVIEW' / 'KEY MILESTONES' / 'BUSINESS HIGHLIGHTS')
- **페이지 H1 위 키커:** `14pt SemiBold`, 그 위 작게. (예: 'Value Creation in Business')
- **페이지 H1 한글 (s9):** `28pt SemiBold`, 좌측 정렬. (예: "개인화의 혁신 'On-Service AI'")
- **타임라인 시기 라벨 (s4):** `32pt Bold` 4구간. (예: '2008-2014' / '2015-2019' / '2020-2022' / '2023-2024')
- **ESG 등급 알파벳 (s3):** `90~110pt Bold`, 2024년만 그린 / 과거 `#C8C8C8`. (예: 'A' / 'AA' / 'AAA')
- **글로벌 진출 거대 숫자 (s3):** `60pt Bold` 그린 + `14pt Medium` 검정 단위. (예: '13'개국 진출)
- **데이터 카드 거대 % 수치 (s7/s8):** `40pt Bold` 또는 `56pt Bold`, 부문 컬러. (예: '9.9%' / '11.0%↑')
- **거대 솔리드 원 안 흰 수치 (s8):** `60pt Bold` 흰색, 원 정중앙. (예: '400'(60pt) + '만 개'(24pt) + '+'(36pt))
- **분기 막대 우측 연간 합계 (s8):** `56pt Bold` 검정. (예: '39,462')
- **도넛 강조 조각 옆 % (s7/s8):** `24pt Bold` 부문 컬러. (예: '36.8%')
- **2년 비교 막대 우상단 델타 (s8):** `40pt Bold` % + `12pt` '전년 대비' + ▲, 모두 부문 컬러.
- **본문:** `11~12pt Regular`, 행간 `1.55`, `#0A0A0A`. 멀티컬럼 좌측 정렬(양끝 정렬 금지).
- **캡션·푸터·출처:** `9~10pt Regular`, `#7B7B7B`.
- **상단 네비 라벨:** `11pt Medium`, ALL CAPS, 자간 `+4%`. 비활성 `#B4B4B4` / 활성 `#0A0A0A` + `1.5pt #03C75A` 하단 언더라인. 풀블리드 페이지(s5)에서는 모든 라벨 흰색.
- **상단 서브탭 (BUSINESS REPORT 활성 시):** `11pt Medium`, Mixed Case, 자간 `+2%`. 활성 `#0A0A0A` + 그린 언더라인 / 비활성 `#7B7B7B`. (예: 'Approach to Business · Business Portfolio · Sustainable Business Practices')

### Mixed-size 한국식 단위 타이포 (NAVER 시그니처 — 반드시 적용)

한국식 단위를 잘게 쪼개 거대 숫자 + 작은 단위로 리듬화. 이게 없으면 NAVER 톤이 안 난다.

```
"4천 8백만 명"   →   "4"(36pt Bold) + "천"(14pt Medium) + "8"(36pt Bold) + "백만 명"(14pt Medium)   ← s8 도넛 우측
"1억 2천만 회"   →   "1"(36pt) + "억"(14pt) + "2"(36pt) + "천만 회"(14pt)                          ← s8 우상 픽토그램
"50.3 조원"      →   "50.3"(60pt Bold) + "조원"(24pt Medium)
"70만 개+"       →   "70"(36pt Bold) + "만 개"(14pt Medium) + "+"(36pt)
"400만 개+"      →   "400"(60pt Bold 흰) + "만 개"(24pt Medium 흰) + "+"(36pt 흰)              ← s8 거대 솔리드 원 안
"13개국 진출"    →   "13"(60pt Bold 그린) + "개국 진출"(14pt Medium 검정)                       ← s3 글로벌 네트워크
"11.0%↑"         →   "11.0%"(56pt Bold 검정) + "↑"(24pt 검정)                                  ← s7 영업수익 거대 델타
```

- 숫자 = 그 부문 시그니처 컬러 또는 `#0A0A0A` (거대 솔리드 원 안에서는 흰색).
- 단위 = 동일 컬러 또는 `#7B7B7B`.
- 숫자와 단위의 weight 차이(Bold vs Medium)와 size 차이(2~4배)가 동시에 작동해야 리듬이 산다.

### 거대 알파벳/숫자 자체를 인포그래픽으로 사용 (s3)
- ESG 평가 등급(`A`, `A+`, `AAA`, `AA`)을 `90~110pt Bold`로 직접 표시. 2024년 등급만 `#03C75A`, 과거는 `#C8C8C8`.
- 글로벌 진출 국가 수 — `13` `60pt Bold` 그린 + `개국 진출` `14pt Medium` 검정.
- 차트 없이 알파벳/숫자가 곧 데이터.


## 레이아웃 / 그리드

- 좌우 여백 각 `4.5%`(약 0.6in), 상하 여백 각 0.5in.

## 하지 말 것 (이 스타일에서 금지)

- **5개 사업부문 컬러를 한 페이지에 동시 강조 금지.** 한 페이지 = 한 부문 컬러. 다부문 비교 도넛(s7) + On-Service AI 다이어그램 4컬러 노드(s9) 2종만 예외. Search 그린과 Commerce 퍼플을 같은 데이터 카드 페이지에 섞으면 즉시 실패.
- **솔리드 풀블리드 컬러 배경 금지.** 표지·섹션 슬레이트는 흰 캔버스 위 옅은 메쉬 페이드만. On-Service AI 인트로(s5)와 Next, N(p19, v3 덱 외)만 부문 컬러 풀블리드 메쉬 그라디언트 허용.
- **표지·섹션 슬레이트 거대 영문을 작게 쓰지 말 것.** 페이지 폭 60~75% 점유가 어워드 시그니처. 100pt 미만은 즉시 어워드 강도 상실.
- **Mixed-size 한국식 단위 타이포 누락 금지.** '4천 8백만 명'을 통자 36pt로 쓰면 NAVER 톤이 아니다. 숫자만 거대 + 단위 한글만 작게가 의무.
- **무지개 색칠 / 다색 차트 금지** (s7 다부문 비교 도넛 1종 예외). 단일 강조 차트는 부문 컬러 1색 + 무채색 비교.
- **3D 차트 / 입체 도넛 / 그림자 막대 / 면적 채움 라인차트 / 기본 PPT 차트 위젯** 금지. 모두 SVG 정밀 렌더.
- **격자선 다중 / 양쪽 축선 / 범례 박스** 금지. 직접 라벨링 의무. 잘린 축 금지(기준선 0 시작).
- **둥근 모서리 과다(16px 이상 반경), 그림자, 텍스처, 노이즈** 금지. 카드 8~10px, 라벨 박스 12px, 원형 999px 셋만.
- **이모지 불릿 / 클립아트 / 스톡 픽토그램** 금지. 아이콘은 1.5~2pt 라인 단색 SVG.
- **Nanum 한글 폰트 금지.** NAVER 보고서는 Pretendard 톤. Nanum 시리즈는 명백히 다른 톤.
- **본문 페이지에서 60pt 이상 거대 타이포 금지.** 거대 타이포는 표지·섹션 슬레이트·데이터 카드 KPI에만.
- **CIRCLE/DOT/LINE/BLOCK/WAVE 5종 모티프 시스템에 회귀 금지.** v1의 결정적 오류. 실제 변주 축은 5개 사업부문 시그니처 컬러다.
- **고정 chrome(상단 네비 + 하단 푸터) 누락 금지** — s1·s5(풀블리드) 제외 8장에서는 chrome 표시. s5에서는 chrome 흰색 토글.
