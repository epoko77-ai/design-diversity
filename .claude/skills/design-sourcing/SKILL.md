# Design Sourcing — 디자인 스타일 소싱 방법론

design-scout가 시각적으로 뚜렷이 구별되는 스타일 후보 풀을 만들 때 따르는 방법론.

## 소싱 원칙

1. **1차 출처를 확인한다.** 공식 디자인 시스템 문서, 브랜드 가이드, 디자인 운동을 정의한 원저자 글. WebSearch·WebFetch로 URL을 실제 확인하고 `sources`에 기록한다.
2. **다양성이 목적이다.** 후보는 `design-pack-schema`의 5축(color/type/layout/space/motion)에서 서로 흩어져야 한다. 같은 축 값이 몰리면 빈 칸을 채우는 방향으로 추가 후보를 찾는다.
3. **영감이지 복제가 아니다.** 추출 대상은 공개적으로 학습 가능한 시각 원리뿐. 상표·로고·독점 일러스트·고유 아이콘셋은 후보 DNA에 포함하지 않는다.
4. **라이선스를 기록한다.** 원자산 라이선스를 확인하고, 불명확하면 `license: unclear`로 표시해 pack-architect에 넘긴다. 우리가 배포하는 것은 명세·토큰이지 원자산이 아니라는 점을 전제로 한다.

## 원본 적격 게이트 (`exact_document` 후보 전용)

특정 공개 덱을 원본으로 삼는 프리미엄 후보는, DNA를 쓰기 **전에** 기계적으로 거른다. 상세는 `reference-analysis` 스킬이 SSOT다.

| 게이트 | 기준 |
|---|---|
| 확보 | `curl -sL -o`로 실제 다운로드 성공. 링크 존재만으로는 불가 |
| 매체 형태 | PPT 트랙 **종횡비 ≥ 1.6** (1페이지 mediabox 실측) |
| 분량 | 페이지 ≥ 8 |
| 디자인 밀도 | 앞 5장을 렌더해 **직접 보고** 시각 언어 유무 판정 |
| 권리 | 공개 배포물 + 1차 출처 |

**종횡비 게이트가 이 프로젝트에서 가장 많이 실패한 지점이다.** A4 세로 한글 문서(≈0.71)를 덱으로 오인해 국토부·고용부 2팩을 폐기했고, 농식품부·행안부·식약처·기후에너지부·한국은행 후보 6건을 다운로드 후에야 버렸다. **비율을 먼저 재라 — 정독보다 먼저.**

탈락 후보도 사유와 함께 `01_scout_candidates.json`에 남긴다. 탈락 사유는 다음 회차가 같은 링크를 다시 파는 것을 막는 자산이다.

```json
{ "code": "cjenm", "aspect_ratio": 1.415, "gate_16x9": "fail",
  "verdict": "drop", "drop_reason": "A4 가로 비율. 16:9 게이트(≥1.6) 미달." }
```

## 후보 DNA 작성

각 후보는 후속 curator가 곧장 팩으로 증류할 수 있는 구체성을 갖춰야 한다:
- `dna` — "무엇을 보면 이 스타일인가" 2~3문장. 색 관계·타이포 성격·레이아웃·질감을 담는다.
- `distinct_axes` — 다른 후보와 구별되는 축을 명시.
- 추상적 형용사("우아한")가 아니라 관찰 가능한 특징("12열 그리드, 무채색 + 단일 강조색, 헤어라인 보더")으로 쓴다.

## 출처 우선순위

1. 공식 디자인 시스템 — Material Design, Apple HIG, IBM Carbon, Shopify Polaris, Atlassian, Microsoft Fluent, Base Web 등.
2. 디자인 운동 정전 — 스위스/인터내셔널 타이포그래피, 브루탈리즘, 멤피스, 바우하우스 등에 대한 학술·박물관·원저자 자료.
3. 공개 갤러리·어워드 — Awwwards, SiteInspire, Godly, Brutalist Websites 등 (스타일 분류 참고용, DNA는 실제 사례에서).
4. 한국 맥락 — 정책보고서·IR·공공 디자인 가이드 등 한국 사용자 수요가 큰 스타일.

블로그 재가공물은 보조로만 쓰고 1차 출처를 함께 단다.
