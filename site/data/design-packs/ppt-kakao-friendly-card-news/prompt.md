# 카카오 1Q26 보수 IR 옐로우 시그널 — ppt 디자인 팩 (v3)

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱 **10장**을 만든다. 카카오 2026년 1분기 실적발표(`1Q26 Earnings Release`, 소스 15장)를 우리 덱 10장으로 **1:1 미러**한 보수 IR 분석가 데크다. Bloomberg/Reuters 어닝 데크 양식 위에 카카오 옐로우를 **강조 시그널로만** 얹는 양식 — 카드뉴스가 아니다, 친근 면채움 아이콘이 없다, 둥근 모서리 절대주의가 아니다. 옐로우는 **슬라이드당 5~12% 면적만** 차지하고, 배경 `#F2F2F2` 밝은 회색이 캔버스 면적의 65~85%를 채운다.

## 이 스타일의 정체성 (v2 lock — 5대 시그니처)

한눈에 알아보는 단서 다섯:

1. **좌측 끝에 붙은 반쪽 알약 타이틀** — 좌측 x=0%에서 시작해 우측만 반원 캡, 너비 26% × 높이 8%, 채움 `#FAE232` 살짝 연한 옐로우, 안에 26pt 700 검정 본고딕 타이틀. 본문 슬라이드 8회 등장(2~9번). 슬라이드 정체성을 만드는 **단 1개의 둥근 요소**.
2. **현재 분기 빨강 사각 테두리** — 슬라이드 6의 실적요약·영업비용 표 1Q26 컬럼 본문을 1.5~2px `#FF0000` 빨강 직각 사각 테두리로 둘러싼다. 한 슬라이드에 **2회 등장**. 분석가 시선을 즉시 현재 분기로 집중시키는 시그니처.
3. **MAU 단일 옐로우 강조** — 슬라이드 9에서 8개 회색 막대 + 마지막 1Q26 한 막대만 옐로우 `#FBE100`, 마지막 라벨만 볼드. 장기 시계열의 "현재 위치"를 단일 색으로 표시. 차트 하단 표 마지막 셀(국내·글로벌)만 매우 옅은 옐로우 띤 `#FEF9D6`로 시각 연결.
4. **음수 = 베이스라인 아래 회색 막대 + 빨강 라벨** — 슬라이드 7 영업이익 AI 부문 `-36/-42/-46/-46/-55` + 당기순이익 4Q25 `-47`. 차트 음수는 빨강, **표 음수는 검정** — 다른 규칙.
5. **스택 막대 + 점선·파란 사각 마커 콤보** — OPM·당기순이익률·매출액 대비 CapEx를 1.5px `#007ABF` 점선(8px-4px) + 6×6 사각 마커로 오버레이. 슬라이드 7×2 + 슬라이드 8×1 = 3회 등장.

다섯 시그니처가 한 덱에 모이면 그것이 카카오 IR이다.

## 색

- 배경 `#F2F2F2` — 모든 본문 슬라이드. **흰색 아님.** RGB(242,242,242) 밝은 웜그레이. 슬라이드 1·10만 예외(표지 #F2F2F2 상단 + #C1E9F3 하단 / 감사 흰색 #FFFFFF).
- **카카오 옐로우 3종 위계** (혼동 금지):
  - `#FDD000` — 표지 `kakao` 로고타입 전용. 비비드 옐로우. **표지 1곳만, <0.5% 면적.**

## 레이아웃 / 그리드

- **16:9 슬라이드(13.33×7.5in)** 고정. 모든 본문 슬라이드 배경 `#F2F2F2`.

  - 슬라이드 5(포털·기타): 좌 50% 2차트 스택 + 우측 작은 옐로우 인셋 카드.
  - 슬라이드 6(실적요약/영업비용): 좌 50% 표 + 우 50% 표 + 하단 6 불릿.
  - 슬라이드 7·8: 좌 50% + 우 50% 차트.
  - 슬라이드 9(MAU): 풀폭 헤드라인 + 풀폭 9막대 차트 + 풀폭 표.
  - 컬럼 사이 디바이더 없음, 공백으로만 구분.
- **풋터 존**: 페이지 번호 슬라이드 중앙 하단 ~96% y, `kakao` 검정 워터마크 슬라이드 우하단 ~94~96% y. 슬라이드 1·10 예외(풋터 0개).
- **정보 밀도 중간(분석가 친화)**: 1슬라이드 1메시지 카드뉴스가 아님. 슬라이드당 1~2개 차트 + 3~5개 ▪ 불릿. 그러나 여백 35~45% 충분히 확보(빽빽한 컨설팅 덱과 다름).
- **카드·패널 없음.** 둥근 카드(반경 24/28/32px)·소프트 섀도·풀블리드 옐로우 패널 모두 금지. 컨텐츠는 배경 회색 위에 직접 떠 있고, 시각 분리는 (1) 알약 타이틀, (2) 표 zebra, (3) 1pt x축 베이스라인, (4) 표 빨강 테두리만으로 한다.

## 형태 / 질감

- **모서리 반경**: 알약 타이틀 1개 요소만 반쪽 캡슐(우측 반원). 차트 막대·표·박스·콜아웃 전부 **직각(radius 0)**. 둥근 모서리 16/24/28/32px 절대 금지.
- **보더**: 표 외곽선 없음 — 행 간 0.5pt `#BFBFBF` 헤어라인만(필요 시). 차트 외곽 박스 없음, x축 1pt `#000000` 가는 검정선만.
- **드롭섀도·소프트 섀도·링 펄스 전면 금지.** 분리는 채움 대비와 헤어라인으로만. 카카오 IR은 평면 인쇄 양식이다.
- **현재 분기 빨강 사각 테두리**: 1.5~2px solid `#FF0000`, 정확히 직각 사각 외곽선. 슬라이드 6의 실적요약·영업비용 표 1Q26 컬럼 본문 영역만 둘러쌈(헤더는 옐로우 채움이므로 테두리 시작은 헤더 바로 아래부터). **두 표 모두 동일 양식 — 한 슬라이드에 2회 등장**.
- **아이콘·일러스트 본문 0건.** 친근 면채움 글리프(말풍선·하트·전구·손인사·체크 동그라미 등) 사용 금지. 본문 카테고리 표시도 텍스트 라벨로만 — 옐로우 둥근 컨테이너 안 아이콘 컴포넌트 자체가 이 팩에 없다.
- **캐릭터 일러스트**: **표지(슬라이드 1)·감사(슬라이드 10) 두 페이지에만** 등장. IR 본문(슬라이드 2~9)은 일러스트 0건. 라이선스 사유로 카카오프렌즈(라이언·춘식이·어피치·무지·콘) 직접 사용 금지 — 일반화된 친근 마스코트(둥근 사자/곰/오리)로 대체하거나 생략. v3는 v2에서 ESG 페이지를 제외했으므로 캐릭터 출현이 3 → 2로 축소.
- **그라디언트·텍스처·노이즈·블러·3D·아이소메트릭·글래스모피즘 전면 금지.** 평면 IR 데크.

## 차트·데이터 시각화 (직각 막대 + 옐로우 강조 시그널)

차트는 SVG로 정밀 렌더한다. 카카오 IR 차트는 글로벌 IB 어닝 차트 표준 양식이다.

- **막대 모양**: **직각 사각 막대**, corner radius **0**. 둥근 막대 절대 금지. 막대 폭 50~60% of slot 너비(gap_ratio ~0.4). 스택 막대도 스택 사각형 — 각 세그먼트 직각.
- **축**: x축만 1pt `#000000` 가는 검정선 + 짧은 ~3px 검정 틱(카테고리마다). **y축선 없음. 가로 격자선 없음. 차트 박스 테두리 없음.** 분석가가 보는 정통 IR 차트 양식 — 데이터 라벨이 막대 위에 직접 표기되므로 격자선·y축이 불필요.
- **데이터 라벨**: 모든 값은 막대 위(총합) + 스택 구간 중앙(구간 값+%)에 직접 표기. 포맷 `1,022 (58%)` — 천 단위 콤마 정수 + 괄호 정수 %. 색 `#000000` 검정(음수만 `#FF0000` 빨강). 총합 16pt 700 Bold, 스택 구간 13pt 400 Regular. 어두운 회색 막대 위에서도 검정 유지(흰 글씨 사용 금지).
- **데이터 색 가변 할당 원칙**: 페이지마다 강조 카테고리 = 옐로우 `#FBE100`, 보조 카테고리 = 회색 `#BFBFBF` 또는 라이트 블루 `#99CCFF`. **고정 카테고리-색 매핑이 아니다** — 같은 "톡비즈"가 한 페이지에선 옐로우, 다른 페이지에선 회색이 될 수 있다. 페이지 내 강조 의도에 따라 가변.
  - 슬라이드 3 예: 좌(플랫폼 부문)는 톡비즈=회색·포털비즈=옐로우·플랫폼기타=라이트블루 / 우(콘텐츠 부문)는 뮤직=라이트블루·스토리=다크그레이·미디어=옐로우. 두 차트에서 옐로우가 다른 카테고리를 가리킨다.
- **단일 색 차트**:
  - `광고`, `엔터테인먼트` — 옐로우 `#FBE100` 단색 막대 5개(자사 전략 카테고리).
  - `커머스`, `포털비즈`, `픽코마` — 회색 `#BFBFBF` 또는 `#7F7F7F` 단색 막대 5개(중립·외부 컨디션 카테고리).
  - `플랫폼 기타`, `뮤직`, `미디어` — 라이트 블루 `#99CCFF` 단색 막대 5개(보조 카테고리).
- **스택 막대**: 슬라이드 2 매출 구성, 슬라이드 3 부문별 매출, 슬라이드 7 영업이익, 슬라이드 8 인원·CapEx. 옐로우 주력 + 회색·라이트블루 보조 조합. 페이지 내 강조 의도에 따라 옐로우가 위 또는 아래 스택.
- **음수 막대(베이스라인 아래)**: 음수는 x축 베이스라인 아래로 떨어진 회색 막대(`#BFBFBF`), 데이터 라벨 `#FF0000` 빨강. 음수 막대 안 텍스트도 빨강. 예: 슬라이드 7 영업이익 하단 -36, -42, -46, -46, -55(AI 서비스 손익) / 슬라이드 7 당기순이익 4Q25 -47.
- **라인 차트(콤보 전용)**: 스택 막대 + 점선 라인 콤보 차트. 라인은 **1.5px 점선** (dash 8px - gap 4px), 색 `#007ABF` 어두운 시안 블루. 각 데이터 포인트에 **6×6px solid 사각 마커** `#007ABF`. **둥근 라인 캡·스무드 커브 금지** — 점선과 사각 마커가 양식. 마커 옆 값 라벨은 검정 텍스트로 직접 표기. 적용: 슬라이드 7 OPM 라인(`7.3% / 10.6% / 11.4% / 10.6% / 10.9%`), 슬라이드 7 당기순이익률 라인(`11.5% / 9.0% / 9.8% / - / 11.7%`), 슬라이드 8 매출액 대비 CapEx 라인(`7% / 5% / 9% / 9% / 6%`).
- **MAU 단일 옐로우 강조 시그니처** (슬라이드 9): 9개 분기 카카오톡 MAU에서 **마지막 1개 막대(1Q26)만 옐로우** `#FBE100`, 나머지 8개는 회색 `#BFBFBF`. 라벨도 마지막 막대만 16pt 700 볼드, 나머지는 14pt 400 일반. 데이터: 48,696 / 48,931 / 48,933 / 48,954 / 49,099 / 49,298 / 49,468 / 49,500 / **49,575**(마지막만 볼드). 차트 하단 데이터 표(국내/글로벌 2행) 마지막 셀(1Q26)만 매우 옅은 옐로우 띤 `#FEF9D6`로 시각 연결.
- **범례**: 차트 위 또는 차트 위 좌측에 12×12px 작은 색 사각형 + 카테고리 텍스트(12pt). 라인은 점선 + 사각 마커 미니 아이콘. **범례 박스 보더 없음.** 예: `■ 톡비즈   ■ 포털비즈   ■ 플랫폼 기타`, `■ 카카오(별도)¹⁾   ■ 종속회사²⁾   ■ AI³⁾   ┄■ OPM`.
- **출처/단위**: 차트 우상단 또는 (단위: 십억원) 형식으로 메타 표기, `#7F7F7F` 12pt. 각주 1)/2)/3) 9pt `#7F7F7F`로 차트·표 아래 좌측.
- **금지 차트**: 도넛, 메코, 워터폴, 3D, 그라디언트 채움, 면적 채움 라인, 무지개 채색, 둥근 막대, 부드러운 곡선 라인, 드롭섀도, 다중 도넛, 차트 박스 테두리, y축 라인, 가로 격자선.

## 표 (어닝 분석표 양식)

표는 카카오 IR의 두 번째 핵심 시각 양식이다. 슬라이드 6(실적요약 + 영업비용 좌·우 통합)이 v3 표 양식의 정립 페이지다.

- **헤더 행**: `#FBE100` 옐로우 풀채움 + 14pt 700 검정 볼드. 컬럼: `구분 | 1Q25 | 4Q25 | 1Q26 | YoY | QoQ`.
- **합계/소계 행**: `#BFBFBF` 진한 회색 음영 + 13pt 700 검정 볼드. 적용: `매출`, `플랫폼 부문`, `콘텐츠 부문`, `영업비용`, `영업이익`, `당기순이익` 등.
- **본문 행**: zebra `#FFFFFF` ↔ `#F2F2F2` 교대. 13pt 400 검정. 하위 항목은 들여쓰기 + 일반 weight.
- **YoY/QoQ 컬럼**: italic + 400 + 검정.
- **비율 행**(영업이익률, 당기순이익률 등): italic + 400 + `#7F7F7F` 옅은 회색. 예: `영업이익률 7.3% 10.6% 10.9% +3.6%pt +0.3%pt`.
- **특수 키워드**: `흑자전환`, `Flat` — italic + 700 + 검정. 색 없음.
- **외곽선 없음**: 표 전체를 둘러싸는 굵은 외곽선 금지. 행 간 0.5pt `#BFBFBF` 미세 헤어라인만(필요 시).
- **현재 분기 빨강 사각 테두리**: **1.5~2px solid `#FF0000` 직각 사각형**으로 1Q26 컬럼 본문 영역 전체를 둘러쌈. 헤더(옐로우 풀채움)는 제외 — 테두리는 헤더 바로 아래 첫 본문 행부터 시작해서 마지막 본문 행까지. 분석가 시선을 즉시 현재 분기로 집중. 슬라이드 6에 **2회 등장**(좌 실적요약 표, 우 영업비용 표).
- **표 음수**: 표 내 음수는 텍스트만 검정 `-47` 식. 차트 음수는 빨강, **표 음수는 검정** — 다른 규칙(차트는 시각 강조, 표는 분석 데이터).

## 다이어그램·컴포넌트 (해당 없음)

이 팩에는 **별도 다이어그램 언어가 없다.** 카드뉴스 카드 그리드, 둥근 카드 적층 퍼널, Before/After 비교 카드, KPI 아이콘 카드, 프로세스 노드 그래프, 타임라인 트랙바, 옐로우 풀스크린 섹션 표지, 친근 면채움 아이콘 컨테이너 — **전부 사용 금지.** 시각 커뮤니케이션은 (1) 차트, (2) 표, (3) ▪ 사각 불릿 본문 세 가지 양식으로만 한다.

- 프로세스가 필요하면 → ▪ 번호 불릿 리스트 + 굵은 단계명으로 표현.
- 비교가 필요하면 → 단일 표에서 `1Q25 | 4Q25 | 1Q26 | YoY | QoQ` 컬럼 + 1Q26 빨강 사각 테두리로 표현.
- KPI가 필요하면 → 차트 옆 메트릭 콜아웃 한 줄(`1Q26 +16% YoY, -10% QoQ`) + ▪ 보조 불릿으로 표현.
- 섹션 구분이 필요하면 → 알약 타이틀 텍스트에 파이프 `|` 또는 슬래시 `/`로 표기(예: `플랫폼 부문 | 톡비즈`, `영업이익 / 당기순이익`). 풀스크린 섹션 디바이더 페이지 없음.
- 아이콘이 필요하면 → 텍스트 라벨로 대체. 본문에 아이콘 0건.

## 전환 (PPT)

서브틀. **슬라이드 컷 전환만** — 휘릭·바운스·페이드·6px 슬라이드 인·패럴랙스·스케일 인·옐로우 링 펄스·소프트 바운스 cubic-bezier 전부 금지. 분석가 친화 대시보드의 청결함이 메시지다. 움직임은 보수 IR 톤을 배신한다.

## 하지 말 것

- **둥근 모서리(반경 16/24/28/32px) 차트·표·박스에 절대 금지** — 둥근 모서리는 알약 타이틀 1개 요소(우측 반원 캡)만. 차트 막대 직각, 표 직각, 사각 테두리 직각.
- **드롭섀도·소프트 섀도·링 펄스·옐로우 글로우 전면 금지** — 평면 IR 데크. 분리는 채움 대비와 헤어라인만.
- **카드뉴스 풍 둥근 흰 카드(반경 24~32px) 적층 금지** — "한 슬라이드 = 한 카드 = 한 메시지" 양식 자체가 이 팩에 없음. 정보 밀도 중간(슬라이드당 1~2 차트 + 3~5 불릿).
- **친근 면채움 아이콘·옐로우 둥근 컨테이너·아이콘 그리드 카드 금지** — 본문 IR 슬라이드에 아이콘 0건. 카테고리 표시는 텍스트 라벨로만.
- **풀블리드 옐로우 섹션 디바이더 페이지 금지** — 옐로우는 강조 시그널이지 면채움 양식이 아니다. 슬라이드당 옐로우 5~12% 면적 상한 엄수.
