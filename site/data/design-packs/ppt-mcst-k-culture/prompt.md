# 문체부 K-컬처 라벤더 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in = 1280×720px) 슬라이드 덱을 만든다. 이건 다크 시네마틱 브리핑도, 흑백 백서도, 산업 슬로건 일러스트도 아니다. **라벤더-퍼플 `#7285E4`를 시그니처로, navy `#32355D`를 본문 표준으로, K-컬처 브라운 `#8F6F56`을 정책 코드로** 사용하는 3색 정체성의 문화·예술 감성 정부 브리핑 PPT다. 발표 거리 6m에서 또렷이 읽히는 16:9 캔버스, 카드는 단일 anatomy(둥근 navy pill 헤더 + 흰 본문 박스 + dashed 1px 내부 구분선)로 통일, 섹션 디바이더는 K-컬처 실사 풀-블리드 + 라벤더 반투명 베일로 4회 반복한다.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 페이지 상단 좌측 이브라우(`지난 6개월간 성과` `문화체육관광부 업무보고` `10대 핵심과제`) 좌측에 항상 라벤더 `#7285E4` 작은 점 또는 짧은 막대가 박혀 있다 — 다른 부처(기재부 노랑 형광, 산자부 빨강, 과기부 진청)가 빨강·주황·노랑을 시그니처로 쓸 때 문체부는 **라벤더-퍼플** 한 색으로 문화·예술 감성을 표현한다. (2) 본문 페이지의 카드는 예외 없이 **둥근 navy `#32355D` pill 헤더(radius 999px 풀 라운드) + 흰 본문 박스 + dashed 1px `#DDE2EE` 내부 구분선**의 단일 anatomy로 통일. 3-up·2-up·4-up 어디서나 같은 어휘. (3) Ⅰ~Ⅳ 섹션 디바이더는 K-컬처 실사 사진(전통시장·K-팝 관객·제트엔진·청사초롱)을 풀-블리드로 깔고 라벤더 `#BCC4F2` 반투명 베일(alpha 0.6~0.7)을 씌운 뒤 흰 큰 H1 + 좌상단 outline pill `Ⅰ 10대 핵심과제`를 얹는 패턴이 정확히 4회 반복. (4) 핵심 메시지·정책 불릿은 `●`·`▶`·`■` 대신 **두 갈매기 V 화살표 ▶▶**로 좌측 정렬해 진행·전환 의미를 비주얼화한다. (5) K-관광 3천만 차트 슬라이드(p-20)는 라인 차트(KR navy / JP red dashed) + 미래 구간 노란 음영 + 'X2' 빨강 격차 마커 + 우측 KPI 카드 + 위쪽 화살표 + 빨강 CTA 버튼 5요소를 한 슬라이드에 정밀 결합 — 정부 PPT에서 보기 드문 다요소 비주얼 통합. 이 5개가 빠지면 이 팩이 아니다.

## 타이포그래피
- 한글 본문·헤딩 모두 **Pretendard** 우선 / 보조 `Noto Sans KR` / 폴백 `Apple SD Gothic Neo, Malgun Gothic, sans-serif`. Pretendard 전 가족(Black 900 / Bold 700 / SemiBold 600 / Medium 500 / Regular 400) embed 필수 — 정부 문서이므로 폰트 누락 시 모든 한글 깨짐. 모노스페이스(IBM Plex Mono·JetBrains Mono) 금지, 영문 등폭 숫자 금지, 영문 워드마크 라인 금지.
- **표지 H1 (p01):** Pretendard Black(900) ~64pt, navy `#0B2A4F` 또는 `#022853`, 가운데 정렬. 페이지 중앙에 한 줄 또는 두 줄. letter-spacing -0.02em. 위쪽에 작은 정부 엠블럼(태극 + 문화체육관광부 워드마크).
- **페이지 이브라우 (모든 본문 페이지 좌상단):** Pretendard Medium(500) 14pt navy `#32355D`, letter-spacing -0.02em, **좌측에 라벤더 `#7285E4` 작은 점(지름 ~6px) 또는 짧은 막대(폭 ~12px×3px) 의무**. 형식 = `지난 6개월간 성과` `문화체육관광부 업무보고` `10대 핵심과제 N`.
- **본문 H1 hero (페이지 메인 메시지):** Pretendard Black(900) 44~52pt, navy `#32355D`, line-height 1.18, letter-spacing -0.03em. 가운데 정렬 또는 좌측 블록 정렬. 한 페이지에 한 줄(예: `K-컬처가 新성장동력이 되다` `K-관광, 3천만 조기 달성`).
- **outline pill 섹션 라벨 (본문 상단):** Pretendard Bold(700) 18pt navy `#32355D`. 둥근 모서리 풀 라운드(radius 999px) outline 박스(1.5pt navy stroke, transparent fill). 형식 = `6 문화창조산업 성장엔진 가속화` `09 K-컬처 활용 방한관광 활성화`. 박스 안쪽 padding x 3%, y 1%.
- **카드 헤더 pill (navy 풀필):** Pretendard Bold(700) 20pt 흰색 `#FFFFFF`, 가운데 정렬. 컨테이너 = radius 999px(fully rounded) + fill `#32355D` solid + padding x 3% / y 1%, 카드 폭의 80~90% 차지. **테두리·그림자·그라데이션 금지**.
- **카드 lead 문장:** Pretendard Bold(700) 17pt navy `#32355D`, line-height 1.45. 카드 본문 첫 줄, 한 문장으로 끝.
- **카드 본문 텍스트:** Pretendard Regular(400) 14pt `#5C5C63`, line-height 1.55, 가운데 또는 좌측 정렬. 슬라이드당 카드 모듈 1개에 4~6줄 이하.
- **카드 내부 dashed 구분선:** 1px dashed `#DDE2EE`, dash pattern 3-on/3-off, 카드 본문 항목 사이 가로 hairline.
- **번호 배지 (큰 번호 ⑥⑦⑧⑨⑩):** Pretendard Black(900) 24pt 흰색, 원형(지름 ~4% 슬라이드 폭) navy `#32355D` fill, p-09·p-11 형식 좌측 정렬 시 사용.

- **CTA 버튼 (p-20):** Pretendard Bold(700) 16pt 흰색 + 빨강 `#E33D3C` 또는 `#DB0725` fill + radius 999px(fully rounded). 예: `관광 정책 컨트롤 타워 강화`.

- **섹션 디바이더 H1:** Pretendard Black(900) 52pt **흰색** `#FFFFFF`, 가운데 정렬(또는 좌하단 정렬), letter-spacing -0.03em. 풀-블리드 사진 위 라벤더 베일 위에 얹힌다.

## 레이아웃 / 그리드
- **페이지 크기 16:9:** 13.33in × 7.5in = 1280px × 720px (또는 12192000 × 6858000 EMU). 모든 좌표는 page width/height 대비 % 비율로 계산해야 정확 재현 가능.
- **페이지 마진:** top 5.5% / right 4.8% / bottom 5.5% / left 4.8%.
- **본문 페이지 4단 수직 분할:**
  - 헤더 존: y=4.5%~11.0%. 좌측 이브라우(라벤더 점 + 텍스트) + 우상 정부 엠블럼(1.5%×3% 매우 작게) + 하단 1px `#C8E1EE` 가는 룰 라인.
  - H1 존: y=13.0%~26.0%. 본문 메인 메시지 H1 또는 섹션 큰 제목 + 그 아래 outline pill 섹션 라벨.
  - 메인 콘텐츠 존: y=28.0%~88.0%. 카드/다이어그램/차트/이미지 그리드.
  - 푸터 데코 존: y=88.0%~96.0%. 왼쪽 또는 양쪽 모서리 도트 패턴(8×6 그리드, `#BAD7E7` / `#8E93A7`). 페이지 번호·각주·워드마크 일체 없음.
- **표지·섹션 디바이더·종결:** 헤더·푸터 분할 없이 전체 캔버스를 풀-블리드로 사용. 표지 = 좌우 sweep 그라데이션 BG + 중앙 navy 제목 + 정부 엠블럼 + 모서리 도트. 섹션 디바이더 = 풀-블리드 사진 + 라벤더 베일 + 좌상단 outline pill + 흰 H1. 종결 = 좌 1/2 텍스트 + 우 1/2 실사 풀브리드.
- **카드 그리드 변형:**
  - 2-up = column 2개, col gap 5.0%, col width 41.5%
  - 3-up = column 3개, col gap 3.5%, col width 28.0%
  - 4-up = column 4개, col gap 2.5%, col width 21.5%
- **카드 anatomy (모든 카드 공통):**
  - 헤더 pill = height 7.0% (슬라이드 높이 대비), fill `#32355D`, text white 700 20pt, radius 999px fully rounded
  - 본문 박스 = height 55.0%, fill `#FFFFFF` 또는 rgba(255,255,255,0.85), 테두리 없음, padding 3.0%
  - 내부 구분선 = dashed 1px `#DDE2EE`, margin y 2.5%
- **모서리 처리:** 모든 카드·pill·outline 박스는 radius 999px(pill) 또는 8~12px(콘텐츠 박스). 사각 각진 모서리(0px) 금지. 다이어그램 트리(p-13 형식)의 외곽선은 둥근 모서리 사각 1.5pt navy stroke.
- **풀-블리드 사진:** 페이지 가장자리까지 닿게 깔되, 안전 영역(safe zone)은 안쪽 5% 여백 안. 사진 위 텍스트는 라벤더 베일(alpha 0.6~0.7)을 거쳐야 가독성 확보.

## 형태 / 질감
- **모서리 도트 패턴:** 좌하단·우상단에 작은 원형 도트(지름 ~4~6px) 8×6 또는 6×4 그리드. fill `#BAD7E7` 라이트 톤 또는 `#8E93A7` 짙은 톤. 페이지 정체성 데코 — 모든 본문 페이지에 최소 1코너 의무.
- **곡선 sweep 그라데이션 (표지 한정):** 좌우 비대칭의 부드러운 청회색 굴곡. fill linear-gradient `#E7EDF5` → `#FFFFFF` → `#DDE7F0`, 표지 캔버스 양옆에서 안쪽으로 휘어들어오는 sweep. 다른 페이지 사용 금지.
- **풀-블리드 사진 + 라벤더 베일:** Ⅰ~Ⅳ 섹션 디바이더 4페이지 한정. K-컬처 실사 사진(전통시장 K-푸드 좌판 / K-팝 콘서트 관객 / 제트엔진 클로즈업 / 청사초롱 야경) 풀-블리드 + 그 위 라벤더 `#BCC4F2` alpha 0.6~0.7 단색 반투명 오버레이.
- **K-컬처 일러스트 (p-13·p-17 형식):** K-푸드/K-패션/K-뷰티/K-관광 실사 사진을 둥근 마스크(원형 또는 radius 16px 사각)로 클립. 마스크 외곽에 보더 없음. 사진 톤은 브라운 `#8F6F56` 자연 톤이 두드러지게.
- **다양성 사람 일러스트 (p-13 우측):** 컬러 flat 일러스트(Made With Korea / K-브랜드 호감도 / 소비재 제조업 수출증가). 다양한 인종·연령 그룹. 클립아트·스톡 사진 금지 — flat 일러스트만.
