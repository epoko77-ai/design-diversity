# 통일부 한반도 평화공존 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(1280×720, 13.33×7.5in) 슬라이드 덱을 만든다. 통일부·외교부 합동 2026 업무계획 보고서 "한반도 평화공존 원년 만들기"를 mirror한 외교·통일 정부 정책 보고서 미감 — 다크 네이비 풀-블리드 위에 흰 카드가 떠 있고, 표지·종결에 한반도 발광 지도가 북엔드로 박혀 있으며, 슬라이드당 1회 손글씨 캘리그래피가 슬로건을 응축한다.

## 이 스타일의 정체성
한눈에 알아보는 단서 다섯 가지: (1) 전 슬라이드 다크 네이비 `#050829` 풀-블리드 — 일반 흰 배경 정부 보고서와 정반대, (2) 표지·종결에 **한반도 발광 지도**가 동일 형태로 박힌 '책의 북엔드' 모티프(북측 레드 글로우 `#A41729` / 남측 시안 글로우 `#5794C3` — 분단을 색으로 표현하되 같은 다크 캔버스에 함께 배치해 '평화공존' 시각화), (3) 손글씨 캘리그래피 슬로건이 슬라이드당 정확히 1회 등장(오렌지 `#F59751` 또는 종결 골드 `#FFFF66`), (4) Roman numeral(Ⅰ·Ⅱ·Ⅲ·Ⅳ)이 `#105FD2` 또는 `#08306C` 원 안에 흰색으로 박혀 목차·breadcrumb·내러티브 번호를 일관 표기, (5) 본문 카드는 흰색/페일블루로 다크 위에 떠 있고 카드 좌측에 `#105FD2` 컬러 스트립 5~10% 폭. 우상단에 통일부 BI 자리(흰 워터마크)가 본문 페이지 동일 위치 고정.

## 색
정부 보고서이지만 단조롭지 않다. **다크 캔버스 + 한반도 분단을 인코딩한 듀얼 글로우 + 캘리그래피 액센트**라는 3층 색 시스템.
- **배경 다크 네이비** `#050829` — 표지·종결·본문 전 13페이지 풀-블리드. 위에서 아래로 살짝 더 어두워지는 미세 그라데이션(헤더 영역 `#02072B` → 중간 `#02153D` → 액센트 `#001B4A`) 허용, 면적은 동일 톤.
- **한반도 북측 글로우 (레드 시스템 / 표지·종결 전용)** — 코어 `#A41729`, 하이라이트 `#C91E28`, 외곽 마젠타 `#9D204B`. 픽셀 입자감이 살짝 들어간 외부·내부 광선 효과로 다크 배경에 fade-out.
- **한반도 남측 글로우 (시안/블루 시스템 / 표지·종결 전용)** — 코어 `#5794C3`, 하이라이트 `#4AA2C1`, 깊은 외곽 `#1566A5`, 청록 엣지 `#327CAA`.
- **프라이머리 블루 (구조색)** `#105FD2` — 카드 좌측 컬러 스트립, Roman numeral 원, 하단 블루 리본 바, 듀얼 비교의 좌측(우방·미국) 태그.
- **딥 네이비 원 번호** `#08306C` — 내러티브 슬라이드의 01·02·03·04 큰 번호 원.
- **카드 표면색 팔레트** — 주력 화이트 카드 `#FFFFFF`, 보조 페일블루 `#EDF4FD`, 라이트 블루 틴트 `#D7E6FB`, 뉴트럴 그레이 `#EAEDF2`/`#E0E5EC`(부차 정보), 인포그래픽 노드는 파스텔 크림 `#FFF0B9` + 파스텔 시안 `#9EDBF4`/`#B9E5F7`.
- **캘리그래피 액센트 (희소)** — 오렌지 `#F59751`(본문 인용·표지 슬로건), 네온 골드 `#FFFF66`(종결 슬로건 전용). 캘리그래피 박스 그라데이션은 크림 `#FAE1C6` → 따뜻 살구 `#F4B673`.
- **듀얼 비교 페어(고정 규칙)** — 좌측 우방·미국 태그 `#105FD2`(블루), 우측 북한 태그 `#A41729`(레드). 비교 슬라이드 전반에 이 페어 룰 일관.
- **다크 위 텍스트** — 주 `#FFFFFF`, 보조 `#C9D9E6`, 음소거 `#9D9DAE`. **카드 위 텍스트** — 주 `#050829`, 보조 `#1E213F`, 태그 인디고 `#08306C`.
- 색 규칙: 다크 네이비는 캔버스, 화이트 카드는 콘텐츠 컨테이너, `#105FD2`는 구조(스트립·원·리본), 레드/시안은 한반도 모티프 전용(장식용 사용 금지), 캘리그래피 오렌지/골드는 슬라이드당 1회만.

## 타이포그래피
**캘리그래피 손글씨 + Pretendard ExtraBold**의 2-track 타이포 시스템. 캘리그래피는 슬로건 응축에만, 본문은 정부 표준 고딕.
- **캘리그래피 헤드라인** — 한국어 붓글씨 톤. 대체 폰트로 '나눔 손글씨 펜' 또는 'KCC 도담돋움 손글씨' 계열. 표지 슬로건 60~80pt, 본문 내 인용 32~40pt. 색은 `#F59751`(본문·표지) 또는 `#FFFF66`(종결 전용). **슬라이드당 1회만** — 남발 금지.
- **헤드라인 고딕**: `Pretendard` ExtraBold(800) 또는 Black(900), 32~38pt. 대체 `Noto Sans KR`. 흰색 위에 키워드 단어만 `#F59751` 오렌지로 강조.
- **서브헤딩**: Pretendard SemiBold(600), 20~24pt, 흰색.
- 본문: Pretendard Regular(400) ~ Medium(500), 12~14pt. 다크 배경 위 `#FFFFFF` 또는 `#C9D9E6`, 흰 카드 위 `#050829` 또는 `#1E213F`. 행간 1.5 (한국어 기준), 슬라이드당 최대 7줄.
- 캡션·출처·인용 라벨: Pretendard Regular, 9~10pt, 색 `#9D9DAE`. 예 "(트럼프 대통령, '25.10.29)".
- 태그 라벨: Pretendard SemiBold, 10~12pt 흰색, 배경 `#105FD2` 또는 `#08306C`, 둥근 모서리 사각형 또는 원(Roman numeral 표기 시 원).
- Breadcrumb (좌상단): Pretendard Regular, 10~11pt, 색 `#C9D9E6`. 포맷 "Ⅰ. 2025년 성과 및 평가" — 본문 전 페이지 일관.
- Roman numeral 원 안 숫자: 18~24pt 흰색, 원 직경 3~4% 슬라이드 폭.

## 레이아웃 / 그리드
모든 값은 16:9(13.33×7.5in / 1280×720) 캔버스 기준 **절대값**. 본문 페이지와 표지/종결 페이지는 별도 grid를 쓴다.
- **본문 페이지 그리드 (p02~p12 mirror — 9슬라이드)**:
  - **헤더 영역 (0~6%)**: 좌측 0~35% 가로에 breadcrumb "Ⅰ.·Ⅱ.·Ⅲ.·Ⅳ." 섹션 표기, 우측 85~98%에 통일부 BI 워터마크(흰색 또는 옅은 베이지). 풀-블리드 다크 `#050829`.
  - **타이틀 영역 (8~22%)**: 좌측 정렬(들여쓰기 4%), Pretendard ExtraBold 28~38pt 흰색 + 키워드 `#F59751` 강조, 부제 SemiBold 20~24pt.
  - **본문 영역 (22~85%)**: 다크 배경 위에 카드 컴포넌트(흰색/페일블루/그레이)를 떠 있게 배치. 가장 흔한 양식은 **3-column 또는 4-column 가로 카드 그리드**. 2-column comparison도 등장. 카드 모서리 반경 6~8px, 매우 부드러운 그림자 `0 4 12 rgba(0,0,0,0.3)`.
  - **푸터 영역 (88~96%)**: 캘리그래피 인용 1줄 또는 `#105FD2` 블루 리본 바 한 줄. 텍스트는 흰색 또는 캘리그래피 오렌지/골드.
- **표지·종결 페이지 그리드 (p01·p13 mirror — 북엔드 동일 구조)**:
  - 전면 다크 `#050829` 풀-블리드.
  - 좌측 5~50% 영역에 캘리그래피 슬로건 3줄(표지 오렌지 `#F59751`, 종결 골드 `#FFFF66`).
  - 우측 50~95% 영역에 한반도 발광 지도 — 가로 약 35~40%, 세로 약 80%, 수평 중앙선 기준 우측 60~95% / 수직 15~85%.
  - 좌하단 4~10% 가로, 7~13% 세로에 통일부 BI 로고.
- **카드 시스템 (본문 페이지 공통)**:
  - 카드 채움 `#FFFFFF`(주력) / `#EDF4FD`(보조) / `#EAEDF2`(부차).
  - **카드 좌측 컬러 스트립**: 폭 5~10%, 색 `#105FD2`(주) 또는 `#08306C`(섹션 강조). 스트립이 없는 카드는 카드 본문에 원형 번호 칩으로 대체.
  - 카드 내부 패딩 0.2in, 모서리 반경 6~8px, 그림자 `0 4 12 rgba(0,0,0,0.3)`.
  - 카드 안에 헤드라인(SemiBold 16~18pt, `#050829`) + 본문(Regular 12~14pt) + 선택적 작은 일러스트/사진.
- **Roman numeral 시스템**: 원 직경 3~4% 슬라이드 폭(약 0.45in), `#105FD2`(주) 또는 `#08306C`(섹션) 채움, 흰 숫자 18~24pt. p02 4분할 agenda 카드 상단 + 본문 페이지 breadcrumb에 사용.
- 듀얼 비교: 2-column 좌우 동일 폭. 좌측 카드 상단에 `#105FD2` 태그(미국·우방), 우측 카드 상단에 `#A41729` 태그(북한). 각 카드 인용문 + 사진 + 라벨.

## 형태 / 질감
- 카드 모서리 반경 6~8px. 부드러운 그림자 `0 4 12 rgba(0,0,0,0.3)`. 카드는 다크 위에 '떠 있는' 듯 보여야 한다 — 평면 붙임 금지.
- 한반도 발광 지도: 외곽선이 있고 내부는 빛나는 다이아몬드/네온 효과. 외부·내부 광선 효과처럼 작동, 픽셀 아트 같은 입자감(보석/지도 격자 느낌)이 살짝. 외곽으로 갈수록 다크 배경에 fade-out. 표지와 종결에 **동일 형태**로 배치(북엔드).
- Roman numeral 원: 모서리 반경 50%(완전 원). `#105FD2` 채움(주), `#08306C` 채움(섹션 강조).
- 블루 리본 바: 슬라이드 하단 88~96% 영역에 `#105FD2` 풀폭 띠 한 줄 + 흰 16pt SemiBold 텍스트. p06·p09 mirror 슬라이드에서 사용.
- 캘리그래피 박스 (key-message 슬라이드 하단): 그라데이션 `#FAE1C6` → `#F4B673`, 모서리 반경 12px, 내부에 캘리그래피 오렌지 손글씨 32~40pt.
- 다이어그램 노드: 흰 채움 + 1px 헤어라인 `#C5D2E3`, 모서리 반경 6~8px. 커넥터 1.5pt `#105FD2` 직각 화살표(화살촉 6px 삼각). 곡선 커넥터 금지.

## 차트 / 데이터 시각화
차트는 SVG로 정밀 렌더(div 블록 막대 금지). 다크 배경 위에 **흰 카드 컨테이너 + 카드 내부에 차트**라는 2층 구조 — 차트 자체는 카드 위에 그려진다.
- **데이터 색**: 주계열 `#105FD2`(KRDS 블루), 강조 1개 `#A41729`(레드) 또는 `#1566A5`(딥 시안), 무채색 보조 `#9D9DAE`. 무지개·장식 색칠 금지. 한 차트가 단일 계열이면 전부 `#105FD2`, 강조할 막대 1개만 의미색.
- **차트 카드 컨테이너**: 흰 `#FFFFFF` 카드, 모서리 6~8px, 좌측 `#105FD2` 컬러 스트립 5~10%. 차트는 카드 내부 패딩 0.3in 안에서 그려짐.
- **노드 그리드 인포그래픽 (p08 mirror)**: 3-column 흰 카드 안에 파스텔 크림 `#FFF0B9` + 파스텔 시안 `#9EDBF4` 노드(체크리스트 모양). 각 노드 0.5×0.5in 정사각, 모서리 4px, 라벨 12pt `#050829`.
- **막대 차트**: 막대 폭:간격 = 3:2, 모서리 반경 2~4px, 단색조. 막대 끝에 14pt SemiBold 값 레이블 직접 표기(`#050829`), 카테고리명 막대 아래 12pt `#5C6470`. 격자선 없거나 y축 주요 눈금 1~2개만 0.5pt `#E3EAF3`. x축 베이스라인만 0.75pt `#C5D2E3` 헤어라인. **y축 0에서 시작 의무**.
- **라인 차트**: 1.75pt 실선 `#105FD2`, 마커는 끝점·강조점만 0.14in 원형.
- **출처 의무**: 차트 하단 좌측 10pt `#9D9DAE` "출처: ..." 캡션 + 단위. 데이터를 쓰면 출처 필수.
- 금지: 3D 막대, 막대 그림자, 무지개 채색, 격자선 과다, 잘린 y축, 범례 박스(직접 라벨링).

## 다이어그램·컴포넌트
색·분위기만으로 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며, 하나의 다이어그램 언어를 공유한다 — **노드 모서리 반경 6~8px(카드와 동일), 커넥터 1.5pt `#105FD2` 직각 화살표(화살촉 6px 삼각), 단계 번호는 Roman numeral 원(`#105FD2` 채움·흰 숫자 20pt) 또는 01~04 깊은 네이비 원(`#08306C` 채움·흰 숫자 28pt), 강조는 한반도 듀얼(좌 블루 / 우 레드)로만**.
- **프로세스 플로우**: 3~4단계 흰 카드 노드(높이 1.0in, 모서리 6~8px, 그림자), 노드 좌측에 `#105FD2` 5~10% 컬러 스트립 + 좌상단 Roman numeral 원, 노드 사이 1.5pt `#105FD2` 직각 커넥터 + 6px 삼각 화살촉. 활성/현재 단계는 카드 상단에 `#105FD2` 태그 추가.

## 하지 말 것
- **흰 배경으로 회귀** — 다크 `#050829` 풀-블리드가 정체성. 모든 13페이지 동일 다크 캔버스.

- **한글 폰트를 Pretendard·Noto Sans KR 외로** — 폰트 깨짐 방지를 위해 반드시 한글 지원 폰트.
