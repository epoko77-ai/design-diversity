## 1. 캔버스 · 그리드 · 전역 규칙

- **캔버스:** 16:9 고정. 권장 1920×1080(또는 원본 1285×910).
- **세이프 마진:** 상 4% / 하 5% / 좌 6% / 우 6%.

- **워드마크:** 표지(v3 p-01)와 종결(v3 p-10) **우하단 5%×3%**에만 "산업통상부" 원형 마크 + 한글 텍스트. **부처합동(중기부·지식재산처) 워드마크 금지 — 원본 22장 어디에도 없다.** 본문 페이지 워드마크 금지.
- **breadcrumb:** 본문 페이지 좌상단 y3~8% / x4~35% 영역에 `정책방향 N. ___` 라벨(10~12pt, `#1C2848` 또는 `#303040`, Regular). 풀스크린 슬로건 페이지(p-01·종결 명언)엔 breadcrumb 없음.

- **풀스크린 슬로건:** y30~65% 영역에 캘리그래피 슬로건만. 한·두·세 줄, 우측 정렬이 한 칸씩 어긋난 손글씨 리듬.

## 3. 타이포그래피 — **한글 캘리그래피가 시그니처 폰트**

### 3-A. 캘리그래피 슬로건 (원본 22장 중 18장에 등장)
- **반드시 한글 브러시펜 캘리그래피 폰트로 처리한다.** Pretendard Bold 만으로 슬로건을 만들지 말 것.
- 특징: 굵기 변화 큼, 자음 끝선 살짝 끊김(먹물 번짐), 'ㅇ'·'ㅎ'의 곡선이 둥글게 휨, 자간 자연스러움.
- 사이즈: 표지 60~80pt / 정책방향 인트로 50~70pt / 본문 페이지 메인 타이틀 32~44pt / 종결 명언 44~60pt.
- 색: 라이트 배경 `#1C2848`, 다크 배경 `#FFFFFF` (강조 단어만 `#F2C45C`).
- **후보 폰트(유료):** 산돌제비2, 조선100년체, tvN 즐거운이야기체, 박용수체, 한컴 윤고딕흘림.
- **오픈 대체:** 학교안심실험(OFL), 둥근모꼴, 휴먼명조, GongGothic Bold(OFL), Pretendard Black + italic skew 6deg (최후수단).

### 3-B. 본문·라벨·캡션 (산세리프)
- Pretendard Regular/Medium/SemiBold 또는 Noto Sans KR / KoPubWorldDotum Pro.
- 카드 라벨 칩: 16~22pt Bold, 흰 글자.
- 본문 캡션: 12~16pt Regular/Medium, 행간 1.35~1.45.
- breadcrumb: 10~12pt Regular, `#1C2848`.

### 3-C. 큰 숫자 토큰 (차트 대체)
- 정량 데이터는 **반드시 56~96pt 큰 숫자 + 단위 + 1줄 캡션 카드**로만 표현. 예: `7,000억$ · 수출`, `500여 부문 · AI 팩토리`, `15개 단지 · AI 산업단지`, `90억$ · APEC 투자유치`.
- Pretendard ExtraBold/Black, 색 `#0066CC` 또는 `#F2C45C`.

### 3-D. 정책방향 인트로 인용부호 규칙 (시그니처)
- 정책방향 1·2·3 인트로 슬로건은 **반드시** `" "` 인용부호로 감쌈.
- 종결 페이지 슬로건도 인용부호 권장.
- 예: `" 지역 성장 '풀인' "` / `" 첨단제조 AI 대전환 "` / `" 新 통상전략으로 "`.

### 3-E. 한자 강조
- v3 p-03(3대 정책방향), p-08(新 통상전략) 등에서 한자는 한글보다 굵게/약간 키워서.
- 예: `新` `通商` — 한자만 +4~8pt, weight Black.

## 10. 반드시 (SOFT REQUIREMENTS) ★

1. 표지·정책방향 인트로·종결 슬로건은 **한글 캘리그래피 손글씨**로 처리.
2. 정책방향 인트로 슬로건은 **반드시 `" "` 인용부호로 감쌈**.
3. 본문 페이지 좌상단에 `정책방향 N. ___` 형식 breadcrumb (10~12pt, `#1C2848`).
4. 카드 라벨은 **5단 블루 그라데이션(`#0066CC → #00BCD4`)** 컬러 칩 + 흰 글자.
5. 다크 배경 페이지엔 골드 `#F2C45C` 강조 단어 / 시안 `#48F8F8` 또는 옐로그린 `#C8F018` 글로우(Slide 06 호 다이어그램만).
6. 라이트 배경 페이지엔 페일블루 `#E8F0F8` 또는 라이트시안 `#E8F8F8` 베이스.
7. 정량 데이터는 **차트가 아닌 큰 숫자 토큰 카드**(56~96pt + 단위 + 1줄 캡션).
8. 워드마크는 표지(Slide 01)·종결(Slide 10) 우하단에만 5%×3%.
9. 풀스크린 슬로건 비중은 전체 슬라이드의 **최소 30% 유지** (10장 중 최소 3장 = Slide 01·06 상단·10 명언 띠).
10. K-산업방파제(Slide 09)는 **반드시 3+2 카드 + 좌측 컬러 액센트 바 + 파도 배경**.
11. 한반도 지도(Slide 05)와 세계지도(Slide 08)는 **일러스트 톤 + 6핀+캡션 박스**로 처리.
12. AI 대전환 호 다이어그램(Slide 06)은 **반드시 위로 솟는 반원 점선 호 + 3노드 + 시안+옐로그린 듀얼 글로우**.
